# 결과보고서 — 탭 아이콘 통일 + PC 사이드바 자동펼침

> 작성일: 2026-05-21
> 계획서: `docs/plan-탭아이콘통일-사이드바자동펼침.md`

## 변경 사항 요약

### 작업 A — 벼/잡곡 탭 아이콘을 판매관리 기준으로 통일
원물재고·제품재고 탭의 아이콘을 판매관리 탭과 동일한 lucide 아이콘으로 교체.

- `app/(dashboard)/raw-stocks/raw-stocks-tabs.tsx`
  - import `{ RiceIcon, GrainIcon } from '@/components/icons/category'` → `{ Wheat, Sprout, type LucideIcon } from 'lucide-react'`
  - 타입 `Icon: typeof RiceIcon` → `Icon: LucideIcon`
  - `TABS`: 벼 `RiceIcon`→`Wheat`, 잡곡 `GrainIcon`→`Sprout`
  - lucide는 기본 24px이라 `<Icon>`에 크기 클래스 `w-3.5 h-3.5`(=14px, 기존 category 아이콘과 동일 크기) 추가
  - F안 스타일(active 시 scale-110 / strokeWidth 2.4·1.8 / 텍스트 14·13px / 2.5px 바)은 그대로 유지
- `app/(dashboard)/packages/packages-tabs.tsx` — 위와 동일
- `components/icons/category.tsx` — **삭제** (유일 사용처였던 두 탭이 교체되어 미사용)

결과: 원물재고 / 제품재고 / 판매관리 세 페이지의 벼·잡곡 탭 아이콘이 `Wheat`·`Sprout`로 통일됨.

### 작업 B — PC 사이드바 서브메뉴 자동펼침
`components/desktop-sidebar.tsx`의 "통계"·"관리자 메뉴" 서브메뉴를 항상 펼침 → 자동펼침 + 클릭 토글로 변경.

- import에 `useState`·`useEffect`·`ChevronDown`·`ChevronRight` 추가
- `statsActive`/`adminActive`(현재 경로 기반)로 `useState` 초기 펼침 결정
- 헤더 `<div>` → `<button onClick={토글}>` + 우측 Chevron(열림 ▾ / 닫힘 ▸)
- 서브 목록을 `{statsOpen && (…)}` / `{adminOpen && (…)}` 조건부 렌더
- 사이드바가 layout에 상주(persistent)해 SPA 이동 시 useState 초기값이 재평가되지 않으므로, `useEffect`로 해당 섹션 경로 진입 시 자동 펼침 동기화

동작: 통계/관리자 하위 페이지에 들어가면 그 섹션이 자동으로 펼쳐지고, 화살표를 눌러 수동으로 접고 펼 수 있음.
