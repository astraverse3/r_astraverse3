## 1. 배경

#5 본 작업(잡곡 입고 등록)에 들어가기 전 **잡곡 다이얼로그의 생산자 풀** 정책이 필요. 사용자 1차 피드백(2026-04-30):

> "잡곡 생산자는 대부분 기존 벼 생산자 중에 일부야. 모든 농가를 노출하는 건 비효율, 따로 잡곡생산자 테이블 분리도 비효율. 기존 생산자 테이블에 잡곡 생산도 하는지 필드를 추가하는 게 어때?"

→ A안 채택 — `Farmer.producesMiscGrain` Boolean 플래그.

## 2. 변경 사항

### 2.1 스키마 (prisma)
- `prisma/schema.prisma:36` Farmer 모델에 `producesMiscGrain Boolean @default(false)` 추가
- 마이그레이션 `20260430000000_add_produces_misc_grain_to_farmer/migration.sql` 생성 (단일 ALTER TABLE)
- `prisma migrate deploy`로 Neon DB 적용 — 기존 모든 농가 `false`로 백필됨

### 2.2 Server Actions ([app/actions/admin.ts](../app/actions/admin.ts))
- `FarmerFormData` 타입에 `producesMiscGrain?: boolean` 필드 추가
- `createFarmer`: `data.producesMiscGrain ?? false` 저장
- `updateFarmer`: 조건부 spread (`data.producesMiscGrain !== undefined`) — 미전달 시 기존 값 보존
- `createFarmerWithGroup`: `fProducesMiscGrain` 헬퍼 변수로 트랜잭션 내부 farmer create에 전달

### 2.3 UI ([app/(dashboard)/admin/farmers/add-farmer-dialog.tsx](../app/(dashboard)/admin/farmers/add-farmer-dialog.tsx))
- Farmer interface에 `producesMiscGrain?: boolean` 추가
- `useState<boolean>` 신규 — 다이얼로그 열 때 farmer 값으로 동기화 (등록 시 false, 수정 시 기존 값)
- 폼 하단(연락처 아래, 저장 버튼 위)에 체크박스 카드 — amber 색 강조, "잡곡도 생산" 라벨
- onSubmit 분기 3가지(`createFarmerWithGroup` / `createFarmer` / `updateFarmer`) 모두에 `producesMiscGrain` 전달

### 2.4 farmer-list.tsx
- Farmer interface에 optional 필드 추가만. 표시 측은 본 단계에서 변경 없음 (잡곡 농가 표시 칼럼은 #5d 작업 또는 후속 PR에서 검토 가능)

## 4. 영향 범위

### 회귀 위험 (체크 완료)
- 기존 `getFarmersWithGroups`: prisma findMany는 자동으로 모든 컬럼 반환 → 신규 필드도 자동 포함, 호출부 변경 불필요
- 벼 입고 다이얼로그(`AddStockDialog`): `producesMiscGrain` 무시. 기존 인증/년도 필터만 사용 — 동작 변화 없음
- 농가 등록/수정 외 모든 화면: 영향 없음

### 이후 활용 (#5a 진입 시)
- `app/actions/misc-stock.ts`의 `getMiscFarmers()`에서 `where: { producesMiscGrain: true }` 필터로 활용

## 6. 추가 작업 (사용자 2차 피드백 반영)

PC 사용자 검수 후 표시·필터 요청 추가 — 같은 #5-pre 커밋에 통합:

### 결정 (B안)
- `Farmer.producesRice` 필드 신설 X — 모든 농가는 기본 "벼 생산"으로 가정
- 표시: **"벼"** (잡곡 미체크) / **"벼,잡곡"** (잡곡 체크)
- 빈 비고/연락처는 **미표시** (회색 빈 뱃지 아님)
- 마우스오버: PC native title 속성 (외부 dep 없이), 모바일 기존 Popover 유지
- 필터: "잡곡 생산자만" 체크박스 1개

### 변경 (PC 테이블)
- "품목" 컬럼 → **"곡종"** 컬럼 (벼/벼,잡곡 뱃지). 그 우측에 새 **"비고"** 컬럼 추가
- 비고 뱃지: 보라색 round-pill, max-w 160px truncate, `title` hover로 풀텍스트
- 연락처 뱃지: 청색 round-pill + 전화 아이콘 + `tel:` 링크, `title` hover
- 그룹 헤더 행 `colSpan` 3→4 / 빈 상태 `colSpan` 10→11 보정

### 변경 (모바일 카드)
- 좌측 [번호][이름][전화뱃지] 다음에 **곡종 라벨**(벼/벼,잡곡) 추가
- 우측 "품목" 배지 텍스트 → **"비고"**, Popover 헤더도 "생산 품목" → "비고"
- 빈 phone/items는 회색 placeholder 제거 → **미표시**

### 변경 (검색 필터)
- `farmer-filters.tsx`에 "잡곡 생산자만" 체크박스 추가 (amber 강조)
