## 2. 주요 결정

- **미결 A~D 확정**: A=포장일자 자리 대체 / B=**primary**(amber 기각 — 재포장 손실 인정과 동일 어휘) / C·D=계획서 확정안 그대로
- 이력 「보기」는 공개, **되돌리기 버튼만 OPERATION_MANAGE**(`canCancel` prop) — 서버도 같은 권한으로 거부
- 이력 메뉴 노출 판정 = `qty > available` — includeDeducted가 아니어도 부분 차감 행에서 동작
- 차감된 행의 개수 표시는 `available` 그대로(0으로 덮지 않음) — 음수가 나오면 데이터 깨짐 신호가 화면에 드러난다(`lib/package-available.ts` 철학)
- 검증 에러(가용 초과 여러 줄)는 `whitespace-pre-line`으로 그대로 표시
- 엑셀 다운로드는 `includeDeducted` 무시(구조분해 안 함) — 종전과 동일 확인

## 2-1. 브라우저 검증 후 수정 라운드 (같은 날)

시안을 실 데이터로 확인하며 3라운드 돌았다. 시안(`재고차감-시안.html`)도 함께 갱신됐다.

| 라운드 | 지적 | 조치 |
|---|---|---|
| 1차 | 행 많으면 **푸터가 잘려 버튼 클릭 불가** | 🔴 `DialogContent` 기본이 `grid`라 92dvh에 맞춰 줄지 않았다 → `flex flex-col` + 본문 `flex-1`. **`repack-dialog`에도 같은 결함이 잠복**해 있어 함께 고침 |
| 1차 | 로트 줄바꿈 · 이력 간격 | 열 폭 확대 + 한 줄 고정, 이력 항목 여백 한 단씩 |
| 1차 | 되돌리기 후 빈 이력만 남음 | 마지막 항목 되돌리면 **자동 닫기**(토스트가 이미 알린다) + 헤더 「N개 중 M개」 실시간 갱신 |
| 1차 | 「문희준」이 누구인지 모름 | 「**작업자** 문희준」으로 라벨 |
| R1 | 같은 품종·규격이 9행씩 와서 **행 구분 불가** | ① sticky 컬럼 헤더 ② 생산자·포장일 ③ 로트 **앞말줄임**(뒷자리가 유일한 구분자) |
| R2 | 행이 왼쪽만 2줄이라 짜임새 없음 | 보조줄을 **컬럼으로 승격** — 6열 한 줄(품종·규격/생산자/포장일/로트/가용/개수). 데스크탑은 로트 자르지 않음(모바일만 앞말줄임) |
| R2 | 폰트·버튼 톤 | 표 13px(목록과 동일), 「전량으로 초기화」 outline |
| 최종 | **목록 바탕이 회색** | 🔴 `--background: #f1f5f9`(회색) + shadcn `bg-background` → 다이얼로그 카드가 통째로 회색. `bg-white` 명시로 해결. **전역 결함이라 백로그 §22에 기록** |

시안과 의도적으로 다르게 간 것 **1건**: 행 구분선을 시안 `#f1f5f9` → **`slate-200/60`**.
시안 값은 흰 배경에서 실제로 보이지 않아 「행간 줄이 전혀 없다」는 지적을 받았다. 목록 서브행이 이미 쓰는 톤이라 새 어휘는 아니다.
