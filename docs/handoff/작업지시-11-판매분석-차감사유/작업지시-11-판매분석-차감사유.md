# 작업지시 ⑪ — 판매분석 점검 · 모바일 · 원물출고 탭 / 재고차감 사유 기본값

시안: `시안/판매분석-차감사유-시안.html` (섹션 A-1 ~ B)

## A-1. PC 점검 (`sales-stats-client.tsx` · `_parts/`)
1. `sales-summary-cards.tsx`: 색 띠(`h-[3px]`)·점 제거. 이유: 판매량 파랑·개수 초록·주문 노랑이 옆 차트의 택배·서울급식·해남급식 색과 겹쳐서 채널을 뜻하는 것처럼 읽힌다. 카드는 4개 그대로 둔다.
2. 탭 끝에 구분선(`w-px h-4 bg-slate-200`)을 넣고 그 뒤에 「원물출고」 탭을 둔다.
3. `sales-breakdown-table.tsx`: 거래처 탭은 상위 20곳만 보이고, 아래에 「나머지 N곳 더 보기」 줄을 둔다. 엑셀은 전체를 내보낸다.
4. 빈 상태: 차트 자리에 「이 기간에 판매가 없어요」 + 「판매는 2026.10.01부터 기록되고 있어요」를 한 번만 띄운다. 요약 카드는 0(slate-300)으로 두고 표 카드는 숨긴다.

## A-2. 채널 색 (`sales-colors.ts` · `lib/purchase-channel.ts`)
- 이마트 `#4a3aa7` → **`#b9472a`(벽돌색)**. 나머지 5색은 그대로 둔다.
- 시안 안에서 계산한 참고값(ΔE2000, Machado 1.0): 택배↔이마트 45/54/50, 이마트↔서울급식 62/18/27. 이웃 쌍 최솟값은 지금과 같다(서울급식↔해남급식 제1색약 15.2). 이마트는 흰 바탕 대비 5.3:1이다. → 기존 검증으로 다시 돌려서 확정해 주세요.
- 채널 배지도 T1 대상이다. 배지 색 계열을 차트 색과 맞춘다.
  - 이마트 `bg-orange-50 text-orange-800`
  - 서울급식 `bg-emerald-50 text-emerald-700`
  - 해남급식 `bg-amber-50 text-amber-800`
  - 기업별 `bg-pink-50 text-pink-700`
  - 택배는 그대로 둔다.

## A-3. 모바일
- 필터: `stock-filter-sheet.tsx`와 같은 시트(탭바 위, z-50)로 한다. 카드 안에는 「기간 라벨 · 날짜 범위 · [조건 (N)] · 엑셀」 한 줄만 둔다.
- 탭: `md` 미만에서는 「별」을 뗀다 → 채널 · 거래처 · 품종 · 제품 | 원물출고 (`px-3 text-[13px]`). 이러면 약 300px라 360 폭에 들어간다.
- 순서: 요약(2×2) → 차트 → 목록. 지금은 차트가 먼저다.
- 차트: 일별 31개를 그대로 둔다. `maxBarSize` 20, 막대 사이 간격 20%로 하고 눈금은 1·8·15·22·29만 찍는다. 가로 스크롤이나 주별 강제는 하지 않는다.
- 표 → 두 줄 목록
  - 1줄: 순위 · 이름(거래처면 채널 점) · kg
  - 2줄: 비중 막대 · `N개 · 주문 N · %`
  - 거래처는 상위 20곳 + 더 보기.

## A-4. 원물출고 탭
- 탭 바로 아래에 안내 한 줄(`bg-amber-50/60`)을 둔다: 「벼 원물을 그대로 내보낸 기록이에요. 단위는 톤이고, 제품 판매(kg)와 따로 셉니다.」
- 필터는 기간과 목적만 둔다. 🔴 **이 탭은 기간을 따로 들고, 기본값은 「올해」다.** 「이번 달」로 두면 늘 비어 보인다.
- 차트: 월별 누적 막대
  - 판매 = 「원물판매」·「판매」, `#0f766e`
  - 판매 아님 = 종자·육묘장출고·톤백 빌려줌, `#cbd5e1`
- 요약 3장: 출고량(톤, 아래에 판매/판매 아님 내역) · 출고 건 · 출고처 곳
- 표: 출고처별/목적별을 토글로 바꾼다. 출고처 줄에는 목적 태그를 붙인다(판매 = teal-50/800, 그 외 = slate-100/600).

## B. 재고차감 사유 (`packages/deduct-dialog.tsx`)
1. `type` 상태를 `ManualMovementType | null`로 바꾸고, 열 때 `null`로 둔다.
2. 아무것도 안 골랐을 때
   - 칩: `border-dashed border-slate-300`
   - 「사유」 라벨 옆: 「하나 골라주세요」(text-[12px] slate-600)
3. `blockingReason`에 사유 미선택을 맨 앞에 추가한다. 이 경우만 **빨간 줄 대신 회색 한 줄**을 띄운다: 「사유를 고르면 차감할 수 있어요.」(slate-600). 푸터 제목은 「사유 미정」.
4. 거래처 칸은 늘 렌더한다. 판매가 아닐 때는 `disabled`, `bg-slate-100`, placeholder 「판매일 때만 적어요」. 「· 필수」는 판매일 때만 붙인다. 모바일도 `grid-cols-[132px_minmax(0,1fr)]`로 발생일과 나란히 둔다 → 아래가 밀리지 않는다.
5. 판매가 아닌 사유로 바꿔도 입력한 거래처 값은 버리지 않는다(다시 판매로 오면 복원). 서버로는 지금처럼 판매일 때만 보낸다.

## 다른 통계 화면에도 적용할 것 (판매분석 하고 나서)
- 요약 카드 색 띠·점: 재고분석(`stock-summary-cards.tsx`)도 같은 구조다. 차트 계열 색(`#0080c8`·`#8dc540`·`#f89c1e`)을 카드에 쓰고 있어서, 카드가 차트 범례처럼 읽힌다 → 판매분석과 같이 뺀다.
- 빈 상태: 재고분석 표 3곳이 「데이터가 없습니다」(slate-400)라서 ③ T3 대비 기준에 못 미친다 → 「이 조건에 맞는 재고가 없어요」(slate-500)로 바꾸고, 판매분석처럼 한 곳에서만 말한다.
- 모바일 표 → 두 줄 목록, 눈금 솎기: 도정·재고분석 모바일도 같은 기준으로 점검한다(이번 묶음엔 시안 없음).
- 탭 라벨: 모바일에서 「별」 떼기 규칙을 통계 화면 공통으로 한다.
