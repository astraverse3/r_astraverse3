# 작업 지시: admin 다이얼로그 색상 시스템 정렬

## 목표
admin 영역에 남아 있는 **레거시 액션색(녹색 `#8dc540`·`#7db037` / 시안 `#00a2e8`)** 을
디자인 시스템 토큰(`--primary` = `#2563eb`)으로 통일한다.
앱의 다른 화면(milling·raw-stocks·packages·sales·statistics)은 이미 `bg-primary`/`text-primary`로 마이그레이션 완료됐고, **admin 다이얼로그 3개만 동떨어져 있다.**

## 핵심 원칙
- `Button` 컴포넌트의 **기본 variant가 이미 `bg-primary text-primary-foreground hover:bg-primary/90`** 이다.
  → 녹색 버튼은 `className="bg-[#8dc540] hover:bg-[#7db037] text-white"` 를 **그냥 삭제**하면 자동 정렬된다 (다른 size/px 클래스는 유지).
- ⚠️ **통계 차트·realtime-status 막대·품종 구분 점의 녹색/시안은 "의미색"이라 건드리지 말 것.** 이번 작업은 **UI 액션색(버튼·포커스링·체크박스·아이콘 hover) 한정.**

## 치환 규칙
| 레거시 | → 교체 |
|---|---|
| `bg-[#8dc540] hover:bg-[#7db037] text-white` | (클래스 삭제 — Button 기본 variant 사용) |
| `focus:ring-[#00a2e8]/40` | `focus:ring-primary/40` |
| `accent-[#00a2e8]` | `accent-blue-600` |
| `text-[#00a2e8]` (아이콘/포커스) | `text-primary` |
| `hover:text-[#00a2e8]` | `hover:text-primary` |
| `hover:bg-[#00a2e8]/10` | `hover:bg-primary/10` |
| `focus:ring-[#00a2e8]` | `focus:ring-primary` |
