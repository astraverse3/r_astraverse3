# 작업 지시: 제품유형 카탈로그 — 벼/잡곡 탭 + 레이아웃 분리

대상: `app/(dashboard)/admin/product-types/product-type-page-client.tsx`
시안: `card-layouts/제품유형-벼잡곡탭-시안.html`
선행: `제품유형-색상정렬-작업지시.md` (색상 토큰 정렬) 먼저 적용 권장. 본 지시는 `bg-primary` 정렬 상태를 전제.

---

## 최종 구조 요약
**제품유형(SKU) 카탈로그** 섹션을 벼/잡곡 탭으로 분리하고, 탭마다 레이아웃을 다르게 한다.

| 탭 | 분류 | 레이아웃 | 도정 컬럼 |
|---|---|---|---|
| **벼** | `variety.category === 'RICE'` | **품종별 아코디언**(접기/펼치기) | 있음 |
| **잡곡** | `variety.category === 'MISC_GRAIN'` | **평면 테이블**(그룹화 X) | 없음(생략) |

- 잡곡은 규격이 한정적이라 그룹화 불필요 → 품종 컬럼 포함 평면 테이블.
- 탭 패턴은 `raw-stocks-tabs.tsx` / `packages-tabs.tsx`와 동일(`rice` | `misc`). 포장지 마스터 섹션은 탭 위/공통으로 그대로 둔다.

---

## 0. 데이터 — category 이미 들어옴
`listProductTypes()` 가 `include: { variety: true, packaging: true }` 라 **`variety.category`·`variety.type` 이 이미 응답에 포함**됨. 신규 쿼리·마이그레이션 불필요.
타입 선언만 확장:

```tsx
type ProductTypeRow = {
  id: number
  varietyId: number
  millingType: string
  packageType: string
  packagingId: number
  isDefault: boolean
  active: boolean
  variety: { name: string; category: string; type: string }   // ← category, type 추가
  packaging: { name: string; active: boolean }
}
```

## 1. 탭 상태 (client useState)
모든 데이터가 이미 client로 내려오므로 URL 라우팅 없이 `useState`로 충분.
(raw-stocks·packages와 완전 일치시키려면 `?tab=misc` URL 동기화 추가 가능 — 선택사항.)

```tsx
import { Wheat, Sprout } from 'lucide-react'

const [tab, setTab] = useState<'rice' | 'misc'>('rice')

const visibleTypes = productTypes.filter((r) =>
  tab === 'rice' ? r.variety.category === 'RICE' : r.variety.category === 'MISC_GRAIN'
)
const varietyCount = new Set(visibleTypes.map((r) => r.variety.name)).size
```

탭 바 (데스크탑 underline + 모바일 segmented는 `raw-stocks-tabs.tsx` 그대로 복제 권장. 간략형 ↓):

```tsx
<div className="flex items-center gap-1 border-b border-slate-200 mb-3">
  {([['rice','벼',Wheat],['misc','잡곡',Sprout]] as const).map(([v, label, Icon]) => {
    const on = tab === v
    return (
      <button key={v} type="button" onClick={() => setTab(v)}
        className={`relative inline-flex items-center gap-1.5 px-3.5 py-2 font-semibold transition-all ${on ? 'text-slate-900' : 'text-slate-400 hover:text-slate-600'}`}>
        <Icon className={`w-3.5 h-3.5 ${on ? 'scale-110' : ''}`} strokeWidth={on ? 2.4 : 1.8} />
        <span className={on ? 'text-[14px]' : 'text-[13px]'}>{label}</span>
        <span className={`absolute left-2 right-2 bottom-[-1px] h-[2.5px] rounded-full ${on ? 'bg-slate-900' : 'opacity-0'}`} />
      </button>
    )
  })}
</div>
```

## 2. 벼 탭 — 품종 아코디언
```tsx
import { getVarietyTypeLabel } from '@/lib/variety-labels'
import { ChevronDown } from 'lucide-react'

// 품종별 그룹 (가나다순)
const riceGroups = (() => {
  const m = new Map<string, ProductTypeRow[]>()
  for (const row of visibleTypes) {
    if (!m.has(row.variety.name)) m.set(row.variety.name, [])
    m.get(row.variety.name)!.push(row)
  }
  return [...m.entries()]
    .map(([name, rows]) => ({ name, type: rows[0].variety.type, rows }))
    .sort((a, b) => a.name.localeCompare(b.name, 'ko'))
})()

// 펼침 상태 (기본 전체 펼침)
const [openGroups, setOpenGroups] = useState<Record<string, boolean>>({})
const isOpen = (name: string) => openGroups[name] ?? true
const toggleGroup = (name: string) => setOpenGroups((s) => ({ ...s, [name]: !(s[name] ?? true) }))
```

렌더 (벼 탭일 때):
```tsx
<div className="flex flex-col gap-2">
  {riceGroups.map((g) => {

      <div key={g.name} className="rounded-lg border border-slate-200 overflow-hidden">
        <button type="button" onClick={() => toggleGroup(g.name)}
          className="w-full flex items-center justify-between px-3 py-2.5 bg-slate-50 hover:bg-primary/5 transition-colors">

            <ChevronDown className={`w-4 h-4 text-slate-400 transition-transform ${open ? '' : '-rotate-90'}`} />

                  <td className="py-2 px-3 text-right whitespace-nowrap">{/* 기존 수정/삭제 그대로 */}</td>

  {riceGroups.length === 0 && <p className="py-8 text-center text-xs text-slate-400">등록된 제품유형이 없어요.</p>}
</div>
```

## 3. 잡곡 탭 — 평면 테이블 (그룹화 X, 도정 컬럼 없음)
```tsx
<table className="w-full text-sm border-collapse">
  <thead>
    <tr className="text-left text-[11px] text-slate-400 border-b border-slate-200">
      <th className="py-2 px-2 font-medium">품종</th>
      <th className="py-2 px-2 font-medium">규격</th>
      <th className="py-2 px-2 font-medium">포장지</th>
      <th className="py-2 px-2 font-medium text-center">기본</th>
      <th className="py-2 px-2 font-medium text-center">상태</th>
      <th className="py-2 px-2 font-medium text-right">관리</th>
    </tr>
  </thead>
  <tbody>
    {[...visibleTypes]
      .sort((a, b) => a.variety.name.localeCompare(b.variety.name, 'ko'))
      .map((row) => (
        <tr key={row.id} className={`border-b border-slate-50 hover:bg-primary/5 transition-colors ${row.active ? '' : 'opacity-50'}`}>
          <td className="py-2 px-2 font-medium text-slate-800 whitespace-nowrap">{row.variety.name}</td>
          <td className="py-2 px-2 text-slate-600 whitespace-nowrap">{row.packageType}</td>
          <td className="py-2 px-2 text-slate-600 whitespace-nowrap">{row.packaging.name}</td>
          <td className="py-2 px-2 text-center">{row.isDefault && <Star className="w-3.5 h-3.5 text-amber-400 fill-amber-400 inline" />}</td>
          <td className="py-2 px-2 text-center">{/* 기존 상태 토글 버튼 그대로 */}</td>
          <td className="py-2 px-2 text-right whitespace-nowrap">{/* 기존 수정/삭제 그대로 */}</td>
        </tr>
      ))}
    {visibleTypes.length === 0 && (
      <tr><td colSpan={6} className="py-8 text-center text-xs text-slate-400">등록된 제품유형이 없어요.</td></tr>
    )}
  </tbody>
</table>
```

> 잡곡은 도정 컬럼 미표시. 등록 다이얼로그의 도정 구분은 잡곡 품종 선택 시 `'기타'` sentinel로 저장되므로 폼 동작은 변경 없음(원하면 잡곡 선택 시 도정 select 자동 '기타' 고정·비활성 처리는 별도 개선).
