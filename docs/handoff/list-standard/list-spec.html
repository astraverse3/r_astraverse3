목록 표준규격

목록 테이블 11곳의 헤더·행 스펙과 펼침 그룹 표현이 전부 달라 화면을 옮길 때마다 밀도와 색이 튑니다. 헤더·본문은 생산자 관리의 TableHead 기본값을, 펼침 그룹은 원물재고 잡곡의 slate 묶음톤을 정본으로 삼아 통일합니다.

헤더 40px · 14px / 500 / slate-900모든 행 44px · 본문 14px좌우 12px · 헤더 배경 slate-50컬럼 폭 % · 가로 스크롤 없음펼침 그룹 slate 묶음톤정렬은 페이지별 현행 유지데스크탑 먼저
기존 문서와의 충돌. handoff.md §4.2.3은 테이블 헤더를 text-[10.5px] uppercase tracking-wider text-slate-400 font-bold, 본문을 12.5px·px-4 py-2.5로 지정하고 있습니다. 그 값은 Typography의 Micro Bold(섹션 그룹 헤더) 토큰 — 영문 라벨("MAIN MENU")용입니다. 한글 헤더("품종", "생산자")에 uppercase·tracking-wider는 아무 효과가 없고 글자만 작아집니다. 이 문서를 정본으로 하고 §4.2.3을 개정하는 것을 전제로 작성했습니다 (개정안은 작업지시 R5).
