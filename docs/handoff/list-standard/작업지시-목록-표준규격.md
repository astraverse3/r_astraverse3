# 작업지시 — 목록 표준규격 통일 (데스크탑)

시안: `handoff/list-standard/목록-표준규격-시안.html`

## 배경

목록 테이블 11곳의 헤더/행 스펙이 전부 다르다. 헤더 폰트가 `text-sm`/`text-xs`/`text-[11px]`, 웨이트가 `bold`/`semibold`/`medium`, 좌우 패딩이 `px-1`/`px-2`/`px-3`/`px-5`로 섞여 있어 화면을 이동할 때마다 밀도가 튄다. 생산자 관리 목록의 여백감을 기준으로 통일한다.

## 결정 사항

- 밀도: **헤더 40px / 행 44px** (밀도 B)
- 헤더 텍스트: **13px / 700 / slate-500**, 배경 slate-50, 하단 border slate-200
- 본문 텍스트: **13.5px / slate-700**, 좌우 패딩 **12px (px-3)**
- 행 구분: **구분선만** (`border-b slate-100`) + 호버 `slate-50`. 짝수행 음영 없음
- **정렬은 페이지별 현행 유지** — 이번 작업에서 손대지 않는다
- sticky 헤더: 다이얼로그·긴 목록에만 적용 (현행 유지)
- **모바일 카드는 이번 범위 밖** — 별도로 다시 검토

## R1. 공통 프리미티브 정비

`components/ui/table.tsx`의 `TableHead` / `TableCell` 기본값을 표준으로 올린다. 각 목록에서 개별 클래스로 덧붙이던 것을 걷어내는 것이 목적.

```
TableHead: h-10 px-3 text-[13px] font-bold text-slate-500 whitespace-nowrap align-middle
TableCell: h-11 px-3 text-[13.5px] text-slate-700 align-middle whitespace-nowrap
TableRow:  border-b border-slate-100 hover:bg-slate-50 transition-colors
```

- 정렬은 기본값 없이 각 호출부의 `text-left/center/right`가 결정 (현행 유지 원칙)
- 체크박스·아이콘 전용 컬럼만 `px-1` 예외 허용
- 헤더 행 `<TableRow className="bg-slate-50 border-b border-slate-200 hover:bg-slate-50">`

## R2. 셀 클래스 규약

| 성격 | 클래스 |
| --- | --- |
| 텍스트 | 기본값 그대로. 대표값(생산자명·품종명)만 `font-bold text-slate-900` |
| 숫자·수량 | `text-right font-mono tabular-nums`. 합계·중량은 `font-bold text-slate-900` |
| 보조 숫자 | 년도·번호 등 참고값 `text-slate-400` |
| 로트번호 | `text-[12.5px] font-mono text-slate-600`, 컬럼 폭 ≥210px (자르지 않는다) |
| 인증 칩 | `text-[11.5px] font-semibold px-1.5 rounded-md border` · 유기=lime, 무농약=sky |
| 상태 배지 | `text-[11.5px] font-semibold px-2 rounded-full` · 테두리 없이 배경 톤만 |
| 액션 | 아이콘 버튼 `h-8 w-8 text-slate-400`, 호버 `text-primary bg-primary/10` |
| 그룹 헤더 행 | `bg-blue-50 text-blue-900 font-bold border-y border-blue-200`, 펼침 하위행 `bg-blue-50/30` |
| 빈 목록 | `h-32 text-center text-[13.5px] text-slate-400`, 문구 "OOO이 없습니다." |

## 검수 체크리스트

- [ ] 모든 목록의 헤더 높이가 40px, 본문 행이 44px로 측정되는가 (2줄 셀 예외 제외)
- [ ] 헤더 텍스트가 전부 13px/700/slate-500인가
- [ ] 로트번호가 어느 목록에서도 잘리지 않는가
- [ ] 짝수행 음영이 남아 있는 목록이 없는가
- [ ] 정렬이 기존과 동일한가 (이번 작업에서 바뀌면 안 됨)
