목록 표준규격

목록 화면 11곳의 헤더·행 스펙이 전부 달라 화면을 옮길 때마다 밀도가 튑니다. 생산자 관리 목록의 여백감을 기준으로 하나의 규격으로 묶습니다.

밀도 B · 표준정렬은 페이지별 현행 유지데스크탑 먼저 · 모바일 카드는 별도

1. 표준 토큰

모든 목록 테이블이 공유하는 값

헤더 배경slate-50하단 1px solid slate-200. 호버 없음

본문 텍스트13.5pxtext-[13.5px] text-slate-700
좌우 패딩12pxth·td 공통 px-3. 아이콘 전용 컬럼만 px-1
행 구분구분선만border-b slate-100 · 호버 시 slate-50. 짝수행 음영 없음
컨테이너r8 · slate-200rounded-lg border, shadow-sm, overflow-hidden
숫자tabular-nums수량·중량·로트·번호는 monospace + tabular
헤더 고정다이얼로그·장문만sticky top-0 z-10 + bg-white. 일반 목록은 미적용

bg-blue-50 text-blue-900 font-bold border-y border-blue-200 · 펼침 하위행 bg-blue-50/30
