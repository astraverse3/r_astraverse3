# 목록 표준규격 — 핸드오프

> **Claude Code 전달용.** 이 문서 → `list-spec-instructions.md` 순으로 읽으면 바로 적용 가능합니다.
> 시안 미리보기: `list-spec.html`

## 한 줄 요약

목록 테이블 **11곳**의 헤더·행 스펙과 펼침 그룹 표현이 전부 달라 화면 이동 시 밀도와 색이 튄다. `components/ui/table.tsx`를 정비하고, 각 목록에 흩어진 개별 클래스와 하드코딩 색을 걷어낸다.

## 정본

| 무엇 | 어디서 | 값 |
| --- | --- | --- |
| 헤더·본문 타이포 | 생산자 관리 (`admin/farmers/farmer-list.tsx`) | `TableHead` 기본값 `h-10 text-sm font-medium text-foreground` |
| 펼침 그룹 표현 | 원물재고 잡곡 (`raw-stocks/misc/misc-stock-list-client.tsx`) | slate 묶음톤 + 단일건 낱개 |

> 잡곡이 정본인 것은 **묶음톤과 단일건 낱개 패턴**입니다. 행 높이는 아닙니다 — 잡곡도 `h-12`를 갖고 있어 "모든 행 44px"에 맞춰 같이 고칩니다.

## 확정된 표준

| 항목 | 값 |
| --- | --- |
| 헤더 행 높이 | **40px** (`h-10`) |
| 헤더 텍스트 | **14px / `font-medium`(500) / `text-slate-900`**, 좌측정렬 |
| 헤더 배경 | `bg-slate-50` + 하단 `border-slate-200`, 호버 없음 |
| 본문 행 높이 | **44px** (`h-11`) — 그룹 헤더 행도 동일. 2줄 셀만 예외 |
| 본문 텍스트 | **14px / `text-slate-700`** (`Table`의 `text-sm` 상속) |
| 좌우 패딩 | **12px (`px-3`)** — 체크박스·아이콘 전용 컬럼만 `px-1` |
| 행 구분 | 구분선만 (`border-b border-slate-100`) + 호버 `bg-slate-50`. 짝수행 음영 없음 |
| 컬럼 폭 | `colgroup`에 **% 비율** + `table-layout:fixed`. 로트 컬럼 ≥24%. 가로 스크롤 없음 |
| 펼친 그룹 | 헤더+서브행 같은 `bg-slate-50/75`, 상단 `border-slate-200/80` |
| 접힌 그룹 | `bg-slate-50` + 상하 border. **흰 배경 금지** (낱개와 구분 안 됨) |
| 단일 건 그룹 | 그룹 헤더 없이 낱개 흰 행 |
| 숫자 | 수량·중량·로트·번호는 `font-mono tabular-nums` |
| sticky 헤더 | 다이얼로그·긴 목록에만 (현행 유지) |

## 적용 순서

1. **R1 — 공통 프리미티브 정비.** `components/ui/table.tsx` + 컬럼 폭을 `colgroup` %로 이전. 이걸 먼저 하지 않으면 R4에서 클래스를 걷어낼 때 스타일이 빠진 채로 남는다.
2. **R2 — 셀 클래스 규약 확인.**
3. **R3 — 펼침 그룹 통일.** 생산자관리의 `#00a2e8` 제거, 벼의 `h-12` 제거, 서브행 묶음톤 추가.
4. **R4 — 화면별 헤더 클래스 제거.** 7개 파일은 삭제, 4개 파일은 생 `<th>` → `ui/table` 교체.
5. **R5 — 문서 개정.** 저장소의 `docs/handoff/디자인시스템/` **1벌만** 개정. 잡곡 폴더엔 정본 안내 한 줄만 추가.

## 기존 문서와의 충돌 (중요)

`handoff.md §4.2.3`은 테이블 헤더를 `text-[10.5px] uppercase tracking-wider text-slate-400 font-bold`, 본문을 12.5px·`px-4 py-2.5`로 지정하고 있습니다. **이 표준과 정면 충돌합니다.**

그 값은 Typography의 **Micro Bold (섹션 그룹 헤더)** 토큰 — 영문 라벨("MAIN MENU")용입니다. 한글 헤더("품종", "생산자")에 `uppercase`·`tracking-wider`는 효과가 없고 글자만 작아집니다.

**결정: 이 문서를 상위 정본으로 하고 §4.2.3을 개정합니다** (R5).

이 패키지의 `handoff/handoff.md`·`handoff/design-system.html`에는 개정이 **이미 적용돼 있습니다** — 저장소 반영 시 그대로 예시로 삼으면 됩니다. 단 **저장소 쪽은 아직 옛 값**이므로 R5는 확인이 아니라 실작업입니다.

저장소에 `handoff.md`·`design-system.html`이 각각 2벌 있습니다. **`docs/handoff/디자인시스템/` 1벌만 개정**하고, `잡곡재고관리/`엔 정본 경로 안내 한 줄만 넣습니다 — 2벌 동기화가 이 불일치의 원인입니다.

§4.2의 CSS grid 마크업 자체는 유지하고 타이포·여백·묶음톤만 바꿉니다 — 펼침 포장재고는 `<table>`로 표현하기 어렵기 때문입니다.

§4.2.6의 NOTE는 이미 **"펼친 그룹의 시안톤 강조는 낱개 행과 섞이면 톤이 과해서 폐기했다"** 고 기록하고 있습니다. 그런데 생산자관리에는 여전히 `bg-[#00a2e8]/20`이 남아 있었습니다 — R3에서 제거합니다.

## 명시적으로 범위 밖

- **컬럼 정렬은 손대지 않습니다.** 같은 성격 컬럼이 페이지마다 좌/중앙으로 갈리는 문제는 남아 있지만, 이번엔 밀도·타이포·펼침 표현만 통일합니다. 기준선(텍스트 좌 · 숫자 우 · 상태·코드 좌)은 시안 2절에 기록해 뒀습니다.
- **모바일 카드.** 목록과 성격이 달라 별도 검토합니다. 대상: `mobile-package-card.tsx`, `misc-stock-table-row.tsx` 카드 모드, `farmer-list.tsx` 모바일 그룹, `stock-list-client.tsx` 모바일 카드.

## 주의

- 정렬이 바뀌면 회귀입니다. R4에서 클래스를 걷어낼 때 `text-right`는 **반드시 남겨 두세요.**
- `TableCell`의 `p-2`를 `px-3 py-0` + `h-11`로 바꾸지 않으면 행 높이 고정이 안 됩니다.
- 헤더 색은 연한 회색이 아니라 **진한 본문색**입니다. 스펙의 `text-slate-900`은 현행 기본값 `text-foreground`(#0f172a)와 같은 값이므로, 코드에서는 **`text-foreground`를 유지**하세요 — 새 하드코딩을 넣으라는 뜻이 아닙니다. 결과적으로 `TableHead` 변경은 `px-2` → `px-3` 하나뿐입니다.
- `*-table-row.tsx` 3개(`milling-table-row`, `stock-table-row`, `misc-stock-table-row`)를 빼먹으면 개별 `TableCell` 클래스가 프리미티브를 덮어써서 본문 44px가 무효가 됩니다.
- `#00a2e8`은 코드베이스에 31건 있지만 이 작업 범위는 **펼침 그룹 2건**입니다. 나머지 29건은 의미색이므로 건드리지 마세요.
- 접힌 그룹 헤더를 흰 배경으로 두면 낱개 행과 구분되지 않습니다.
- 로트번호 컬럼에 24% 미만을 주면 잘립니다.
- 감사 로그(`log-list.tsx`)의 셀 세로 구분선(`border-l`)은 표준에 없으므로 제거합니다.
