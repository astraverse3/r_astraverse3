## 한 줄 요약

목록 테이블 **11곳**의 헤더·행 스펙이 전부 달라 화면 이동 시 밀도가 튄다. `components/ui/table.tsx` 기본값을 표준으로 올리고 각 목록에 흩어진 개별 클래스를 걷어낸다.

## 파일

| `density-a-compact.html` / `density-b-standard.html` / `density-c-roomy.html` | 밀도 후보 3안 (**B 채택**, 나머지는 기록용) |

## 확정된 표준

| 항목 | 값 |
| --- | --- |
| 헤더 행 높이 | **40px** (`h-10`) |
| 헤더 텍스트 | **13px / 700 / slate-500** (`text-[13px] font-bold text-slate-500`) |
| 헤더 배경 | `bg-slate-50` + 하단 `border-slate-200`, 호버 없음 |
| 본문 행 높이 | **44px** (`h-11`) — 2줄 셀 행만 예외 |
| 본문 텍스트 | **13.5px / slate-700** |
| 좌우 패딩 | **12px (`px-3`)** — 체크박스·아이콘 전용 컬럼만 `px-1` |
| 행 구분 | 구분선만 (`border-b border-slate-100`) + 호버 `bg-slate-50`. 짝수행 음영 없음 |
| 컨테이너 | `rounded-lg border border-slate-200 shadow-sm` |
| 숫자 | 수량·중량·로트·번호는 `font-mono tabular-nums` |
| sticky 헤더 | 다이얼로그·긴 목록에만 (현행 유지) |

기준 페이지는 **생산자 관리**(`app/(dashboard)/admin/farmers/farmer-list.tsx`)입니다. 이 화면의 여백감이 그대로 표준이 됐고, 나머지가 여기에 맞춰 올라오거나 내려옵니다.

## 적용 순서

1. **R1 — 공통 프리미티브 정비.** `components/ui/table.tsx`의 `TableHead`/`TableCell`/`TableRow` 기본값을 위 표대로 올린다. 이걸 먼저 하지 않으면 R3에서 클래스를 걷어낼 때 스타일이 빠진 채로 남는다.
2. **R2 — 셀 클래스 규약 확인.** 지시서의 성격별 표를 기준으로 각 셀을 분류.
3. **R3 — 화면별 적용.** 7개 파일은 개별 클래스 삭제, 4개 파일은 생 `<th>` → `ui/table` 컴포넌트로 교체.

## 명시적으로 범위 밖

- **컬럼 정렬은 손대지 않습니다.** 같은 성격 컬럼이 페이지마다 좌/중앙으로 갈리는 문제는 남아 있지만, 이번엔 밀도·타이포만 통일합니다. 나중에 정리할 때의 기준선(텍스트 좌 · 숫자 우 · 상태·코드 중앙)은 시안 2절에 기록해 뒀습니다.
- **모바일 카드.** 목록과 성격이 달라 별도 검토합니다. 대상: `mobile-package-card.tsx`, `misc-stock-table-row.tsx` 카드 모드, `farmer-list.tsx` 모바일 그룹, `stock-list-client.tsx` 모바일 카드.

## 주의

- 정렬이 바뀌면 회귀입니다. R3에서 클래스를 걷어낼 때 `text-left/center/right`와 `w-[..]`는 **반드시 남겨 두세요.**
- 로트번호는 어느 목록에서도 자르지 않습니다. 컬럼 폭 ≥210px 확보.
- 감사 로그(`log-list.tsx`)의 셀 세로 구분선(`border-l`)은 표준에 없으므로 제거합니다.
- Tailwind 임의 값(`text-[13px]` 등)은 프리미티브 안에서만 쓰고, 호출부로 다시 퍼뜨리지 마세요.
