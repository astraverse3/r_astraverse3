## 1. D4 — 선택 모드 2종화

### `package-list-client.tsx`
- prop `selectMode?: boolean` → **`mode?: 'repack' | 'deduct' | null`**. 패널 두 곳도 같이 바꾼다.
- 동질성 제약은 **재포장 전용**:
```ts
isDisabled: row =>
    mode === 'repack' && anchorKey !== null && identityKey(row) !== anchorKey && !selected.has(row.id),
disabledReason:
    mode === 'repack' ? '품종·도정유형·출처가 같은 재고끼리만 함께 재포장할 수 있어요.' : '',
```
  차감은 **아무 행이나 함께** 고를 수 있다. `anchorLabel`도 repack일 때만 계산·표시.
- 차감 완료 행(`available <= 0`)은 두 모드 모두 `isDisabled` — 뺄 게 없다.
- 안내 문구(목록 위 11.5px slate-500) 분기:
  - repack: 「합칠·나눌 재고를 고르세요. 품종·도정유형·출처가 같아야 해요.」(현행 유지)
  - deduct: 「재고에서 뺄 항목을 고르세요. 사유와 발생일은 다음 단계에서 정합니다.」
- **선택 바** — 틀·위치·그림자는 그대로, 안쪽 문구·버튼만 분기:
  - repack: 「N건 선택 | 최대 M,MMMkg · (기준 라벨)」 + 「재포장하기」 (현행)
  - deduct: 「**N건** 선택 | **M개** · 총 K,KKKkg」 + 「차감하기」. 기준 라벨 없음
  - 모바일 pill도 동일 분기 — 「N건 선택 · M개」
  - 차감 개수 합계는 **가용 합**(`Σ row.available`) 기준. 실제 개수는 다이얼로그에서 정한다
- 다이얼로그 렌더 분기: `mode === 'repack' ? <RepackDialog…> : <DeductDialog…>`.
  `DeductDialog`에는 **행 객체 배열**을 넘긴다(`rows={selectedRows}`) — 다이얼로그가 품종·규격·로트·가용을 다시 조회하지 않게.

### 구조 (위→아래)
1. **헤더** — 「재고차감」 / 「고른 N건 M개를 재고에서 빼고 이력에 남깁니다」
2. **설정 영역**(`shrink-0`, `bg-slate-50/60`, `border-b`)

   - **발생일**(190px) + **거래처**(1fr, `type === 'SALE'`일 때만 렌더).
     라벨에 「· 판매일 때만」을 primary로 병기
   - 발생일이 오늘이 아니면 amber 11.5px 힌트: 「오늘(YYYY-MM-DD)이 아닌 **과거 날짜**로 기록됩니다. 묶음 하나에 날짜 하나예요 — 시기가 다르면 나눠서 실행하세요.」

3. **본문**(스크롤) — 「차감할 재고 N건」 + ghost `전량으로 초기화`
   행 그리드 `1fr 132px 54px 96px` = 품종·규격 / 로트(또는 매입 칩) / 가용 / 차감개수
   - 기본값 = **전량**(`available`)
   - `available === 1` → 입력 대신 「1개 전부」 텍스트
   - `0` → 행 `opacity-55` + 「제외」 회색 배지, 합계에서 빠짐
   - 상한은 `available`. 초과 입력은 그 행에 인라인 오류(재포장 `rowError` 패턴)
4. **인라인 확인**(§3) — 본문 맨 아래
5. **푸터** — 좌: 11px 볼드 「{사유}로 차감」 + 11.5px 「N행 · 발생일 · 거래처」, 그 옆 22px 볼드 `M개`.
   우: `취소`(outline) + `차감하기`(primary). 높이 `h-11 sm:h-8`

### 확인 단계 (N5 — 항상)
`confirmDialog()`를 띄우지 않는다. **다이얼로그 안에서** 해결(재포장 「손실 인정하고 진행」과 동형):
- `차감하기` 클릭 → `confirming = true`. 설정·본문은 `opacity-50 pointer-events-none`,
  푸터 `차감하기`는 disabled, 계기판 라벨은 「확인을 기다리는 중」
- amber 박스: 「**N행 M개**를 **{사유}**로 차감합니다. 발생일 YYYY-MM-DD · 거래처 ○○.
  차감한 재고는 목록에서 사라지고, 「차감된 재고 보기」를 켜야 다시 보입니다.」
  + `다시 고치기`(outline) / `확인하고 차감`(amber `bg-amber-700`)
- 입력이 하나라도 바뀌면 `confirming = false`로 되돌린다 (재포장 `lossConfirmed` 무효화와 같은 이유)

# R1 — 첫 구현본 점검 후 수정분 (2026-09-01)

`deduct-dialog.tsx` · `movement-history-dialog.tsx` 구현본을 실 데이터로 확인한 결과. 시안도 함께 갱신했다.

## R1-1 🔴 행을 서로 구분할 수 없다 — `deduct-dialog.tsx`

실 데이터는 **같은 품종·규격이 여러 행**으로 온다(실측: `새청무 · 5kg 백미` 9행). 구분자가 로트뿐인데
로트는 `251119-11-15103885-4118`처럼 **앞부분이 전부 같고**, 176px `truncate`가 **뒷자리를 잘라내** 서로 다른 로트가 같아 보였다. 어느 줄에 몇 개를 넣는지 판단할 수 없는 상태.

세 가지를 함께 넣는다(하나만으론 부족):

1. **컬럼 헤더를 스크롤에 고정** — 본문 첫 줄에 `sticky top-0 bg-white z-10` 헤더:
```tsx
<div className="sticky top-0 z-10 grid grid-cols-[1fr_148px_54px_110px] gap-x-2.5 border-b border-slate-200 bg-white pb-1.5 text-[10.5px] font-bold uppercase tracking-wider text-slate-400">
    <span>품종 · 규격 · 생산자</span><span>로트</span><span className="text-right">가용</span><span className="text-right pr-0.5">차감 개수</span>
</div>
```
2. **보조줄 추가** — 품종 줄 아래 `생산자 · 포장일자` (11px slate-400, `truncate`):
```tsx
<span className="mt-0.5 block truncate text-[11px] text-slate-400">{r.producer} · {r.date}</span>
```
   행 높이가 늘어나므로 로트는 데스크탑에서도 계속 별도 열에 둔다(모바일은 현행처럼 품종 아래 묶음 — 「가용 N · MM-DD」를 같은 줄에).
3. **로트는 앞말줄임** — 뒷자리가 유일한 구분자다. CSS `direction:rtl` 트릭은 숫자·하이픈에서 bidi 재배치 위험이 있으니 **문자열로 자른다**:
```tsx
const shortLot = (lot: string) => (lot.length > 16 ? `…${lot.slice(-14)}` : lot)
// <span title={lot}>{shortLot(lot)}</span> — title에 전체 로트 유지
```
   같은 규칙을 `movement-history-dialog.tsx` 헤더의 로트 칩에도 적용.

## R1-2 이력 헤더 구분자 — `movement-history-dialog.tsx`
`— {qty}개 중 …` → **`· {qty}개 중 …`**. 앞이 로트 칩이라 em dash가 떠 보인다.

## R1-3 이력 다이얼로그 오버레이
차감 다이얼로그보다 dim이 옅어 뒤 목록이 그대로 읽힌다. `DialogOverlay` 기본값을 덮어쓴 곳이 있는지 확인하고 **두 다이얼로그를 같은 dim**으로 맞춘다.

## R1-4 (선택) 푸터 요약 간격
좌측 라벨과 `78개`가 붙어 보인다. `gap-3` → `gap-5` 정도로.

# R2 — 실 데이터 스크린샷 점검 (2026-09-01)

R1 반영본을 실 데이터로 보니 **행이 왼쪽만 2줄**이 되어 오른쪽에 빈 공간이 크고 짜임새가 없다. 데스크탑은 폭이 남으므로 로트를 자를 이유도 없다.

## R2-1 행을 한 줄로 — 목록 테이블과 같은 컬럼 어휘

보조줄(`생산자 · 포장일자`)을 **없애고 컬럼으로 올린다**. 데스크탑 전용 그리드:

```
grid-cols-[1fr_.5fr_74px_158px_42px_110px]
품종·규격(도정) / 생산자 / 포장일 / 로트 / 가용 / 차감 개수
```
- 포장일은 `MM-DD` 12px slate-400 우측 정렬 (연도는 목록에서 확인 가능)
- 헤더는 R1대로 `sticky top-0` 유지, 라벨만 위 6개로 교체
- 모바일(`sm:hidden`)은 지금 구조 유지 — 품종 줄 + 아래 `로트 / 가용 N · MM-DD`

## R2-2 로트는 자르지 않는다

→ R1-3의 `shortLot()` 앞말줄임은 **데스크탑에서 되돌린다**(모바일 카드에서만 유지).
```tsx
// 데스크탑: white-space:nowrap, truncate 없음
className="rounded border border-slate-200 bg-slate-100 px-1.5 py-[1px] font-mono text-[10.5px] leading-4 text-slate-500 whitespace-nowrap"
```
`title={lot}`은 남겨둔다(비용 0).

## R2-3 본문 폰트 12.5px → 13px
목록 행(`package-row.tsx`)이 13px인데 차감 목록만 12.5px이라 작아 보인다. 이 영역은 입력 폼이 아니라 **표**이므로 목록 톤을 따른다. 사유·발생일·메모 등 **설정 영역은 12.5px 그대로**(재포장 관습).
