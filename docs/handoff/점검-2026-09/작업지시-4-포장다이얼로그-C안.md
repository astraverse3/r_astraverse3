## C1. 편집 행

```ts
- const MOBILE_EDIT_COLS = 'grid-cols-[1fr_128px_50px_40px]'
+ const MOBILE_EDIT_COLS = 'grid-cols-[1fr_108px_64px_28px]'
```
- 행 여백 `px-2 py-2 gap-1.5` → `px-2 py-1.5 gap-1`. 헤더 행도 같은 gap으로 맞춥니다.
- **규격+포장지 셀(`MobileSpecCell`)**: `h-10` → `h-9`. 아랫줄 `leading-4` → `leading-[14px]`.
  - **톤백**은 외곽선 박스 없이 한 줄 「톤백」(13px semibold)만 표시합니다. 지금은 윗줄과 아랫줄에 「톤백」이 두 번 나옵니다.
  - 잔량은 지금 모양을 유지합니다(윗줄 yellow + 「포장지 없음」).
- **스테퍼**: `h-10` → `h-9`. ± 버튼 `w-10` → `w-9`, 가운데 칸은 `flex-1`(약 36px).
- **중량**:
  - 입력칸(**톤백만**): 칸 폭 64px, `h-9 px-1.5`. 네 자리 + 여백이 들어갑니다.
  - **잔량**: kg 입력칸은 지금처럼 **스테퍼 자리(108px)**에 두고, 중량 칸에는 계산값을 표시합니다. 잔량은 수량이 늘 1이라서 스테퍼가 필요 없어요.
  - 계산값(그 외): 14px mono bold, 우측 `pr-1`.
- **삭제**: `h-10 w-10` → `h-9 w-7`. 아이콘 16px, 기본 `text-slate-400`, 누를 때 rose입니다. 행 오른쪽 끝이라 옆에 잘못 누를 대상이 없어서 폭을 줄였어요. 세로 36px은 유지합니다.

## C2. 입력칸 숫자 14px

- `MOBILE_INPUT`의 `text-base`(16px)를 `text-sm`(14px)로 바꿉니다. 스테퍼 가운데 숫자와 중량 입력칸 모두 해당합니다. 계속 mono bold입니다.
- **iOS 자동 확대 처리는 이번에 하지 않습니다.** 지금 `app/layout.tsx`에는 `maximumScale: 1, userScalable: false`가 있어서 확대가 일어나지 않아요. 처리 컴포넌트는 **② D4(확대 허용)를 할 때 함께** 넣습니다. 내용은 아래와 같고, §86에 기록해 두세요.
  - 작은 클라이언트 컴포넌트를 두고, **iOS일 때만** viewport meta에 `maximum-scale=1`을 덧붙입니다.
    ```ts
    // components/ios-input-zoom-fix.tsx ('use client', useEffect 1회)
    if (/iP(hone|ad|od)/.test(navigator.userAgent) || (navigator.platform === 'MacIntel' && navigator.maxTouchPoints > 1)) {
      const m = document.querySelector('meta[name=viewport]')
      if (m && !/maximum-scale/.test(m.content)) m.content += ', maximum-scale=1'
    }
    ```
  - 이유: iOS 10 이후로는 `maximum-scale`이 있어도 핀치 확대는 계속 됩니다. 막히는 건 입력칸 자동 확대뿐입니다. Android는 원래 자동 확대가 없고, 이 설정을 넣으면 핀치까지 막히기 때문에 iOS에만 적용합니다.
  - D4를 할 때 확인할 것: iPhone에서 톤백 중량칸에 포커스해도 확대되지 않고, 핀치 확대는 되는지. Android에서도 핀치 확대가 되는지.
  - 이 처리를 넣으면 ② D4의 「입력 필드 16px」 규칙은 전역에서 풀어도 됩니다. 다만 지금은 포장 다이얼로그만 14px입니다.

## C5. 하단 바 (편집 상태) — 두 줄을 한 줄로

```
[총 포장 / 1,091kg]              [🗑 초기화] [🔒 마감] [저장]
```
- 왼쪽: 「총 포장」 11px slate-500을 윗줄에, 숫자를 아랫줄에 16px mono bold로 둡니다. 「kg」은 12px slate-500입니다.
- 오른쪽 버튼은 모두 `h-10`, 간격 `gap-2`입니다.
  - **초기화**: ghost `text-rose-700`, 13px, 아이콘 13px. 문구는 「포장 초기화」에서 「초기화」로 줄입니다.
  - **마감**: `bg-amber-50 border-amber-200 text-amber-800`, 13px. 문구는 「작업 마감」에서 「마감」으로 줄입니다.
  - **저장**: primary, `px-4`, 14px semibold. 문구는 「기록 저장」에서 「저장」으로 줄이고, 불러오는 중·저장 중 문구는 지금처럼 둡니다.
- 초기화와 마감 사이는 `gap-2`(8px)이고, 초기화 버튼은 테두리 없이 글자만 있습니다. 누르면 기존 confirm이 뜨기 때문에 잘못 눌러도 안전합니다.
- 바 여백은 `pt-3 space-y-3` → `pt-2.5`입니다. **좌우 여백은 추가하지 않아요**(다이얼로그 본문 여백을 그대로 씁니다). 점선 구분선은 없앱니다.
- **폭 예산**(다이얼로그 360, 본문 약 328px): 총 포장 약 74(`12,345kg`) + 초기화 약 76 + 마감 약 68 + 저장 약 60 + gap 24를 합치면 약 302px라 여유는 약 26px입니다. 넘치면 **초기화를 아이콘만 있는 40×40 버튼**(`aria-label="포장 초기화"`)으로 먼저 줄이고, 글자 크기는 줄이지 마세요.
- **마감됨**과 **조회 전용** 상태도 같은 왼쪽 표기(두 줄 총 포장)를 쓰고, 오른쪽 구성은 ③ T3 그대로입니다.
- PC(`sm` 이상)는 지금 두 줄 구성을 유지합니다. `sm:` 접두로 나누세요.
