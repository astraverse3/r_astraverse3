# 작업지시 ② 디자인 토큰·기계적 정리 (P1)

> 대상 레포: `milling-log/` · 작성 2026-09-30

## D1. globals.css 죽은 토큰 정리

- `@theme inline`의 `--color-sidebar-*` 8개, `--color-chart-1~5` 5개 → `:root`에 정의 없음 + 사용처 0 → 삭제.
- `:root`/`.dark`의 `--sidebar-bg`, `--sidebar-fg`, `--sidebar-hover` → 사용처 0 → 삭제. (사이드바 색은 `desktop-sidebar.tsx`에 직접 지정돼 있음을 확인 후)
- `@layer utilities`의 `.glass`, `.glass-dark`, `.text-gradient`(stone 계열) → 사용처 0 → 삭제.
- `--destructive-foreground`는 정의만 있고 `@theme` 매핑 없음 → `--color-destructive-foreground` 추가.
- `--shadow-mobile-header`의 `rgba(99,102,241,…)`(indigo) → `rgba(15,23,42,0.06)`(slate-900).

**확인** — 삭제 전 `grep -r "sidebar-\|chart-\|glass\|text-gradient"` 결과 0건 재확인.

## D2. body 배경을 토큰으로

`app/layout.tsx` body:
```
- bg-gradient-to-br from-slate-100 to-slate-200 ... text-slate-900
+ bg-background text-foreground
```
그라데이션이 꼭 필요하면 `--background`를 쓰는 유틸로 옮긴다. `globals.css` base의 `body { @apply bg-background text-foreground }`와 중복되므로 클래스 제거만으로도 됨.
**확인** — 데스크톱/모바일 대시보드 스크린샷 전후 비교(미세한 명도 차만 허용).

## D3. 회색 계열 slate로 통일 (1:1 치환)

stone·gray → 같은 단계의 slate. 색상 계열만 바꾸고 단계 숫자는 유지.

| 파일 | 대략 건수 |
|---|---|
| `app/(dashboard)/milling/add-packaging-dialog.tsx` | ~40 |
| `app/(dashboard)/milling/new/page.tsx` | 2 |
| `app/(dashboard)/milling/close-batch-button.tsx` | 1 |
| `app/(dashboard)/milling/spec-summary.tsx` | 1 |
| `app/(dashboard)/raw-stocks/edit-stock-dialog.tsx` | 1 |
| `app/(dashboard)/raw-stocks/delete-stock-button.tsx` | 1 |
| `app/(dashboard)/admin/farmers/add-farmer-dialog.tsx` | 2 (gray) |
| `app/(dashboard)/admin/farmers/farmer-filters.tsx` | 1 (gray) |
| `app/login/page.tsx` | 1 (gray) |

정규식: `\b(text|bg|border|divide|ring|placeholder|hover:bg|hover:text)-(stone|gray)-(\d{2,3})\b` → `$1-slate-$3`.
**purple / violet / indigo는 건드리지 말 것** (③에서 결정).

## D4. 화면 확대 허용 (접근성)

`app/layout.tsx` viewport:
```
- maximumScale: 1,
- userScalable: false,
```
삭제. 입력 포커스 시 iOS 자동 확대가 문제되면 **입력 필드 글자만** `text-base sm:text-sm`(16px)로 올린다 — `components/ui/input.tsx`, `textarea.tsx`, `select.tsx` 트리거. 확대 차단으로 해결하지 말 것.
**확인** — iOS Safari에서 핀치 확대 가능 / 입력 포커스 시 확대 없음.

## D5. Pretendard 로딩

`globals.css` 첫 줄의 CDN `@import` → 렌더 블로킹 + 외부 의존.
- `pretendard` npm 패키지의 `PretendardVariable.woff2`를 `next/font/local`로 로드, `variable: '--font-pretendard'`.
- `@theme`의 `--font-sans` 첫 항목을 `var(--font-pretendard)`로.
- CSP `style-src`/`font-src`의 `https://cdn.jsdelivr.net` 제거(① S5와 함께).

**확인** — 네트워크 탭에 jsdelivr 요청 0건, 첫 화면 폰트 깜빡임 없음.
