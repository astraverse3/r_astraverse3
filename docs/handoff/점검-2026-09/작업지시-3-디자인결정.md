## T2. 타입 스케일 · 텍스트 명암

**스케일 (5단계, 이 외 금지)**

| 토큰 | px | 용도 | 텍스트 색 하한 |
|---|---|---|---|
| `text-caption` | 11 | 컬럼 헤더 · 단위(kg/개) · 보조 메타 | slate-500 (4.8:1) |
| `text-meta` | 12 | 뱃지 · 칩 · 소계 라벨 | slate-600 |
| `text-body-sm` | 13 | 모바일 표 본문 · 다이얼로그 본문 | slate-700 |
| `text-body` (=`text-sm`) | 14 | PC 표 본문 · 버튼 | slate-800 |
| `text-input` (=`text-base`) | 16 | 모든 입력 필드 | slate-900 |

**규칙**
- 11px 미만 금지. 흰/밝은 배경의 **텍스트**는 slate-500 이상. slate-300/400은 선·아이콘·비활성·플레이스홀더 전용.
- 예외: 진한 채움 위 흰 글씨(막대 그래프 안 % 등)는 11px + `font-bold` 허용. 그래도 공간 부족 시 막대 밖에 표기.

**구현**
1. `globals.css` `@theme`에 추가:
   ```css
   --text-caption: 11px;  --text-caption--line-height: 16px;
   --text-meta: 12px;     --text-meta--line-height: 16px;
   --text-body-sm: 13px;  --text-body-sm--line-height: 20px;
   ```
2. 일괄 치환 (정규식, 파일 단위 커밋):
   - `text-\[(8|9|10|10\.5|11)px\]` → `text-caption`
   - `text-\[(11\.5|12)px\]` → `text-meta`
   - `text-\[(12\.5|13)px\]` → `text-body-sm`
3. 치환된 요소 중 텍스트 색이 `slate-300|slate-400|stone-300|stone-400`이면 → `slate-500`. (아이콘·구분자 `·` `→` `-` 는 제외 — 사람이 확인)
4. 약 200곳. 우선순위: 포장 다이얼로그 → 원물재고 행 → 도정 모바일 카드 → 판매 매트릭스 → 대시보드 `realtime-status.tsx` → 나머지.

**주의** — `realtime-status.tsx` 막대 그래프(222–316)와 `matrix-head.tsx`는 폭이 빡빡함. 치환 후 넘침 확인, 넘치면 레이아웃 조정(글자 축소로 해결 금지).

**확인** — `grep -rE "text-\[[0-9.]+px\]" app components` 0건(의도적 예외는 주석). 모바일 390px에서 주요 화면 5곳 가로 넘침 없음.

## T3. 포장 등록 다이얼로그 — 모바일 터치 영역 (B안)

**대상** — `app/(dashboard)/milling/add-packaging-dialog.tsx` 모바일(`sm` 미만) 행. **PC(`sm` 이상)는 현재 레이아웃 유지.**

**변경**
1. **규격 버튼 그리드**: 높이 28px → **40px**, 글자 11px → 13px, gap 4→6px. `기타`는 점선 외곽선.
2. **행 구성** (1행 유지): `[규격+포장지 셀] [스테퍼] [중량] [삭제]`
   - 규격+포장지 셀: 높이 40px, 외곽선 박스 안 2줄 — 윗줄 규격(13px semibold), 아랫줄 포장지명(11px slate-500, 말줄임) + `▾`. 셀 전체가 포장지 선택 트리거. 잔량은 윗줄 `text-yellow-800`, 아랫줄 「포장지 없음」, 트리거 비활성.
   - 포장지명에서 규격 중복 제거(「친환경 10kg 지대」→「친환경 지대」) — 표시만, 데이터 변경 없음.
   - 스테퍼: 버튼 40×40, 가운데 숫자 48px 폭 16px mono bold, 하나의 외곽선 그룹.
   - 중량: 50px 우측 정렬, 13px mono bold. 단위 kg 생략(헤더에 표기).
   - 삭제: 40×40 아이콘 버튼, 기본 slate-500, 누를 때 rose.
3. **컬럼 헤더** (662–665): 9px stone-300 → `text-caption text-slate-500`. 「중량(kg)」.
4. **하단 고정 바**: 합계 `N / 예상 kg` + 저장 버튼 높이 44px.
5. 스테퍼 숫자 직접 입력은 기존처럼 유지하되 `inputMode="numeric"`, 16px.

**확인** — 390px 뷰포트에서 모든 탭 타깃 ≥40px, 가로 스크롤 없음. 규격 5개 행 추가 시 하단 바가 가려지지 않음.
