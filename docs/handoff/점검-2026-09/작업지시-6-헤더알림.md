# 작업지시 ⑥ — 헤더 알림(종) 1단계

시안 `시안/헤더-알림-시안.html` · 선행: ① S1(승인제, `countPendingUsers`) · ② 타입 토큰 · ③ T4
관련: 백로그 §83(T4 임시 뱃지 교체)

## 목표
승인 대기를 **헤더 종 아이콘 하나**로 알린다. 앞으로 알림 칸으로 키울 자리다.
1단계 알림은 **저장하지 않는다.** 요청 때마다 지금 상태를 보고 계산하고, 해결되면 저절로 사라진다. 읽음 개념은 없다.

## N1. 데이터 — `getHeaderNotifications()`
- 위치: `app/actions/notifications.ts`(신규) 또는 `lib/notifications.ts`(server-only)
- 반환: `{ items: { kind: 'pending-users'; count: number; href: string }[] }`
  - `pending-users`: ADMIN만 해당한다. `count = countPendingUsers()`, `href = '/admin/users'`
- `count === 0`인 항목은 **넣지 않는다.**
- 함께 반환: `eligible: boolean`. 해당 알림 종류가 하나라도 **있을 수 있는** 사람인지를 뜻한다(1단계에선 `role === 'ADMIN'`).
- `app/(dashboard)/layout.tsx`: 지금의 `pendingUsers` 계산을 이 함수로 바꾼다. 승인·삭제 뒤 `revalidatePath('/', 'layout')`는 이미 있으니 그대로 둔다.
- 다른 종류는 이번에 추가하지 않는다. 배열이라 나중에 kind만 늘리면 된다.

## N2. 아이콘 — `BellIcon` (duotone.tsx에 추가)
기존 `Base`·`active` 규칙을 그대로 따른다(stroke 1.8, active면 몸통 `currentColor` 채움).
```tsx
export function BellIcon({ active = false, ...props }: DuotoneIconProps) {
    return (
        <Base {...props} active={active}>
            <path d="M6 9.5a6 6 0 0 1 12 0c0 4.2 1 6.4 2.1 7.5H3.9C5 15.9 6 13.7 6 9.5Z" fill={active ? 'currentColor' : 'none'} />
            <path d="M10 20.2a2.3 2.3 0 0 0 4 0" />
            <path d="M12 3.5V2.6" />
        </Base>
    )
}
```
목록 타일 아이콘(승인 대기)은 lucide `UserPlus`를 쓰되, 시안처럼 채움형이 필요하면 같은 방식으로 `UserPlusIcon`을 추가한다(시안 `header-bell-parts.jsx`의 `HB_P.userPlus` 경로 참고).

## N3. 컴포넌트 — `components/header/header-bell.tsx`(신규)
props: `items`, `variant: 'mobile' | 'desktop'`

**트리거**
| | 모바일 | PC |
|---|---|---|
| 버튼 | 40×40 `rounded-full` | 32×32 `rounded-full` |
| 아이콘 | 20 | 18 |
| 색 | 1건 이상 `text-slate-600` · 0건 `text-slate-400` · 열림 `text-blue-600 bg-blue-50` + `active` | 같음 |

**뱃지** — 아이콘을 `relative` span으로 감싸고, 그 안에 붙인다. 버튼이 아니라 **아이콘 기준**으로 붙여야 모바일·PC에서 같은 자리에 뜬다.
- `absolute left-[calc(100%-8px)] -top-[7px] min-w-[18px] h-[18px] px-1 rounded-full bg-red-600 ring-2 ring-white`
- 글자: `font-mono text-[11px] font-bold leading-[18px] text-white text-center`
- 숫자는 items count의 **합**이며, 100 이상이면 `99+`로 표시한다. 합이 0이면 뱃지를 렌더하지 않는다.
- `aria-label`: 「알림 N건」 / 「알림 없음」

**목록** — PC는 `Popover`, 모바일은 `DropdownMenu`를 쓴다(기존 헤더 패턴과 맞춘다). 배경은 `bg-card`.
- 폭: PC `w-[340px]`, `align="end"` · 모바일은 화면 좌우 8px 여백(`w-[calc(100vw-16px)]`, `sideOffset=4`)
- 머리: h-11 · 「알림」 14 semibold slate-800 · 아래 `border-slate-100`
- 본문: `p-1.5`, 행 간격 2px, 넘치면 본문만 스크롤한다
- 최대 높이: PC 420 · 모바일 `calc(100dvh - 44px - 60px - 16px - 24px - env(safe-area-inset-bottom))`. 하단 탭바(z-40, 바닥에서 16px 띄움)와 겹치지 않아야 한다.
- **행**(`<Link>`, 누르면 목록을 닫고 이동)
  - 높이: 모바일 48 · PC 40 · `px-3 rounded-lg hover:bg-slate-50 gap-3` · 한 줄
  - 왼쪽 타일: 32×32 `rounded-lg bg-amber-50 text-amber-600`, 아이콘 17
  - 제목: 13 semibold slate-800. 숫자는 `font-mono`. 예) 「승인 대기 **2**명」
  - 오른쪽: `ChevronRight` 16 slate-400
- **빈 상태**(eligible인데 0건)
  - 44 원 `bg-slate-100 text-slate-400` + 체크 아이콘
  - 「확인할 알림이 없어요」 13 medium slate-700
  - 세로 여백 32

## N4. 배치
- **모바일** `components/mobile-header.tsx`: 오른쪽 묶음을 `종 · 아바타 · 톱니` 순서로 둔다. 셋 다 40×40 버튼이고 간격은 0(`gap-0`, `pr-1`)이다. 아바타(28)와 톱니(20)도 40 버튼 안 가운데에 놓는다.
- **PC**: 상단 바(h-12) 오른쪽 `종(32) · 세로 구분선(w-px h-5 bg-slate-200) · 프로필` 순서, `gap-2`.
- `eligible === false`면 종을 **렌더하지 않는다**(일반 사용자).
