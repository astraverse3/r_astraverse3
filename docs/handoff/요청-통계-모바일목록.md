## 먼저 끝낸 것 (1단계 `f4e773a`)

작업지시 ⑪ 끝 절 중 시안 없이 되는 것은 판매분석과 같은 값으로 이미 반영했다.

- 빈 상태: 차트 자리 한 곳에서만 말한다(slate-600)

- 모바일

## A. 모바일 두 줄 목록 (폭 360)

판매분석 목록(`app/(dashboard)/statistics/output/_parts/sales-breakdown-list.tsx`, 작업지시 ⑪ A-3)과 같은 결로 부탁한다.

- 1줄: 순위 · 이름 · kg
- 2줄: 비중 막대 · `N개 · 주문 N · %`

그런데 두 화면은 한 줄에 실을 값이 더 많다. 지금은 표가 가로로 스크롤된다.

### A-1. 재고분석 (`/statistics/stock`) — 표 3개

재고 = 그 연산(생산연도) 벼 원물. 한 원물은 셋 중 하나로 끝난다: **도정완료**(도정에 투입) · **직접출고**(원물 그대로 출고) · **미처리**(아직 창고).

| 탭 | 칸 | 줄 수(25년산 실측) |
|---|---|---|
| 생산자 | 생산자명 · 작목반 · 총 입고 · 도정완료 · 직접출고 · 미처리 · 재고율 | **119명**(이름은 2~3자) |
| 작목반 | 작목반명 · 인증(유기농/무농약/일반 배지) · 생산자수 · 총 입고 · 도정완료 · 직접출고 · 미처리 · 재고율 | 42곳(이름 최대 13자) |
| 품종 | 품종명 · 총 입고 · 도정완료 · 직접출고 · 미처리 · 재고율 | 22종 |

- 재고율 = 미처리 ÷ 총 입고. 낮을수록 좋다. 지금은 숫자 색으로 판정한다(≤20% 초록 · ≤50% 주황 · 그 위 빨강)
- 차트는 같은 세 갈래를 가로 누적 막대로 그린다(도정완료 `#8dc540` · 직접출고 `#8b5cf6` · 미처리 `#f89c1e`, 상위 20개)
- 26년산은 이제 막 입고 중이다(9/15~, 원물 15행). 화면을 처음 열면 기본이 최신 연산이라 한동안 줄이 적다

**정해 줄 것**
1. 둘째 줄을 **세 갈래 막대**(도정/출고/미처리 비율)로 할지, **숫자 세 개**로 할지
2. 재고율을 어디에 어떻게 둘지. 지금은 판정을 숫자 색으로만 한다
3. 생산자 119명: 판매분석처럼 「상위 N + 더 보기」로 할지, 다 보여 줄지. 세 표 모두 지금은 **총 입고 많은 순**이다
4. 작목반 줄의 인증 배지 · 생산자수 자리

### A-2. 수율분석 (`/statistics/milling`) — 도정 기록 표 1개

| 칸 | 내용 |
|---|---|
| 날짜 | `yyyy-mm-dd` |
| 도정종류 | 백미 · 현미 · 오분도미 · 칠분도미 · 기타(배지) |
| 품종 | 「새청무」 또는 여러 품종 |
| 생산자 | 「김○○ 외 3명」으로 줄여 보임 |
| 투입량 kg | **누르면 투입 원물 상세 팝업** |
| 생산량 kg | **누르면 포장 내역 팝업** |
| 수율 % | 기준값 대비 판정 색 배지(`getYieldLevel` — 도정구분·품종 2축) |
| 비고 | 한 줄 말줄임 |

- 줄 수: 최근 6개월(기본 기간) **120건**, 전체 205건
- **머리글을 눌러 정렬**한다(기본 날짜 내림차순). 목록으로 바꾸면 정렬 수단이 사라진다
- 같은 화면 위쪽 탭(기간·품종·도정구분)은 차트만 바꾸고, 이 표는 그대로다

**정해 줄 것**
1. 두 줄 배치: 1줄 날짜·도정종류·수율, 2줄 품종·생산자·투입→생산? 아니면 다른 배치
2. 투입·생산 팝업을 어디서 여는지(줄 전체 탭? 숫자만?)
3. 정렬: 모바일에서 뺄지, 정렬 칩(날짜 · 수율 · 생산량)을 둘지
4. 120건 — 다 보여 줄지, 더 보기로 할지

## B. 보라 칩 (작업지시 ③ T1 잔여 — 같은 두 화면)

T1(보라 계열 금지)이 아직 이 두 화면의 **필터 칩**에 남아 있다.

| 화면 | 자리 | 지금 |
|---|---|---|
| 재고분석 | 「생산자」 검색 칩 · 입력칸 | `bg-purple-50 text-purple-700` |
| 수율분석 | 「도정구분」 칩 · 시트 선택 | `bg-purple-50/500` |

- 문제: 필터 칩이 조건마다 다른 색이다(재고분석은 인증 teal · 작목반 blue · 품종 green · 생산자 purple)
- T1의 「필터 칩은 blue」로 바꾸면 작목반 칩과 같은 색이 된다
- 조건별 색을 유지할지, 전부 한 색으로 갈지 정해 주세요
- 재고분석 표의 직접출고 숫자는 보라 글자(`#7c3aed`)다. 표 숫자를 계열 색으로 칠하는 것을 그만둘지도 같이 부탁한다(도정완료 초록 · 미처리 주황도 같은 방식)
- 차트 계열 색(`#8b5cf6`)은 9/30 사용자 결정으로 T1 「해당 없음」이다. 이번 범위가 아니다
