## 2026-08-18 (5) — 모바일 채널별 모드 3종 (잠정 확정)
모바일 「전 채널 공통」 주장을 실제 데이터로 검증 → **깨짐**. 채널마다 행렬 모양이 상이함:
- 택배 14열×20행+ / 이마트 5열×3행 → **현행 OK**
- 서울급식 13열×2행 / 해남급식 10열×2행 → 행이 2개인대 화면이 가로 스크롤에 지배됨
- 기업별 1열×1행 → 셀 1개에 행·열 머리글이 화면 절반

**결정: 모바일은 데이터 모양으로 3모드 자동 판정**(채널 이름으로 분기 안 함 — 같은 채널도 파일마다 모양이 달라짐):
1. **카드 모드** — 수령처 ≤ 2 && 규경 ≤ 2 (기업별). 표 없이 규경별 카드 n장.
2. **전치 매트릭스** — 수령처 ≤ 3 && 규경 ≥ 6 (급식). 행=규경, 열=수령처. 가로 스크롤 제거.
3. **표준 매트릭스** — 그 외 (택배·이마트). 기존 확정판 그대로.

전치 시 유지: 셀 탭→FIFO 시트, 부분 표시(가용 열이 매 규경 행에), 일괄 차감은 열 머리글(수령처) 탭, 합계는 규경별 개수+전진 kg 둘 다.

상태: `모바일-채널별케이스점검.html` 제작(프레임 4 + 판정 그리칙 노트). `건처리-매트릭스-모바일.html` 표기를 「전 채널 공통」→「표준 모드」로 정정. 경계값(2/3/6)은 실제 파일 높어나면 재조정 필요 — **잠정 확정**.

- 개발 주의: 부분 예상 산정은 `suggestAllocation` **dry-run 재사용**(실제 차감 로집과 동일해야 함). 확정 시 재계산 → 검토 시점과 다를 시 조용한 부분차감 금지, 재검토 유도.
