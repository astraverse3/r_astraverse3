택배 매트릭스와 같은 문법으로 통일: 세로축 = 수령인, 가로축 = 품목 규격, 셀 = 발주 수량. 공장동 시트가 원래 이 모양이라 원본과 1:1로 대응됩니다. 헤더 아래 규격별 소계 띠에 가용 재고 대비 부족 규격을 주황색으로 표시 — 상품재고 관점을 한눈에. 특수 사항(보관요청 등)은 재고 차감으로 모델링하지 않고, 업로드 시 입력하는 비고(전달사항)로 상단에 표시합니다.
