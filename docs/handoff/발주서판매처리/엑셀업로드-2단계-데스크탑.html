행 클릭은 이번 단계에서 비활성 — 매트릭스(D2) 연결 후 활성화. 같은 파일에서 온 시트는 파일명 서브라벨로 묶어 보입니다.

이전 시안에서 바뀐 것
  • 파싱 요약 1블록 → 시트 표. 파일 1개 = 묶음 1건 전제가 사라져 「채널·날짜·발주처」를 한 덩어리로 보여줄 수 없음.
  • 전달사항 1개 → 시트별 비고. 체크한 시트 아래로 펼쳐지는 인라인 textarea. 상한 200 → 500.
  • 목록 1열이 파일명 → 시트명. 파일명은 서브라벨로 내려 같은 파일 출신을 알아볼 수 있게.
  • 행 링크 제거. D2까지 비활성 — 커서·호버 배경도 함께 뺐습니다.
  • 경고는 등록을 막지 않는다는 규칙이 표에서 읽히도록, 경고(노랑 칩)와 체크 불가(회색 행)를 다른 시각 언어로 분리했습니다.
