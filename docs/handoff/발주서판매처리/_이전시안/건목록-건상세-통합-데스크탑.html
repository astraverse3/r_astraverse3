건 목록 + 건 상세 — 좌우 통합 (데스크탑)

화면2(건 목록)와 화면3(건 상세)를 한 화면 마스터-디테일로 합친 안. 좌측 건 목록에서 건을 고르면 우측에 그 건의 라인 테이블이 바로 펼쳐져, 묶음 → 건 → 라인을 페이지 이동 없이 오간다. 택배처럼 건이 100개를 넘으면 좌측 목록은 검색 + 상태 세그먼트(작업 필요 기본)로 좁혀 처리할 건만 본다. FIFO 배분은 라인 클릭 시 그 행 아래로 인라인 확장 — 세 번째 고정 컬럼 없이 한 화면에서 차감까지.
