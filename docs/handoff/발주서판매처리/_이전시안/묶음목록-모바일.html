구조 노트

묶음 = 업로드 1건 (단일 채널)
현 업무 프로세스상 한 번에 한 채널만 업로드 → 묶음마다 채널 배지로 식별. 시트명 prefix로 시스템이 분류.

행 데이터
UploadSummaryRow: 파일명 · createdAt · orderCount건. 채널은 묶음 내 건들의 공통 채널. (업로드자 이름은 공장용 지시서에 불필요 → 제외)

상태 카운트 + 진행 바
statusCount 완료·부분·대기 칩(0이면 숨김) + 하단 진행 바로 처리율 시각화.

매칭실패 배지
unmatched>0 빨강 칩 강조 → 건 상세에서 수동지정 유도.

채널·기간 빠른 필터 + 검색
헤더 아래 채널 칩(전체·급식·택배·이마트·기업별)으로 즉시 필터. 검색(blue-50·SlidersHorizontal — 기존 화면 동일 컨벤션)은 기간·복합 조건 다이얼로그.

행 메뉴(⋮): 엑셀 다운로드 / 묶음 삭제(deletePurchaseUpload — 차감된 movement 있으면 비활성). 행 탭 → 건 목록(화면2).
