헤더 카운트 → 진행바
「12완료·1부분·3대기·1실패」 텍스트를 색 진행바 + 12/17 · 작업 5 한 줄로. 끝났는지/얼마 남았는지만.

기본은 전부 접힘
미리 펼쳐 두지 않음. 작업 5줄 + 완료 1줄만 보여 17라인도 한 화면. 탭한 라인만 패널이 열림.

두 그룹뿐
「작업 필요 5 / 완료 12」. 상태별 칩·테두리 색을 줄이고 좌측 점 + 차감/주문으로 통일.

펼침 패널(FIFO·수동지정)은 C안과 동일 — 진입 시점만 사용자가 정함. 이 방향이면 데스크탑까지 확장.
