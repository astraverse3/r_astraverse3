세 가지 모드를 데이터 모양으로 자동 선택

채널 이름으로 분기하지 않습니다 — 같은 채널도 파일에 따라 모양이 달라지므로 행·열 개수로 판정합니다. 데스크탑은 폭이 넉넉해 항상 매트릭스 그대로.

① 카드 모드 — 수령처 ≤ 2 && 규격 ≤ 2
기업별. 표 없이 규격별 카드 n장.
② 전치 매트릭스 — 수령처 ≤ 3 && 규격 ≥ 6
급식(서울·해남). 행=규격, 열=수령처. 가로 스크롤 제거.
③ 표준 매트릭스 — 그 외
택배·이마트. 행=수령처, 열=규격 + 좌우 고정(현행 확정판).

경계값은 실제 파일로 조정 필요 — 위 숫자는 현재 시안 5종(택배 14×20+, 이마트 5×3, 서울급식 13×2, 해남급식 10×2, 기업별 1×1)을 정확히 가르는 최소 규칙입니다.

전치 시 유지해야 하는 것

  • 셀 탭 → FIFO 배분 바텀시트 — 축이 바뀌어도 셀의 의미(수령처×규격 주문량)는 동일.
  • 부족 표시 — 표준 모드의 「가용 재고 띠」가 전치에서는 각 규격 행의 가용 열이 됩니다(주황=부족).
  • 일괄 차감 진입 — 표준은 수령처 이름 탭, 전치는 열 머리글(수령처) 탭으로 같은 시트를 엽니다.
  • 합계는 축과 무관하게 규격별 개수 · 전체 kg 둘 다 노출.

확정 시 문서 정리

확정하면 건처리-매트릭스-모바일.html의 「전 채널 공통」 표기를 「표준 모드(택배·이마트)」로 바꾸고, 전치·카드 모드를 같은 파일에 프레임으로 합치겠습니다. 개발 착수 전 이 규칙만 합의하면 됩니다.
