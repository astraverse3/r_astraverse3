- **D5의 「열은 원본 열」을 뒤집음**(사용자: 「화면처럼. 나중에 회의하겠지만 이 방향으로」)

## 4. 확인이 필요한 사항

1. **다운로드 확인**: 택배 시트 ⋮ 「엑셀 다운로드」 → 머리글 병합 · 포장지 줄 · 로트번호가 잘려 보이는 정도가 괜찮은지
2. 원본 품목명(`유기농 천지향`)은 엑셀에서 빠진다(매칭실패 열 제외). 회의에서 필요하다고 나오면 셀 메모로 붙일 수 있다
3. 하단 안내문 「원본에서 주문이 0인 행·열…」은 그대로 뒀다 — 여전히 맞는 말이지만, 이제 열이 원본 열이 아니라서 회의 때 문구를 다시 볼 만하다
