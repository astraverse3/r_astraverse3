# 계획서: 도정 포장 「포장지 미지정」을 없앤다 — 기본 포장지로 (백로그 §54)

- 작성: 2026-09-30
- 상태: **승인 대기**
- 발단: 사용자 「미지정 아직 나오는데?」 → 「SKU 지정 안 된 건은 수정 후에 기본 포장지로 채워 넣자」

## 1. 목표

1. **앞으로** 도정 포장에 SKU(포장지) 없는 줄이 저장되지 않게 한다 — 기본 포장지가 있으면 자동으로, 없으면 사람이 고를 때까지 저장을 막는다.
2. **이미 저장된** 미지정 줄을 기본 포장지로 채운다(소급).

미지정 줄은 발주서 판매처리가 SKU로만 찾기 때문에 영영 「재고 부족」으로 뜬다.

## 2. 지금 「미지정」이 보이는 경우 (2026-09-30 확인)

| 경우 | 원인 | 이번 처리 |
|---|---|---|
| 포장지 목록을 불러오는 동안 | 선택지가 없어 브라우저가 첫 옵션을 보여줌 | ✅ 해소(`2ed5a84`·`839d18a`, 회전 아이콘) |
| **새 줄을 추가한 직후** | 줄을 먼저 `packagingId: null`로 그리고 기본 포장지 추천(`suggestProductType`)이 오면 채운다(:435-455) | 추천 대기 중엔 회전 아이콘 |
| **그 규격에 기본 SKU가 없을 때** | 추천이 비어 미지정으로 남고, 그대로 저장된다 | 「포장지 선택」 안내 + **저장 막음** |
| **이미 미지정으로 저장된 줄** | 위 경우가 쌓인 것 — 22줄 / 배치 12개(전부 마감) | 소급 채우기(4장) |

## 3. 변경 범위 — 앞으로

| 파일 | 변경 |
|---|---|
| `app/(dashboard)/milling/add-packaging-dialog.tsx` | ① 추천 대기 중인 줄(키=규격+stockId)은 포장지 칸에 회전 아이콘 ② 드롭다운에서 **「포장지 미지정」 선택지 삭제** — 값이 없으면 비활성 안내 「포장지 선택」 + 칸 테두리 강조 ③ 저장 검증: 일반 규격(톤백·잔량 제외) 줄에 포장지가 없으면 막고 「10kg 줄의 포장지를 골라 주세요」 |
| `app/actions/milling.ts` `updatePackagingLogs` | 서버도 같은 규칙으로 거부 — 화면 검증과 한 쌍(낡은 화면·다른 탭에서 와도 막힌다). 지금은 `packagingId === null`이면 SKU 없이 통과한다(:705-706 부근) |
| `lib/`(순수 함수 1개) + 테스트 | 「포장지가 필요한데 없는 줄」 판정 — 화면·서버가 같은 함수를 쓴다. 톤백·잔량 예외 |

- 톤백은 서버가 「톤백」 포장지를 강제하니 그대로, 잔량은 SKU 없음이 정상이라 그대로
- PC·모바일 공용 행이라 둘 다 적용된다
- 🔴 저장·diff·baseline(9/1 사고 대책)은 건드리지 않는다 — 검증 한 단계를 앞에 더할 뿐

## 4. 기존 미지정 줄 — 소급

`scripts/backfill-product-type.ts`(6/22에 쓴 멱등 스크립트, 기본 SKU `isDefault·active` 주입) dry-run 결과(2026-09-30):

- **20줄** — 기본 SKU가 있어 바로 채워진다
- **2줄은 기본 SKU가 없어 못 채운다**
  - 서농22호 / 백미 / 10kg (pkg#1434)
  - IPS / 현미 / 20kg (pkg#1453)
  → 제품유형 관리에서 이 두 조합의 **기본 SKU를 등록**한 뒤 스크립트를 다시 돌리면 채워진다(사용자 결정)

순서: 코드 수정·검증 → `--apply`(운영 DB) → 남은 2줄 → 재실행. 🔴 배포가 도는 동안엔 돌리지 않는다. auto mode가 막으면 사용자가 직접 실행.
