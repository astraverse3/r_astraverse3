# 백로그 §48 — 만들 규격 버튼에 SKU 규격을 더한다

## 1. 목표

재포장·도정 포장에서 **그 품종·도정의 SKU에 등록된 규격**(IPS 백미 907g 등)을 버튼으로 고를 수 있게 한다.
지금은 두 다이얼로그 모두 고정 목록이라, 907g 주문은 매칭은 되는데 재고를 만들 길이 없어 늘 「재고없음」이다.

## 2. 코드 대조 결과 (구현 전)

| 확인 | 결과 |
|---|---|
| 서버가 규격을 막나? | **안 막는다** — 재포장(`createRepack`)·도정(`milling.ts`) 둘 다 규격 문자열·단중을 그대로 받고, SKU는 품종+도정+규격+포장지로 `findOrCreateProductType` |
| 막는 곳 | 화면 버튼뿐 — `lib/repack.ts` `REPACK_SPECS` · `milling/packaging-constants.ts` `PACKAGE_TEMPLATES` |
| 버튼에 없는 SKU 규격(실측) | 벼 **2** — IPS 백미 907g · 서농22호 현미 800g / 잡곡 5 — 발아현미·흑미 800g, 귀리·흑미 500g, 귀리 420g |
| 잡곡 입력 다이얼로그 | 자체 목록에 800g·500g·420g이 **이미 있다** → 이번 범위 밖 |
| 합계 밴드 정렬 | 템플릿에 없는 규격은 **뒤로** 보낸다(`spec-summary.tsx:31`) — 버튼만 늘려도 안 깨진다 |
| 🔴 도정 「기타」 직접입력 | `0.907` → 규격 **`0.907kg`** 으로 저장 → SKU `907g`과 **이름이 달라 SKU가 하나 더 생긴다**. 현재 DB엔 그런 SKU 없음(피해 0) |
| 중량 파서 | `normalizeSpec`(`907g`→0.907)이 **엑셀 파서 파일**(xlsx import)에 있다 — 다이얼로그가 끌어오면 번들에 xlsx가 딸려 올 수 있다 |

## 3. 결정

### A. 고정 목록 **+** 그 품종·도정 SKU 규격 (추천)

- 기존 버튼은 그대로 두고, **목록에 없는 SKU 규격만 끼워 넣는다**(무게 내림차순 자리에 — 907g은 1kg 뒤·잔량 앞)
- SKU 범위는 **소스(재포장)·로트 그룹(도정)의 품종 + 도정**, 활성 SKU만
- 새 규격이 필요하면 → 제품유형 관리에 SKU를 등록 → 버튼이 저절로 생긴다. **SKU 카탈로그가 규격의 원천**이 된다
- ❌ 대안 「SKU 규격만 보여준다」: 그 품종에 SKU가 없는 기존 규격(예: 8kg)을 못 만들게 된다 — 지금은 만들면서 SKU가 자동 생성되는 흐름이라 동작이 바뀐다

### B. 중량 파싱 한 벌

`lib/package-spec.ts`(신규, 의존성 없음)에 `specWeightKg('907g') → 0.907`을 두고,
`normalizeSpec`은 이걸 부르게 바꾼다 — 규칙은 한 곳, 다이얼로그는 xlsx 없이 쓴다.

### C. 범위 — 재포장 + 도정 포장 둘 다 (추천)

사용자 발견은 재포장이지만 도정 포장도 **같은 벽**이고, 게다가 우회로(「기타」)가 **잘못된 SKU를 만든다**.
한쪽만 고치면 도정 쪽에서 `0.907kg` SKU가 생기는 날이 온다.
- ⚠️ `add-packaging-dialog.tsx`는 이미 **833줄**(상한 800 초과). 저장·diff 로직은 건드리지 않고 **버튼 목록 한 곳**만 바꾼다(+10줄 안팎). 분리는 별도 작업
- 도정 「기타」 입력을 `907g` 꼴로 저장하게 바꾸는 건 **이번엔 안 한다**(버튼이 생기면 우회할 이유가 없다) — 백로그에 남긴다

## 5. 확인 항목 (브라우저)

1. IPS 백미 재고 → 재포장 → 버튼에 **907g**(1kg 뒤) → 누르면 단중 0.907 · 포장지 「인디카라이스」 자동 → 저장 → 제품재고에 907g 행, **SKU 89**로 붙는지
2. 서농22호 현미 재포장 → **800g** 버튼
3. 다른 품종(예: 천지향) 재포장 → 버튼이 **예전 그대로**
4. 도정 포장 다이얼로그 — IPS 백미 배치에서 907g 버튼 · 다른 품종은 그대로 · 규격별 합계 밴드 정상
5. 발주서 IPS 907g 줄이 재고가 생긴 뒤 「대기」로 바뀌는지
