# 제품재고 목록 — 포장지 열 추가

작성 2026-10-01

## 발단

사용자: 「제품재고 목록에 포장지 열 추가 (포장지 확인할 방법이 없어)」

## 지금

- 재고 한 줄의 정체는 **품종·규격·단중·포장지 4축**이다(백로그 §19). 그런데 목록에는 포장지가 없다. 같은 「서농22호 10kg」이 자연주의인지 PP마대인지 화면에서 구분이 안 된다.
- 포장지는 `MillingOutputPackage.productTypeId → ProductType.packaging.name`에 있다. 잔량은 `productTypeId = null`이다(SKU 없음). 잡곡 매입은 sentinel `'매입포장'`을 가리킨다.

## 사용자 결정 (2026-10-01)

- PC: **규격 바로 왼쪽**에 「포장지」 열을 추가한다.
- 엑셀에도 「포장지」 열을 넣는다(마찬가지로 규격 왼쪽).

## 변경 범위

| 파일 | 내용 |
|---|---|
| `app/actions/packages.ts` | `PackageRow`에 `packaging: string \| null` 추가 · `getPackages` include에 `productType.packaging.name` 추가 · `exportPackages` 헤더/행에 「포장지」 추가 |
| `app/(dashboard)/packages/package-row.tsx` | `PKG_GRID`/`PKG_GRID_SELECT`에 열 하나 추가 · 헤더 · 낱개 행 · 서브행 · 그룹 행(「—」) |
| `app/(dashboard)/packages/mobile-package-card.tsx` | 모바일 카드에도 포장지를 보여준다(아래) |

## 표시 규칙

- 포장지 이름을 그대로 쓴다. 없으면(잔량·SKU 없음) 「—」를 쓴다.
- 잡곡 매입의 `'매입포장'`은 저장된 값 그대로 「매입포장」으로 보여준다. 숨기면 「포장지가 없다」와 구분이 안 된다.
- 그룹 행(품종 묶음)은 포장지가 섞일 수 있어서 로트·도정구분과 같이 「—」로 둔다.
- 열 폭: 규격(0.5fr)보다 조금 넓은 0.7fr로 시작한다. 포장지 이름이 긴 경우(예: 「아이담쌀」)는 `truncate`로 처리하고, `title`에 전체 이름을 넣는다.

## 모바일

모바일은 열이 없는 카드 구조다. 폰트는 키우지 않는다(줄 넘침이 더 큰 문제였다).
- **낱개 카드**: 「본문 1」 줄의 세 번째 칸이 지금 비어 있다(`<span />`). 거기에 포장지를 넣는다.
- **그룹을 펼쳤을 때 서브 카드**: 빈 칸이 없다. 그래서 생산자 칸에 `생산자 · 포장지`로 붙이고 `truncate`로 처리한다.

## 단계

1. 서버: 타입 · include · 행 변환 · 엑셀
2. PC 목록: 그리드 · 헤더 · 행 3종
3. 모바일 카드
4. 검증: `npm test` · `tsc` · `eslint .` → 🖐 화면(PC 1280 · 폰 390)과 엑셀은 사용자가 확인

## 안 하는 것

- 포장지로 검색·필터: 필요하면 따로
- 포장지 열로 정렬
