# 발주서 매처 — 도정 접두 분리

> 상태: ✅ 구현 완료 (재매칭 브라우저 확인 대기) · 작성 2026-09-28 · 보고서 `docs/report-발주서-도정접두분리-2026-09-28.md`
> 관련: D2e 결정 T(`plan-발주서판매처리-D2e.md` §확인 필요 ④) · 수동지정 제거(`plan-발주서-수동지정-제거.md`)

## 1. 왜 지금인가

#20 해남급식_260821의 **「유기농 백미 천지향5세」 10kg 2품목(item 314·317)이 매칭실패**다.

「매칭실패 0」이 유지돼 온 건 매처가 이 표기를 풀어서가 아니었다. **9/15 수동지정이 붙여 둔 결과가 남아 있었을 뿐이다.**

| 일시 | 일 (감사로그) |
|---|---|
| 09-15 | 수동지정 `productTypeId=38 items=[267,270]` (구 #16) |
| 09-16 | 수동지정 기능 철회·삭제 `c2fc6f3` |
| 09-22 | #16 삭제 → 같은 시트 #20 재업로드 (매칭 8/10) |

D2e에서 「도정 접두 분리는 사용자 결정 대기」로 미뤄 둔 문제가 이 수동지정에 가려져 드러나지 않았다.
지금은 **화면에서 풀 길이 없다** — 수동지정은 삭제됐고, 별칭은 `hasMillingToken` 가드가 거절한다(의도된 거절).
해남급식이 이 양식을 계속 쓰면 **업로드할 때마다 실패**한다.

## 2. 원인

`splitMillingSuffix`는 이름 **끝**(`endsWith`)만 본다.

```
유기농 백미 천지향5세 → 접두 제거 → 「백미 천지향5세」 → 끝이 도정 아님 → 통째로 품종토큰 → variety_unresolved
유기농 천지향5세 백미 → 접두 제거 → 「천지향5세 백미」 → 천지향5세 + 백미 ✅
```

## 3. 변경

**파일**: `lib/purchase-order-matcher.ts` · `lib/purchase-order-matcher.test.ts` (+문서)

접미 분리가 아무것도 못 떼었을 때만 **접두 분리**를 시도한다.

- 토큰이 `백미 `·`현미 `·`오분도미 `·`칠분도미 `(**뒤에 공백**)로 시작하면 떼서 millingType으로 쓴다
  - 공백을 요구하는 건 브랜드 접두(`stripBrandPrefix`)와 같은 규칙이다. 실데이터는 전부 셀 줄바꿈 → 공백이다
- 위탁가공 별도품종(`발아현미`·`흑미`)은 영향 없다 — `현미 `로 **시작**하지 않는다
- 접두·접미가 **둘 다** 있으면(`백미 천지향5세 현미`) 접미가 먼저 떨어지고 토큰에 `백미`가 남아 **지금처럼 실패**한다.
  어느 쪽이 맞는지 모르는 걸 추측으로 붙이지 않는다
- `hasMillingToken`(별칭 가드)은 **그대로 둔다**. 별칭에 도정 단어를 넣으면 안 된다는 이유는 여전히 유효하다. 주석만 고친다
  (가드 설명이 「접두는 분리가 안 되니」를 전제로 쓰여 있다)

### 사전 확인 (2026-09-28 실 DB)

- 품종 45종의 이름·별칭 중 **도정 단어로 시작하는 것 0개** → 접두를 떼서 깨지는 품종 없음
- 대상 SKU 38 = 천지향5세 · 백미 · 10kg · 기본 · 활성 → 분리되면 바로 붙는다
- 발주서 품목명 중 도정 단어 포함: `가바백미`·`가바현미`·`찹쌀현미`·`발아현미`·`가바 발아현미`·**`백미 천지향5세`** → 앞의 다섯은 전부 접미 경로라 영향 없음

## 4. 단계

1. 매처에 접두 분리 추가 + 주석 정리
2. 테스트 추가
   - `유기농 백미 천지향5세` → `천지향5세` + `백미`, 10kg 빈칸 → SKU 38
   - `유기농 현미 천지향5세` → `현미` (백미로 굳지 않는다 — 결정 T가 막으려던 바로 그 사고)
   - 공백 없는 `백미천지향5세`는 분리 안 함
   - 접두+접미 동시 → 실패 유지
   - 기존 `가바 발아현미` 등 회귀는 기존 테스트가 잡는다
3. `npm test` · `tsc` · `eslint`
4. **사용자 브라우저**: #20 해남급식 매트릭스 → **재매칭** → 「1품목 이상 매칭」 → 천지향5세 10kg 열이 생기는지
   (재매칭은 `productTypeId: null` 줄만 건드린다 — 이미 붙은 줄·차감된 줄은 안 바뀐다)

## 5. 범위 밖

- 공백 없는 표기(`유기농백미천지향5세`) — 실데이터에 없다. 브랜드 접두도 공백을 요구하므로 같이 풀어야 하고, 그러면 품종명 전수 대조가 따로 필요하다
- 별칭 가드 완화 — 하지 않는다
