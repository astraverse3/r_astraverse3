  정리할 거고, 제품판매 탭과 잡곡 제품재고는 테스트 데이터니 잘 지워야 돼」

## 1. 목표

- **제품판매 탭**을 빈 상태로 되돌린다 — 발주서 묶음·건·라인과 그 판매 차감 전부.
- **잡곡 제품재고**를 빈 상태로 되돌린다 — 도정산·매입 11행 전부.
- **벼 제품재고는 되도록 건드리지 않는다.** 사용자가 직접 한 일괄차감·재포장은 그대로 둔다.
  단, 테스트 판매가 벼 행에서 빼 간 수량은 어떻게든 처리해야 한다(§4 결정 A).

## 4. 사용자 결정 — ✅ 2026-09-29 확정: **A1 · B1 · C1** (셋 다 추천안)

### A. 테스트 판매를 지울 때 벼 행 처리

- **A1 (추천) ★ 11행은 0을 유지한다** — 판매 차감을 지우고 같은 수량(153개)을 「기능 오픈 전
  일괄차감」으로 옮겨 적는다. 사용자가 이미 「이 행은 비었다」고 판단한 행이라 그 판단을 존중한다.
  나머지 11행은 되살아나고 재고조사에서 맞춘다.
- A2 전부 그냥 지운다 — 17행 3.3톤이 목록에 다시 뜬다. 재고조사 때 사용자가 다시 차감해야 한다.

### B. 벼 재포장 13건 (전부 9/14~9/28, 판매 테스트 기간)

- **B1 (추천) #16·#17만 되돌리고 나머지는 남긴다.**
  #16·#17은 새청무 톤백 10개(1,005kg)를 10kg·5kg로 쪼갰다가 **10,050kg짜리 톤백 1개**로 다시
  합친 것이다 — 실물에 없는 자루라 재고조사 때 헷갈린다. 결과 행에 차감이 **하나도 없어**
  깨끗하게 되돌릴 수 있다(원본 pkg#1443 톤백×10 복원).
  나머지 11건은 결과 행 대부분에 사용자 일괄차감이 걸려 있어 되돌리면 그 기록까지 옮겨야 한다.
  중량은 보존돼 있으니 재고조사로 맞춘다.
- B2 13건 전부 남긴다.

### C. 테스트 중 생긴 마스터 데이터

매입 등록이 만든 `PURCHASED` 품종 5종(율무(친환경)·누룽지·녹두(친환경)·혼합곡(친환경)·칼슘찹쌀)과
잡곡 SKU 20개.

- **C1 (추천) 남긴다** — 재고가 아니라 카탈로그다. 실제 매입·발주 때 다시 쓴다.
- C2 `PURCHASED` 품종 5종과 그 SKU 5개를 지운다.

## 5. 실행 방식

`scripts/reset-sales-and-misc-packages.ts` (신규, 일회성)

1. **백업** — 지우거나 바꿀 것 전부를 JSON으로 덤프(저장소 밖 `MillingLog/backup-판매잡곡초기화-2026-09-29.json`).
   덤프 실패 시 즉시 중단.
2. **사전 검증** — 하나라도 어긋나면 중단.
   - 실측 수치와 일치(묶음 5·건 76·라인 126·발주서 차감 99·잡곡 11행) — 어긋나면 그사이 누가 쓴 것
   - 잡곡 11행에 걸린 차감이 발주서 판매뿐 · 재포장 소스/결과 아님
   - ★ 행 11개 · 153개 재계산 일치 (A1일 때)
   - pkg#1443·1457·1458·1459에 #16·#17 외 차감 0 (B1일 때)
3. **한 트랜잭션** (`deleteMany` 위주, 루프 INSERT 없음 · timeout 30초)
   1. (A1) ★ 11행에 일괄차감 11건 `createMany` — 그 행의 가장 최근 일괄차감의 `occurredAt`·작업자를 따른다
      (기존 기록을 고치지 않고 **추가**한다 — 롤백 때 11건만 지우면 된다)
   2. `PackageMovement` 중 `orderItemId≠null` 전부 삭제(99건)
   3. `PurchaseOrder` 전부 삭제(라인 Cascade) → `PurchaseOrderUpload` 전부 삭제
   4. (B1) #17 → #16 순서로: REPACK 차감 3건 삭제 → 결과 행 3개 삭제 → `Repack` 2건 삭제
   5. 잡곡 `MillingOutputPackage` 11행 삭제 → 연결 원물 `CONSUMED→AVAILABLE` 복원(0건 예상)
4. **감사로그 1건** — 요약만.
5. **사후 검증** — 발주서 3테이블 0 · 잡곡 제품재고 0 · 발주서 차감 0 · 가용 음수 행 0 ·
   ★ 11행 가용 0 · 벼 제품재고 행 수 = 702 − 3(B1).

기본은 **dry-run**(백업+검증만), `--apply`를 붙여야 실제로 지운다.
dry-run 결과를 보여준 뒤 실행한다.

트랜잭션 안에서 단계마다 **지운 개수를 스냅샷과 대조**하고, 다르면 throw해 전부 롤백한다
(검증과 실행 사이에 끼어든 쓰기를 잡는다).
