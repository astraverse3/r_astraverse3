# 계획서 — 제품재고 목록 표준규격 적용 (백로그 §30 / 지시서 R6)

**작성일**: 2026-09-04
**근거**: `docs/handoff/list-standard/list-spec-instructions.md` **R6**(디자이너 확정 2026-09-04)
**선행**: R1~R4b 코드(`4098137`) · R5 기준서 개정(`6c5545d`)

---

## 1. 목표

목록 표준규격에서 **혼자 빠져 있던 제품재고 목록**을 표준으로 끌어올려 백로그 §30을 닫는다.

이 작업의 출발점은 「화면을 옮기면 밀도가 튄다」였는데, 표 10곳만 14px로 올린 탓에
**가장 많이 쓰는 목록 하나만 작아져 격차가 오히려 벌어진** 상태다. 그것을 되돌린다.

**grid 마크업 구조는 바꾸지 않는다** — 타이포·밀도만 표준값으로.

## 3. 단계

### D1. 컬럼 헤더 (`:95`)

```
- text-[10.5px] uppercase tracking-wider text-slate-400 font-bold px-4 py-2.5 bg-slate-50/60
+ h-10 items-center px-3 text-sm font-medium text-foreground bg-slate-50
```
`border-b border-slate-200`은 그대로. grid에는 `items-center`가 필요하다(`<th>`의 `align-middle` 대체).

### D2. 행 3곳 (`:219` 낱개 · `:276` 서브 · `:336` 그룹 헤더)

```
- text-[13px] px-4 py-3     (:219, :336)
- text-[13px] px-4 py-2.5   (:276)
+ text-sm px-3 h-11
```
셋 다 이미 `items-center`가 있다. `:276`의 `border-t border-slate-200/60`은 D3에서 함께 본다.

### D3. 펼친 묶음 (`:332`)

```
- bg-slate-50/60 ring-1 ring-inset ring-slate-200/70
+ bg-slate-100 border-t border-slate-200/80
```
`ring-*`은 표 10곳 어디에도 없는 패턴이라 제거(R6). 서브행(`:276`)의 내부 경계 `border-slate-200/60`은
표준(`border-b-0` + 마지막만 경계)과 다르므로 **묶음이 잘려 보이지 않는지 확인 후 조정**한다.
호버도 표준(`hover:bg-slate-200/70`)에 맞춘다 — 현재 `hover:bg-slate-50/70`.

### D4. 보조값 폰트 2단으로 (R6.4)

| 줄 | 현행 | → | 근거 |
| --- | --- | --- | --- |
| `:169` 매입 칩 | `[10px]` | **`[11.5px]`** | 칩/배지 단 (R6 명시) |
| `:187` 차감됨 배지 | `[10px]` | **`[11.5px]`** | 칩/배지 단 (R6 명시) |
| `:178` LOT 칩 | `[11px]` | **`[12.5px]`** | 「로트」는 수치 보조값 단. `misc-stock-table-row:111`도 이미 `[12.5px]` |
| `:350`·`:351` N종 규격·개수 | `[12px]` | **`[12.5px]`** | 수치 보조값 단 (R6가 "N종 규격"을 예시로 명시) |
| `:251`·`:304` 차감 요약 | `[11.5px]` | **`[12.5px]`** | ⚠️ **R6에 없는 판단** — 아래 참조 |

> ⚠️ **`:251`·`:304`는 R6가 열거하지 않았다.** R6는 `[11.5px]`을 「**칩/배지 전용**(`:169`, `:187`)」로
> 한정했는데, 이 둘은 칩이 아니라 **날짜 자리에 들어가는 텍스트**(`「03-14 판매」`)다.
> 규칙을 그대로 적용하면 수치 보조값 단인 `[12.5px]`가 맞다. **그렇게 진행하되 보고서에 명기**한다.

### D5. 기준서 갱신

- §4.2 도입부의 「현재 제품재고 화면(`PKG_GRID`)은 아직 옛 값이 남아 있다 → 백로그 §30」 →
  **적용 완료**로 갱신
- **§4.2.7에 예외 명시**(R6 요구): 「모바일 카드는 표를 따르지 않는다. 카드와 표는 다른 밀도 문맥이며,
  같은 화면에서 데스크탑/모바일 밀도가 갈리는 것은 **의도된 예외**다」

## 4. 검증

- `npx tsc --noEmit` → 0
- `npx eslint app/(dashboard)/packages/package-row.tsx` → 전후 동일
- 🔴 **사용자 브라우저 확인** (dev 서버 상시 기동, `next build` 안 함)
  1. 제품재고 목록 — 헤더 40px·본문 44px, 다른 목록에서 넘어올 때 밀도가 튀지 않는가
  2. **펼친 그룹** — 묶음톤이 한 덩어리로 보이는가, 내부 가로선이 묶음을 자르지 않는가
  3. **재포장 선택 모드**(`PKG_GRID_SELECT`) — 체크박스 열 폭이 어긋나지 않는가 (R6 지적)
  4. 차감된 행 — 「03-14 판매」 요약이 날짜 열에서 넘치지 않는가
  5. 모바일 — **변경 없음**이 맞는지(카드는 손대지 않았다)
