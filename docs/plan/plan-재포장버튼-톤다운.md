## 3. 변경 내용

### 3.1 `repack-toggle-button.tsx` — 톤 한 단 내림

| | 현재 | 이후 |
|---|---|---|
| 꺼짐 | `variant="outline"` | `variant="ghost"` + `text-slate-500` |
| 켜짐 | `variant="default"` (primary solid) | 파랑 틴트 `bg-primary/10 border-primary/30 text-primary` |
| 구분자 | `bg-white/35` (solid 위라서) | `bg-primary/35` (틴트 위로 바뀌니 함께) |
| 폭 | `min-w-[104px]` | `min-w-[96px]` |

`cn` import 추가(현재 없음). 주석의 「액션 그룹 맨 앞(구분선 오른쪽)」·「primary가 둘이 되는 일은 없다」도 사실이 바뀌므로 함께 고친다.

**근거**: 지금 `+ 포장하기`와 똑같은 outline이라 **등록 버튼과 동급으로 튄다.** 재포장은 사용빈도가 낮으니 방향은 올리는 게 아니라 내리는 것. 새 어휘를 만들지 않는다 — ghost는 `재포장 취소`에, 파랑 틴트는 필터 활성에 이미 쓴다.

### 3.2 `rice-package-panel.tsx` — 순서 + 구분선 제거

```
현재:  [엑셀] [검색]  │  [재포장]
이후:  [엑셀] [재포장] [검색]
```

🔴 **벼 패널에는 등록 버튼이 없다.** 재포장이 도구 그룹으로 가면 구분선 오른쪽이 비므로 **구분선(`<span className="mx-1 h-5 w-px bg-slate-200" />`)과 감싼 프래그먼트를 함께 지운다.** 핸드오프 코드도 그렇게 돼 있다.

### 3.3 `misc-package-panel.tsx` — 순서만

```
현재:  [엑셀] [검색]  │  [재포장] [+포장하기] [+매입 등록]
이후:  [엑셀] [재포장] [검색]  │  [+포장하기] [+매입 등록]
```

구분선은 **남긴다**(오른쪽에 등록 버튼 둘이 실재). §3.4 주석의 「추가 버튼은 primary」와 충돌하지 않는다 — 재포장이 primary를 안 쓰게 되므로 오히려 정합이 좋아진다.

### 3.4 안 바꾸는 것

- **`gap-2` 유지** (핸드오프는 `gap-1.5`). 낡은 시안이라 간격 조정은 검증된 값이 아니고, 이번 목적(톤·위치)과 무관하다.
- `disabled` prop 2건 — 이미 완료
- 서버 액션·권한 판정 — 표시 계층만 건드린다
