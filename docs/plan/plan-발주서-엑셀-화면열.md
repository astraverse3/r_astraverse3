## 1. 지금과 바꾼 뒤

지금 엑셀은 **원본 열**(업로드 때 DB에 옮겨 둔 `rawItemName`·`rawPackaging`·`packageType`)로 선다. 열 순서만 화면을 빌린다.

| | 지금 엑셀 | 바꾼 뒤 (= 화면) |
|---|---|---|
| 열 단위 | 원본 열(품목명·포장지·규격 조합) | **SKU 열**(`matrix.columns`) — 표기만 다른 원본 열 둘이 한 SKU면 한 열로 합쳐짐 |
| 1행 품목 | `유기농 천지향` (원본) · 같은 이름 이어지면 병합 | `천지향1세` (`matrix.titles`) · 제목 같은 칸 병합 |
| 포장지 줄 | 원본 포장지, 택배는 대부분 **빈칸** | 실제 차감 포장지 `천지향`·`땅끝에서보냅니다` (`matrix.groups`) · 그룹 단위 병합 |
| 규격 줄 | `4kg` · 톤백 `1,000kg` | 같음(화면 규칙: 톤백은 자루중량) |
| 칸 값·상태 | 원본 칸별로 모아 상태를 다시 냄(`exportCellStatus`) | **매트릭스 셀 그대로**(주문 수·차감 수·상태) — 판정이 한 벌이 된다 |
| 매칭실패 열 | 원본 이름 | 화면처럼 원본 이름 + 포장지 줄 `매칭실패` |

택배 실데이터로 달라지는 것: IPS(`유기농 IPS` / `유기농 프로틴 라이스 IPS`)가 1행 한 칸으로 합쳐지고, 포장지 빈칸이 실제 포장지로 채워진다.

## 2. 결정할 것 — 머리글 줄 순서

지금 엑셀은 `품목 · 농가명 · 로트번호 · 포장지 · 중량 · 소계` 순이다(옛 공장 발주서의 「농가명」 줄 자리를 살린 것).

| 안 | 순서 |
|---|---|
| **A (추천)** | `품목 · 포장지 · 규격 · 농가명 · 로트번호 · 소계` — 위 3줄이 화면 머리글과 똑같다 |
| B | `품목 · 농가명 · 로트번호 · 포장지 · 규격 · 소계` — 지금 줄 자리 유지, 글자만 화면 기준 |

추천 이유: 「화면처럼」의 핵심이 품목 → 포장지 → 규격이 붙어서 한 덩어리로 읽히는 것이다. B는 포장지 줄이 품목과 떨어져 있어 병합이 두 군데로 갈린다.
