## 1. 무엇을 바꾸나

| 채널 | 건을 여는 방식 | 근거(실측 2026-09-22) |
|---|---|---|
| **택배** | 🔴 **건 상세 없음** — 목록 안에서 **행이 펼쳐진다** | 67건 · 평균 **1.18품목** · 1품목 건이 **58** |
| 급식·이마트·기업별 | 건 상세 화면 (지금 그대로) | 1~3건 · 건당 **3~8품목** |

택배는 건 상세를 열어 봐야 **카드 한 장**이다. 깊이만 한 단계 늘고 뒤로가기가 잦아진다.
반대로 서울급식 은평구는 16품목이라 목록 안에서 펼치면 목록이 아니라 스크롤이 된다.

**같이 들어오는 것**: 접힌 줄에는 **예외만** 적는다. 모든 줄에 「1품목」을 반복하면
정작 봐야 할 **부족·실패가 묻힌다**.

```
실패 있음  →  「n — 품종 못 찾음」 (빨강)
부족 있음  →  「n개 부족」 (주황)
2품목 이상 →  「n품목」 (회색)
그 외(1품목) → 아무것도 안 적는다
```

## 2. 🔴 구현 전 대조 — 시안에서 **쓰면 안 되는** 것 3가지

시안을 그대로 옮기면 오늘 한 일이 되돌아간다. (이 항목은 6회 반복된 사고다)

| 시안 | 실제 | 조치 |
|---|---|---|
| `n라인 FIFO 차감` | 오늘 **「품목」**으로 바꾸고 **FIFO는 화면에서 뺐다**(`2a91668`) | **`n품목 일괄차감`** |
| 96라인 · 완료 24 · 부분 1 · 실패 2 · 작업 필요 41 | **79품목 · 완료 6 · 부분 0 · 실패 0 · 작업 필요 61** | 시안 수치는 **시점 불명**. 화면 기대값으로 쓰지 않는다 |
| 「48건이 1라인」 | **58건** | 〃 |
| 「다음 작업 건 ›」 | 현재 구현은 **「다음 건」** | 기존 표기를 따른다 |

📌 시안의 수치는 **스냅샷이고 이미 낡았다.** 구조만 취하고 숫자는 실측으로 다시 채운다.
