# 계획서 — 제품재고 목록: 일부 차감된 줄을 남은 양으로 표시

작성 2026-10-01

## 1. 목표

일부만 차감된 제품재고 줄이 **처음 포장한 개수·중량** 대신 **남은 개수·중량**으로 보이게 한다.
그룹 합계·무게순 정렬도 남은 양 기준으로 맞춘다.

## 2. 현상 (실서버 실측)

- 새청무 10kg 포장 #1482(로트 `251119-11-15103885-4113`): 포장 115개, 오늘 52개 차감(이영명 「기능 오픈 전 일괄차감」)
- DB 가용 = 115 − 52 = **63개**(정상). 발주서·재포장·차감은 이미 63개 기준으로 동작
- 목록에는 **115개 · 1,150kg**으로 보인다

## 3. 원인

- 목록 줄은 `deducted ? available : qty` — **다 차감된 줄만** 가용을 보이고, 일부 차감 줄은 원래 개수(`qty`)를 보인다
  (`package-row.tsx:244·302`, `mobile-package-card.tsx:159·230`)
- 중량 `sub`는 `totalWeight`(원래 중량) 그대로 → 줄 kg·그룹 합계(`packages.ts:246`)·무게순 정렬(`:236·269`)이 전부 원래 중량
- 그룹 머리 개수 `totalQty`는 `qty` 합(`package-row.tsx:333`, `mobile-package-card.tsx:266`)
- `packages.ts:75` 주석은 「차감 도입 후 표시 기준 = 가용」 — 계획서에도 일부 차감 줄 표시 결정은 없다 → **누락**으로 판단.
  지금까지는 줄 전체를 차감하는 경우가 대부분이라 드러나지 않았다

## 4. 변경 범위

| 파일 | 변경 |
|---|---|
| `lib/package-available.ts` | `availableKgOf(row)` 추가 — 가용 = 원래면 `totalWeight` 그대로, 일부 차감이면 `가용 × 단중`(소수 3자리), 0 이하면 0 |
| `lib/package-available.test.ts` | 위 함수 테스트(차감 없음·일부·전부·잔량 줄) |
| `app/actions/packages.ts` | `PackageRow`에 `availableKg` 추가. 그룹 합계·무게순 정렬을 `availableKg`로. `sub`(원래 중량)는 그대로 둔다 — 삭제 확인 문구 등 「포장 자체」를 말하는 곳이 쓴다 |
| `app/(dashboard)/packages/package-row.tsx` | 줄 개수 → `available`, 줄 kg → `availableKg`, 그룹 머리 개수 → 가용 합 |
| `app/(dashboard)/packages/mobile-package-card.tsx` | 위와 같음 |

건드리지 않는 것: 차감 이력 다이얼로그(원래 개수·차감·남은 개수를 이미 따로 보여 준다), 재포장·차감 다이얼로그(이미 가용 기준).

## 5. 사용자 결정 필요

**(A) 일부 차감 줄에 흔적을 남길까?**
- A-1 (추천): 남은 숫자만 — `63개 · 630kg`. 차감 이력은 지금처럼 ⋮ 메뉴
- A-2: 원래 개수를 작게 같이 — `63개 /115`

**(B) 엑셀 내보내기** — 지금은 **다 차감된 줄까지 전부** 원래 개수·중량으로 내보낸다(가용 계산이 없다).
9/9 소급 차감 467행과 오늘 일괄차감분이 엑셀엔 재고처럼 남아 있다.
- B-1 (추천): 화면과 같게 — 다 차감된 줄은 빼고, 「개수」「총중량」을 남은 양으로. 원래 개수는 「포장개수」 열로 남김
- B-2: 이번엔 화면만 고치고 엑셀은 백로그로
