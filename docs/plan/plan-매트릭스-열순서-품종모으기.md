# 계획서 — 발주서 매트릭스 열 순서: 같은 품종 모으기

- 작성: 2026-09-28 · 상태: ✅ **구현 완료 2026-09-28** (화면 확인 통과) · 보고서 `docs/report/report-매트릭스-열순서-품종모으기-2026-09-28.md` — A안
- 발단: D5 엑셀 확인 중 사용자 「같은 품종이라도 떨어져 있다」

## 1. 무슨 일인가

매트릭스 열은 **품목 그룹 = 품종·도정·실제 포장지(SKU)** 로 묶이고, 그룹은 위 행부터 처음 주문된 순으로 선다(`buildColumns`).
원본 포장지가 빈칸이면 규격마다 기본 포장지가 달라(택배 천지향 10kg=「천지향」, 5·1kg=「땅끝에서보냅니다」)
같은 품종이 그룹 여러 개로 갈라져 흩어진다. 택배처럼 수령인마다 1~2품목만 주문하는 시트에서 두드러진다.

원래 「처음 나온 순」은 **엑셀 원본과 대조**하려는 규칙이었다(`fdbee5b`). 행마다 여러 품목을 주문하는 시트(해남·시아스)는
실제로 원본과 같지만, 택배는 원본과 다르다 — D5에서 확인(DB만으로 원본 순서를 못 되살린다).

## 2. 결정 — A안: 품종끼리 모은다

- 그룹을 **품종이 처음 나온 순**으로 세우고, 같은 품종 안의 그룹끼리는 지금처럼 처음 나온 순
- 품종 = SKU의 `varietyName`(도정 무관 — 서농22호 백미·현미 = 가바백미·가바현미가 이웃). 매칭실패 그룹은 원본 품목명이 제 품종
- 그룹 안 규격 순서는 그대로(처음 나온 순)

후보 비교(실DB 시트 5장, 2026-09-28):

| 규칙 | 택배 | 서울급식 | 해남·시아스(현재 원본과 같음) |
|---|---|---|---|
| 지금 | 품종 흩어짐 | — | 같음 |
| **A 품종 모으기** | **품종별로 모임** | 지금과 동일 | **같음 유지** |
| B A+규격 오름차순 | 모임 | 동일 | ❌ 깨짐(원본이 10kg→1kg, 1,000kg→200kg) |
| C 가나다+규격 | 가나다 | 가나다 | ❌ 깨짐 |

⚠️ 미리보기에서 이마트는 비교 스크립트 표기 문제로 빠졌다. 구현 후 실측: **변경 전(화면 순서)에도 원본과 달랐고**(가바현미가 시화지점만 주문해 맨 뒤), A안에서 가바백미 옆으로 와 **원본에 더 가까워졌다**(남은 차이 = 가바백미·가바현미의 앞뒤).
