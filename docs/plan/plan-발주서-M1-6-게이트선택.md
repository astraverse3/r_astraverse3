# M1-6 — 검토 게이트 선택 UI (폰 목록 진입)

상위 계획: `plan-발주서판매처리-M1.md` §M1-6 · 시안: `모바일-건별리스트-핸드오프.md` §7,
`건처리-건별리스트-모바일.html` 「검토 게이트 — 목록에서 진입」

## 1. 목표

폰 목록의 `작업필요 n건 검토`로 연 게이트에서 **뺄 건의 체크를 해제**할 수 있게 한다.
지금은 작업필요 건 **전부**가 무조건 들어가고, 폰에는 고를 수단이 없다(매트릭스 체크박스는 데스크탑 전용).

## 2. 코드 대조 결과 (구현 전)

| 시안·계획서 | 현재 코드 | 처리 |
|---|---|---|
| 진입 = 목록 푸터 `작업필요 n건 검토` · 5건 이상 | **이미 있다**(`order-list-mobile.tsx` `workRows.length >= 5`) | ✅ 그대로 — 새로 만들 건 게이트 안 선택 UI뿐 |
| 게이트 = 건 목록 + 체크박스 | 게이트에 **건 목록이 없다**(합계·구성 바·이슈 목록만) | 목록을 **새로 얹는다** |
| 4갈래 구성·실패 배너·「이 줄」 | 있다 | ✅ 그대로(아래에 둔다) |
| 푸터 `38건 차감 · 1,284kg · 제외 3 · 실패 2` + `38건 차감 확정` | `n품목 차감 확정` | 버튼은 **품목** 유지(9/22 용어 통일), 왼쪽 요약에 건·제외 수 |
| 시안 푸터 `되돌리기는 건 상세에서` | `되돌리려면 셀 단위로 차감 취소` | 🔴 폰엔 셀이 없다 → `품목 단위로` (M1-5로 폰에도 길이 생겼다) |
| 매칭실패 행별 「재매칭」 버튼 | 배너 + 「이 줄」 이동 | ❌ 현행 유지(재매칭은 묶음 단위 액션이라 행별 버튼이 거짓말이 된다) |
| 🔴 (시안에 없음) | 미리보기는 **고른 건 전체로 FIFO를 돌린 결과**다 | §3-B |

## 3. 결정

### A. 선택 UI는 **폰 목록 진입일 때만** (추천)

- 데스크탑은 매트릭스 행 체크박스로 **이미 골라서** 들어온다 — 게이트에서 또 고르게 하면 선택이 두 벌이다
- 건상세 푸터 일괄차감은 건 **하나**라 고를 게 없다
- 구현: 게이트에 `orders?: GateOrder[]`를 주면 선택 모드. 부모는 목록 진입일 때만 넘긴다

### B. 🔴 체크를 바꾸면 **미리보기를 다시 받는다**

FIFO라 한 건을 빼면 그 재고가 뒤 건으로 간다 — 부족이던 건이 정상이 될 수 있다. 화면에서 빼기만 하면
**숫자가 거짓말**이 된다. 확정의 지문(`fingerprint`)도 건 목록마다 다르다.
- 토글 후 **400ms 디바운스** → `previewBatch(남은 건)` (기존 액션 그대로, 서버 변경 0)
- 응답 경합: **요청 번호**로 늦게 온 옛 응답을 버린다
- 🔴 확정은 **그 미리보기를 만든 건 목록**과 지문을 한 쌍으로 보낸다 — 지금 체크 상태가 아니라.
  계산 중에는 확정 버튼을 막는다
- 전부 해제하면 조회하지 않고 「선택된 건이 없습니다」

### C. 목록 모양

- 발주처 그룹(`groupAxisOf` — 폰 목록과 같은 축) 헤더 `땅끝황토친환경 · 9건` + **「그룹 해제」/「그룹 선택」**
- 행: 체크박스 20×20 · 수령인 · `천지향 · 백미 4kg 6개` (`외 n품목`) · 기본 **전부 체크**(빼는 UI) · 해제 행 `opacity-45`
- 🔴 **일괄로 할 게 없는 건**(전부 톤백·매칭실패)은 체크박스 없이 사유만(`톤백만 · 품목을 눌러 처리`) —
  눌러도 아무 일이 없는 체크박스는 거짓 어포던스다. 서버에는 그대로 보낸다(매칭실패가 아래 목록·배너에 계속 보이게)
- 위치: **목록이 위, 기존 구성·이슈는 아래**(상위 계획 §5 위험 대응 그대로). 결과 kg은 **푸터 요약**에도
  찍어 목록을 내려도 보이게 한다

### D. 순수함수 분리 → 테스트

그룹 묶기·행 요약·「일괄 대상 없음」 사유를 `lib/purchase-order-gate.ts`(순수)로 — 화면은 그리기만.

## 5. 확인 항목 (브라우저)

1. 폰 택배 목록 → `작업필요 n건 검토` → 목록이 발주처별로 묶여 전부 체크
2. 한 건 해제 → 흐려지고 잠시 뒤 **차감 예정 kg·구성이 다시 계산**(부족이던 다른 건이 풀리는지 볼 수 있으면 더 좋다)
3. 「그룹 해제」 → 그 발주처 전부 해제 · 다시 「그룹 선택」
4. 전부 해제 → 확정 버튼 비활성 · 안내
5. 해제한 채 확정 → **체크한 건만** 차감됐는지(해제한 건은 그대로 대기)
6. 톤백만 있는 건이 체크박스 없이 사유로 보이는지
7. 데스크탑 매트릭스 선택 → 게이트: **목록 없이** 예전 그대로 · 폰 건상세 일괄차감도 예전 그대로
