## 1. 요약

`/packages` 라우트를 신설해 포장된 제품재고를 한 곳에서 조회할 수 있게 함. 벼/잡곡 2탭 구조이며 벼 탭은 기존 `MillingOutputPackage`(`source=MILLED, category=RICE`) 데이터를 그대로 표시. 잡곡 탭은 같은 모델의 `category=MISC_GRAIN` 레코드를 표시하되, **포장/매입 다이얼로그는 #7·#8로 미룸**(현재는 비활성 placeholder 버튼).

핸드오프 §3.4 헤더 액션, §4.2 품종 그룹 펼침 테이블, §4.3 모바일 2줄 카드, §4.6 검색 다이얼로그를 모두 적용. 사용자 검수 피드백 다수 즉시 반영.

## 3. 핵심 설계 결정 (계획 vs 실제)

| 항목 | 계획 | 실제 | 비고 |
|---|---|---|---|
| 데이터 구조 | InventoryItem 그룹/낱개 혼합 (서버 그룹핑) | 동일 채택 | `varietyId` 기준 |
| 그룹 내부 정렬 | 명시 안 됨 | **FIFO** `(weightPerUnit asc, date asc)` 고정 | 사용자 의견(같은 규격은 오래된 재고부터) |
| 기본 정렬 | latest | **weight_desc** | 사용자 의견(큰 재고가 위) |
| Producer 표시 | "외 N명" 다농장 표시 | 단일 농가만 | 포장은 stock 1:1 매핑이라 다농장 표시는 모순 |
| 진입점 | 사이드바·네비 임시 추가 | **홈 임시 카드만** | #9에서 사이드바 일괄 정리 |
| 헤더 [+] | placeholder | 벼는 숨김, 잡곡은 비활성 + 준비중 툴팁 | |
| 정렬 옵션 | latest 기본 | **재고량 많은순/최신/오래된** 3종 | |
