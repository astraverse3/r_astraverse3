## ① 차감 다이얼로그 — **가장 위험**

**가는 길**: 제품재고(`/packages`) → 상단 액션의 **`차감`** 버튼 → 카드 몇 개 선택 → 차감 진행

> 여기만 모바일에서 **구조가 아예 바뀐다.** 데스크탑 6열 표가
> 모바일에선 **2열 + 보조줄**로 접힌다. 그래서 가장 위험하다.

- [ ] **①-1** 품종·규격 줄이 **두 줄로 넘어가지 않는지** (품종명이 긴 것으로)
- [ ] **①-2** 보조줄의 **로트 칩 · 「가용 N」 · 날짜(MM-DD)** 셋이 서로 붙거나 넘치지 않는지
- [ ] **①-3** 오른쪽 **수량 입력칸**이 왼쪽 텍스트와 겹치지 않는지
- [ ] **①-4** 수량을 비우면 행이 흐려지는데(제외 처리), 그때 **레이아웃이 흔들리지 않는지**
- [ ] **①-5** 🔴 **로트가 긴 행(톤백·잔량)으로 볼 것** — 모바일만 로트를 줄인다
      (16자 넘으면 `…`+뒤 14자). 잘린 로트가 **읽을 수 있는 수준인지**
- [ ] **①-6** 행이 많을 때(9줄 이상) **스크롤이 되는지**, 하단 확인 버튼이 안 밀리는지

> 참고: 오늘(09-08) 이 화면의 **데스크탑 헤더**만 바꿨다(`hidden ... sm:grid` 안쪽).
> 모바일에는 그 헤더가 아예 안 뜨므로 **무영향**이다.

## ② 재포장 다이얼로그

**가는 길**: 제품재고 → **`재포장`** 버튼 → 카드 선택 → 재포장 진행

- [ ] **②-1** **규격 버튼**이 모바일에서 5칸으로 접히는데, 버튼 안 글자가 잘리는지
      (`800g`·`10kg` 같은 긴 것으로)
- [ ] **②-2** 「만들 규격」 목록이 1열로 접힐 때 **입력칸이 화면을 넘는지**
- [ ] **②-3** 규격을 3~4개 추가했을 때 **하단 버튼이 화면 밖으로 밀리는지**

- [ ] **③-2** 사유가 길 때 줄이 넘치는지

## ⑥ 검색·필터 다이얼로그 (2026-09-08 추가 — **실기기에서 실제로 걸린 항목**)

**가는 길**: 제품재고 / 원물재고 / 잡곡 원물재고 / 도정관리 → 각 화면 우측 상단 **필터 아이콘**

> 체크리스트 최초 작성 때 **빠져 있던 화면**이다. 실기기에서 바로 걸렸다 —
> 다이얼로그 오른쪽 컬럼(정렬·인증구분·종료일)이 통째로 화면 밖으로 밀려 나갔다.
> 원인은 `grid` 칸에 `min-w-0`이 없어 트랙이 **드롭다운 글자폭(163px)으로 굳은 것**.
> 390px에서 `146×2`가 되어야 할 컬럼이 `163×2`가 되면서 11px 넘쳤다. 수정 완료.

- [x] **⑥-1** 제품재고 **벼** 탭 검색 — 오른쪽 컬럼이 안 잘리는지 ✅ 확인됨
- [ ] **⑥-2** 제품재고 **잡곡** 탭 검색 — 인증구분 자리가 「출처」로 바뀐다
- [ ] **⑥-3** **원물재고** 필터 (`/raw-stocks`) — 3개 행 전부
- [ ] **⑥-4** **잡곡 원물재고** 필터 (`/raw-stocks?tab=misc`)
- [ ] **⑥-5** **도정관리** 필터 (`/milling`) — 상태·수율, 날짜 버튼 2개
- [ ] **⑥-6** 위 전부에서 **드롭다운 글자가 잘릴 때 `…` 처리**가 되는지
      (칸을 넘기지 않는 게 우선 — 글자가 줄어드는 건 의도된 동작이다)

> 🔴 **다음에 같은 증상이 보이면** 눈대중 말고 콘솔에서 바로 재라:
> ```js
> const d = document.querySelector('[data-slot="dialog-content"]')
> console.log(d.clientWidth, d.scrollWidth)   // 다르면 내부 넘침
> ```
> `scroll > client`면 넘침이고, 자식 트리의 `w=`를 훑으면 어느 칸이 부풀었는지 바로 나온다.

## 알려진 불일치 (넘침 아님 — 볼 필요 없음, 참고용)

같은 390px인데 **로트 표시 규칙이 화면마다 다르다** —
차감 다이얼로그는 로트를 줄이는데(`shortLot`+`truncate`),
제품재고 모바일 카드의 로트 칩은 **전체를 그대로 뿌린다.**
넘치지는 않지만 규칙이 하나가 아니다. 실기기에서 **어느 쪽이 읽기 좋은지** 눈에 들어오면 알려줘 —
그걸로 규칙을 하나로 정한다.
