## 2. 주요 결정 사항

### 2.1 `Sheet`는 회색 유지 — 의도적 제외
`SheetContent`도 `bg-background`지만 유일한 실사용처인 `milling-cart-sheet.tsx`가
**회색 바탕 위에 흰 카드 4개를 얹는** 구조다. 흰색으로 바꾸면 카드 4개를 전부 뒤집어야 하고,
이번 목적(다이얼로그의 카드 성격 바로잡기)과 성격이 다르다. 사용자 승인.

### 2.2 다크모드는 검증 대상 아님
백로그 §22에 「다크모드도 확인」이 적혀 있었으나 실측 결과 **실사용이 없다** —
`app/**/*.tsx`의 `dark:` 유틸리티 **0건**, `ThemeProvider`·`next-themes`·`prefers-color-scheme` **없음**.
`.dark` 팔레트는 정의만 있는 상태라 범위에서 제외했다.

### 2.3 컨트롤의 `bg-background`는 분리 (§25 신규)
`button.tsx:16`의 **outline variant**도 같은 병이다 — outline 버튼 배경이 회색이다.
`repack-dialog:592` · `deduct-dialog:467` · `movement-history-dialog:220`이 전부 손으로 `bg-white`를
되돌린 증거다. 다만 **전 앱 버튼에 파급**돼 위험도가 달라 §25로 분리했다(`switch` thumb · `multi-select` 포함).
`calendar.tsx:38`은 popover 안에서 `bg-transparent`로 무력화되므로 조치 불요.

### 2.4 이미 해소됐는데 표시만 안 된 백로그 2건
- **§13** `getPackages` 2달 cutoff — `lib/package-where.ts`에 cutoff **없음**. 검색 필터 확장(`f8228ab`)·
  기본 생산연도 제거(`77d2703`) 과정에서 정식 필터로 대체되며 사라졌다
- **§14** 비판매 차감 처리 — 2026-09-01 재고차감 D1~D7(`95527a7`)이 구현체다

### 2.5 린트 부채는 §16에 얹는다 (§26 신규)
변경 파일 린트에서 8건이 나왔으나 **전부 내가 건드리지 않은 줄**의 기존 부채다
(앱 전체는 536건). 그중 `add-packaging-dialog.tsx`가 6건을 갖고 있는데
이 파일이 **§16(모바일 잘림) 대상**이라, 어차피 열 때 함께 처리하기로 했다.
표시 계층 PR에 타입 정리를 섞지 않는다.

## 4. 검증 중 발견 — 재포장 규격 표기 중복 (별도 커밋 `8d7276b`)

사용자가 재포장 다이얼로그를 확인하다 **「5kg · 5kg 이안규」** 를 발견했다.
`{packageType} · {weightPerUnit}kg`로 늘 병기하다 보니 **라벨에 이미 무게가 있는 규격**에서 겹쳤다.

무조건 지울 수는 없었다 — `톤백`·`잔량`은 라벨만으로 무게를 알 수 없어 병기가 **필수**다.
그래서 `formatSpec()` 헬퍼를 두고, **라벨이 단중과 같은 `{n}kg` 꼴일 때만** 단중을 생략한다.
규격 `5kg`에 단중 4.8처럼 어긋난 경우는 겹침이 아니라 실제 불일치라 그대로 드러낸다.

§22와 성격이 달라 **별도 커밋으로 분리**했다(사용자 결정).
