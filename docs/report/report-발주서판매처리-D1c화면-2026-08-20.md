### 1.2 액션 보강

- `listPurchaseUploads()` — **`deletable`** 추가(묶음에 `PackageMovement`가 하나도 없을 때만 true). ⋮ 메뉴가 삭제 가능 여부를 미리 알 수 있게. `_count`로 집계해 추가 쿼리 없음.
- `createdAt` — `yyyy-mm-dd` → 표시용 **`MM.DD HH:mm` (KST 고정)**. 서버에서 포맷해 hydration 불일치를 피한다.

### 1.3 박스 입수 (#35)

- `upsertProductType`에 `unitsPerBox` 추가 — **1 이상 정수 또는 null**만 허용(서버·클라 양쪽 검증).
- `/admin/product-types` 등록·수정 다이얼로그에 입력칸 + 안내문("비워두면 박스 칸이 빈칸").
- 목록 표(모바일 그룹표·데스크탑표)의 **규격 셀 옆에 `16개/박스` 보조 표기** — 열을 늘리지 않고 값을 확인할 수 있게.

## 4. 🔴 남은 검증 — 사용자 브라우저 확인 필요

이 단계에서 **D1b의 이월분까지 함께 확인**해야 한다. dev 서버(`localhost:3000`)가 이미 떠 있다.

1. `/sales` 제품판매 탭 → **엑셀 업로드** → `docs/resources/발주서-통일양식-템플릿.xlsx`(5시트) 선택
2. 시트 표에 5시트 + 미인식 시트가 뜨는지, 채널·발주일 추측값이 맞는지
3. **다채널 2시트만 체크 → 등록 → 묶음 2건** 생성 확인 (계획서의 D1b 검증 기준)
4. 같은 파일을 다시 올려 **「이미 적재됨」 배지 + 체크 불가** 확인
5. ⋮ → 비고 수정 저장 → 행 아래 비고 표시 확인
6. ⋮ → 묶음 삭제 → 목록에서 사라지는지 확인
7. `/admin/product-types` → 아무 SKU 수정 → 박스 입수 16 저장 → 목록에 `16개/박스` 표시 확인

## 5. 확인이 필요한 사항

1. **양식 내려받기** — 시안 1단계 푸터에 있으나 대상 파일·기능이 정의되지 않아 뺐다. 템플릿 xlsx를 정적 파일로 배포할지 결정 필요.
2. **모바일 업로드 모달** — 시트 표를 좁은 화면에서 어떻게 접을지는 `엑셀업로드-모바일.html`이 구 양식 기준이라 M2에서 갱신 필요. 지금은 컬럼 접힘으로만 대응.
3. 🔴 **미결 유지 — 재고 분할 차감.** D2 착수 전 결정 필요.
