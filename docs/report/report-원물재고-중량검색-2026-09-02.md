# 결과보고서 — 원물재고(벼) 검색 필터에 중량 추가

작업일: 2026-09-02 · 계획서: `docs/plan/plan-원물재고-중량검색.md`

## 배경
올해 처음 적용하는 방식이라 **톤백번호가 안 적힌 톤백이 많음** → 번호 대신 **무게로 재고를 찾아야** 하는 현장 요구. 임시 운영용 필터.

## 변경 사항

| 파일 | 내용 |
|---|---|
| `app/actions/stock.ts` | `GetStocksParams.weightKg` 추가, 파싱 헬퍼 `parseWeightFilter`(콤마 제거 후 `parseFloat`, 숫자 아니면 필터 미적용) 신설. `getStocks` / `getStockGroups` / `getStocksByGroup` 3곳에 정확 일치 조건 적용 |
| `app/actions/stock-excel.ts` | `exportStocks`가 조건을 자체 구성하므로 동일 조건 별도 반영 (엑셀도 화면과 같은 결과) |
| `app/(dashboard)/raw-stocks/stock-filters.tsx` | 생산자 줄을 `grid-cols-2`로 나눠 오른쪽에 「중량 (kg)」 입력칸 추가. 상태·URL 동기화·적용·초기화·활성 필터 뱃지 카운트 반영. `inputMode="decimal"`, Enter 시 적용 |
| `app/(dashboard)/raw-stocks/page.tsx` | 벼 탭 `filters` / `getStockGroups` 인자에 `weightKg` 전달 |
| `app/(dashboard)/raw-stocks/active-filters.tsx` | 적용된 중량을 `1,004kg` 배지로 표시, 검색결과 카운트 로직에 포함 |

## 주요 결정 사항
1. **매칭 방식 = 정확 일치.** 소수점을 쓰지 않는 운영이라 ±오차/범위 대신 단순 일치로 확정. 나중에 오차 허용으로 바꾸려면 `parseWeightFilter` 사용부 한 줄(`where.weightKg = { gte, lte }`)만 고치면 됨.
2. **조회 함수 3곳 모두 적용.** 벼 탭은 「그룹 집계(건수·합계) → 펼치면 항목 조회」로 나뉘어 있어 한 곳만 고치면 그룹 건수와 펼친 목록이 어긋남.
3. **엑셀도 반영.** 당장 쓰진 않더라도 화면 필터와 내보내기 결과가 달라지는 함정을 남기지 않기 위함.
4. **입력칸 위치**는 사용자 제안대로 생산자 줄을 반으로 나눔. 폭이 줄어 생산자 placeholder를 `예: 홍길동, 김영희`로 축약.
5. **잡곡 탭은 범위 밖** (요청이 벼 한정).
