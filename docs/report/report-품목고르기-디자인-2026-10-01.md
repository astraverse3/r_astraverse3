## 주요 결정

- **P4(「고치는 중」)는 할 일이 없었다.** ⑦(`ff124fe`)에서 지시서와 같은 클래스로 이미 반영돼 있었다.
- **결과 줄 `onMouseDown`에서 `preventDefault`**: 결과는 검색칸 포커스가 있을 때만 보인다. 그래서 누르는 순간 포커스가 먼저 빠지면 목록이 닫혀 클릭이 허공에 떨어진다.
- **목록 안 키보드 이동도 `scrollTop`으로** 맞춘다. `scrollIntoView`는 바깥 시트까지 흔든다.
- **품목 추가 영역 보이기**: 결과 목록이 autoFocus로 펼쳐진 뒤(2프레임 뒤) 재서 패널 본문만 내린다.
- **`taken`에서 매칭실패 줄(`productTypeId` null)은 뺀다.**
- **시안 `sku-picker-parts.jsx`가 `시안/`에 없어** 시안이 안 열린다. 지시서 문구대로 구현했다. 원본 파일은 사용자에게 요청했다.

## 확인이 필요한 사항

지시서 완료 기준 그대로:
1. 두 화면 모두 처음 열면 품목 목록이 안 보이고, 검색칸에 들어가면 최대 5줄 펼쳐지는지
2. 패널·창 안에 스크롤바가 두 겹으로 안 생기는지
3. 고르면 한 줄 + 수량 칸으로 바뀌고, 「바꾸기」로 다시 검색 상태가 되는지
4. 건 상세: 이미 있는 품목은 「이미 있음 · 수량에서 고치기」, 눌러도 반응 없음
5. 건 상세: 품목 추가는 목록 맨 아래 한 줄, 펼친 뒤 닫는 곳은 ✕ 하나
6. 주문 추가 창: 비워도 되는 칸은 placeholder로만 안내
7. 수량 칸 모양이 ⑦ 고치기 목록과 같은지
8. 11px 미만 · slate-400 이하 텍스트 없음
