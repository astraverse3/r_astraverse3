## 1. 목표

기존 `/raw-stocks`(벼 전용)을 **벼/잡곡 2탭 구조**로 재편하고, 잡곡 입고를 도정위탁/농가도정/발아위탁 3가지 sourceType으로 등록·수정·삭제하는 라이프사이클을 구축한다. 잡곡 원물재고는 벼와 동일한 `(생산년도, 품종, 인증유형)` 그룹 키로 lazy load 목록을 제공한다.

### 3.2 #5a — Server Actions + zod (`e98cd42`)

**신규**: [app/actions/misc-stock.ts](../app/actions/misc-stock.ts) (단일 파일 ~390줄)

액션 6종:
- `createMiscStock(input)` — zod discriminated union(`sourceType`)으로 분기 검증, 품종 MISC_GRAIN 확인, 중복 체크, 로트 생성, audit log
- `getMiscStocks(params)` — 평면 조회 (카테고리/년도/품종/생산자/sourceType/인증/상태 필터 + 정렬)
- `getMiscStockGroups(params)` — 그룹 키 `(년도, 품종, 인증유형)` 벼와 동일
- `getMiscStocksByGroup(groupKey, params)` — 그룹 펼침
- `getMillingVendors()` — 도정업체 distinct (자동완성용)
- `getMiscFarmers()` — `producesMiscGrain=true` 농가만

**핵심 결정**:
- 로트번호: 벼와 동일 규칙. millingType은 '백미' 고정 (`getProductCode`가 잡곡 품종명으로 21~215 산출)
- 중복 체크 풀: `(category=MISC_GRAIN, productionYear, farmerId, varietyId, bagNo)` — 벼 풀과 분리
