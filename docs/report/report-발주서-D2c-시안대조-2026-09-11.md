## 2. 주요 발견

1. **`MatrixRow.label`은 죽은 표시값** — 화면은 `vendor`/`recipient`를 직접 조합하고 `label`은 정렬 키로만
   남아 있다. `"발주처 → 수령인"` 문자열이라 「가나다」가 발주처 기준으로 정렬된다. → C0-d에서 제거.
2. **이마트 시트 하단 박스표가 안 들어오는 건 우연** — A열에 값이 있어 `isForeignBlockHeader`를 빠져나가고
   수량이 0이라 `items.length > 0`에서 걸린다. 숫자가 채워지면 주문으로 잘못 적재된다. → 백로그 §41 처방 2.
3. `unitsPerBox`는 스키마·관리화면에만 있고 **환산 계산을 쓰는 코드가 없다.**
