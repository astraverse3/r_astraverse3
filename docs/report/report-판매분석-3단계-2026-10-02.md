## 변경 사항

### PC 점검 (A-1)
- 요약 카드의 색 띠·점을 뺐다. 판매량 파랑·개수 초록·주문 노랑이 차트의 택배·서울급식·해남급식 색과 겹쳐서 채널을 뜻하는 것처럼 읽혔다
- 빈 상태는 차트 자리 한 곳에서만 말한다: 「이 기간에 판매가 없어요」 + 「판매는 2026.10.01부터 기록되고 있어요」. 카드 값은 0(slate-300)으로 두고 표 카드는 숨긴다
- 거래처 탭은 상위 20곳만 보이고 「나머지 N곳 더 보기」를 둔다. 엑셀은 전체를 내보낸다. 탭을 바꾸거나 다시 조회하면 다시 접힌다
- 탭 끝 구분선 뒤에 「원물출고」 탭을 뒀다

### 채널 색 (A-2)
- 이마트 `#4a3aa7`(보라, T1 금지) → `#b9472a`(벽돌색)
- dataviz `validate_palette.js`를 다시 돌렸고 전부 PASS다. 이웃 색약 최솟값은 9.1로 그대로다(서울급식↔해남급식). 일반 시야 최솟값은 16.3에서 19.6으로 올랐다
- 채널 배지(발주서 목록 `upload-table.tsx`, `CHANNEL_META.badge`): **채널마다 색 바탕·점 없음, 이마트만 보라 → 분홍**(지시서 A-2 개정판 14:30 · 사용자 결정). 진행 배지(「완료」·「부분」)는 「색 바탕 + 점」이라 점 유무로 갈린다. 배지 색과 차트 색은 따로 간다
  - 한때 「회색 외곽선 + 차트 색 점」(`f1e872e`)으로 갔다가 개정판에 맞춰 되돌렸다

### 모바일 (A-3)
- 필터 카드에는 「기간 라벨 · 날짜(올해면 연도 뗌) · [조건 N] · 엑셀」 한 줄만 둔다. 조건은 시트에서 고른다(기간 칩 7개 · 곡종 · 채널 · 품종)
- 시트 바닥은 `60px + 1rem + safe + 8px`다. 재고분석 시트는 탭바와 12px 겹치는데(백로그 §36), 그걸 베끼지 않았다
- 탭은 「별」을 떼고 `px-3 text-[13px]`로 했다. 순서는 요약(2×2) → 차트 → 목록이다
- 차트: 막대 20, 간격 20%, 높이 180이다. 일별이면 눈금을 1·8·15·22·29만 찍는다(`interval={6}`). 모바일 판별은 도정 차트와 같은 `matchMedia('(max-width: 767px)')`다
- 표는 두 줄 목록으로 바꿨다(순위·이름·kg / 비중 막대·개수·주문·%). 접기 규칙은 PC 표와 같은 `visibleRows`다

### 원물출고 탭 (A-4, 결정 ②로 줄임)
- 안내 줄 「벼 원물을 그대로 내보낸 기록이에요. 단위는 톤이고, 제품 판매(kg)와 따로 셉니다.」
- 기간은 판매 탭과 따로 들고 기본값은 올해다. 필터는 기간뿐이다
- 월별 막대(한 색 `#0f766e`) · 요약 3장(출고량 톤 · 출고 건 · 출고처 곳) · 출고처별 표(PC)/목록(모바일) · 엑셀
- `lib/raw-release-stats.ts`(+테스트 7, TZ 두 번) · `app/actions/raw-release-statistics.ts`
- 옛 `output-stats-client.tsx` · `app/actions/output-statistics.ts` · `components/statistics/OutputChart.tsx`는 삭제했다. 백로그 §2 `'Tonbag'` 코드 2곳도 같이 사라졌다

### 차감 창 (B ④)
- 거래처 칸을 늘 자리에 둔다. 판매가 아니면 비활성(`bg-slate-100`) + 「판매일 때만 적어요」. 「· 필수」는 판매일 때만 붙인다
- 모바일도 발생일 | 거래처 두 칸이라, 사유를 오가도 아래가 밀리지 않는다
