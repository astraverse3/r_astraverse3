# 결과보고 — 잡곡 제품재고 PC 목록에서 도정구분 열 빼기 (백로그 §94)

## 변경 요약

| 파일 | 내용 |
|---|---|
| `app/(dashboard)/packages/package-row.tsx` | 그리드 상수 2개(`PKG_GRID`·`PKG_GRID_SELECT`)를 `pkgGrid(select, showMilling)` 하나로 바꿈. 4가지 조합은 `PKG_GRIDS`에 통째로 적었다. 헤더·낱개 행·서브행·그룹 행이 `showMilling`(기본 true)을 받고, false면 도정구분 칸을 그리지 않는다 |
| `app/(dashboard)/packages/package-list-client.tsx` | `showMillingType?: boolean`(기본 true)을 받아 헤더·그룹·낱개 행으로 넘김 |
| `app/(dashboard)/packages/misc-package-panel.tsx` | `showMillingType={false}` |

벼 탭은 기본값(true)을 그대로 써서 바뀐 게 없다. 모바일 카드와 엑셀은 원래 도정구분이 없거나 「—」면 비워 둬서 손대지 않았다.

## 주요 결정

- **4가지 그리드를 문자열 그대로 다 적었다.** Tailwind는 소스에 통째로 적힌 클래스만 CSS로 만든다. 그래서 `28px_`를 앞에 붙이거나 `0.5fr_`를 빼는 식으로 조각을 이어 붙이면, 빌드에 그 클래스가 없어 칸이 무너진다.
- **도정구분을 뺀 그리드는 나머지 비율을 그대로 둔다.** 빠진 0.5fr만큼 다른 열이 같은 비율로 넓어진다.
- **재포장 동질성 판정(`identityKey`)과 선택 바 라벨은 그대로 둔다.** 둘 다 화면 열이 아니라 `millingType`·`millingTypeLabel` 값을 쓴다. 잡곡 라벨은 「—」라서 지금도 선택 바에서 걸러진다.
- `PKG_GRID`·`PKG_GRID_SELECT`는 `package-row.tsx` 밖에서 쓰는 곳이 없어서(grep 확인) 이름을 바꾸고 export를 뺐다.
