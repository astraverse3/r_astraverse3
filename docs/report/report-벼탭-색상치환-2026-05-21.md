## 변경 요약
벼 탭(원물재고/도정관리/출고) 3개 디렉토리의 레거시 하드코딩 색을 디자인 시스템 토큰으로 일괄 치환.

- **범위**: `app/(dashboard)/raw-stocks/**`, `milling/**`, `sales/release/**`
- **결과**: **25개 파일, 173곳** 치환
- 방식: `scripts/recolor-rice-tabs.js`(역방향 치환, dry-run 검토 후 `--commit`) — 실행 후 삭제

## 색상 매핑 (적용됨)
| 레거시 hex | → 토큰 |
|---|---|
| `#00a2e8` / `#008cc9` / `#007ab3` | `primary` |
| `#f0f9ff` | `blue-50` |
| `#8dc540` | `emerald-600` |
| `#7db037` | `emerald-700` |
| `#6ba02c` | `emerald-800` |

- opacity 전부 보존: `bg-[#00a2e8]/[0.04]` → `bg-primary/[0.04]`, `ring-[#00a2e8]/20` → `ring-primary/20` 등
- 매핑 외 색 `#2a2a2a`(다크그레이)는 의도적으로 보존

## 검증
- `npx tsc --noEmit` 통과 (EXIT 0)
- 벼 탭 3개 디렉토리 레거시 hex 잔여 **0건** (grep 확인)
- 시각 회귀(특히 `#8dc540`→emerald 색감 변화, 그룹 행 톤)는 사용자 측 화면 검수 권장
