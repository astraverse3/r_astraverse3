## 2. 주요 결정

### 2.1 🔴 일괄차감은 신규 경로가 아니다 — 게이트를 건 하나로 연다

`ReviewGateDialog`는 `orderIds: number[]`를 받는다. **건 하나짜리 배열**을 넘기면 그대로 동작한다.

건상세 전용 확정 경로를 새로 지었다면 **4갈래 구성**(정상 / 부분 / 재고없음 / 실패)이 두 벌이 됐다.
그 4갈래는 실측의 산물이다 — 부족 18라인이 **전부 가용 0**이어서, 「부분 차감」으로 묶으면
아무 일도 일어나지 않는 줄을 조금이라도 나가는 줄로 읽게 된다.

패널은 **열어 둔 채**다. 확정 결과가 패널 숫자에 바로 반영되고(파생이라 자동),
이어서 「다음 건 ›」으로 넘어가는 것이 이 화면의 흐름이다.

### 2.2 🔴 「다음 건」 순서는 **열 때 찍은 스냅샷**이다

지시서 §4.2는 「목록의 현재 필터·정렬 순서를 그대로 받는다」고만 적었다. 그대로 하면 깨진다:

> 모바일 목록의 기본 필터는 **「작업 필요」**다. 이 건을 차감하면 그 순간 목록에서 빠지고
> 뒤 건이 한 칸 당겨진다 → 살아 있는 목록으로 `indexOf + 1`을 하면 **바로 다음 건을 건너뛴다**.

처리할수록 건을 빠뜨리는 동작이라, 연속 처리를 위해 만든 버튼이 연속 처리를 망가뜨린다.
→ 패널을 **열 때** 순서를 찍고, 그 배열을 끝까지 쓴다.

순서를 만드는 쪽도 `shown`이 아니라 **그룹으로 묶은 뒤**의 순서다.
발주처별 정렬일 때 그룹을 건수 내림차순으로 다시 세우므로 `shown`과 화면 차례가 어긋난다 —
사용자는 위에서 아래로 넘긴다고 믿는다.

### 2.3 건마다 `key`로 새 마운트

「다음 건 ›」이 스크롤 위치와 완료 그룹 접힘 상태를 물려받으면 새 건을 중간부터 보게 된다.
`<Body key={orderId}>` 한 줄로 끝난다 — 리셋을 effect로 흉내 내지 않았다.

### 2.4 완료 그룹은 「작업 필요가 있을 때만」 접는다

작업 필요가 하나도 없는 건에서 완료 목록을 접으면 **화면이 비어 보인다**.
그때는 완료 목록이 곧 이 화면의 내용이다.

## 3. 🔴 곁가지 — 모바일에서 게이트의 「이 줄」이 무반응이었다

**대조 중 발견.** 게이트의 이슈 줄을 누르면 매트릭스 셀로 스크롤하는데, **폰에는 갈 셀이 없다** —
매트릭스가 `hidden sm:contents`(= `display:none`)다. DOM에는 있어서 `querySelector`는 **찾지만**
스크롤이 아무 일도 하지 않는다. 사용자 눈에는 게이트만 닫히고 끝이다.

📌 **D3의 `data-cell` 사고(`dc5651b`)와 같은 증상**이다 — 「선택자는 맞는데 아무 반응이 없다」.
그때는 속성이 DOM에 안 갔고, 이번엔 요소가 그려지지 않았다.

들어온 시점은 M1-2(모바일 게이트 진입)이고, M1-3이 진입점을 하나 더 늘리므로 같이 막았다.

**고친 방법** — 브레이크포인트(`sm` = 640px)를 JS에 복제하지 않고
**그 셀이 실제로 그려져 있는지를 DOM에 묻는다**:

```tsx
const el = document.querySelector(cellSelector(at.cellKey))
if (el instanceof HTMLElement && el.offsetParent !== null) { …셀로… } else { …건으로… }
```

- 안 보이면 **그 건의 상세**로 데려간다
- `lineIndex`에 `orderId`를 같이 담았다 — 🔴 `cellKey`를 쪼개 쓰지 않는다
  (표시·이동용 키를 식별자로 겸용하지 말 것)
- 🔴 데스크탑에서 셀로 갈 때는 **패널을 닫는다** — 열린 채면 오른쪽 468px이 그 셀을 덮는다

## 4. 확인이 필요한 것

1. **브라우저 확인 전이라 푸시 보류.** 이 저장소는 푸시가 곧 배포다
2. **패널(Sheet) 위에 게이트(Dialog)가 겹친다** — 둘 다 `z-50`이고 Radix가 나중 마운트를
   위에 올리지만, 중첩 modal의 포커스·`pointer-events` 복원은 **실기기에서 봐야 한다**.
   특히 목록 → 게이트 → 「이 줄」 → 패널 열림은 Dialog 닫힘과 Sheet 열림이 같은 tick이다
3. **`matrix-client.tsx` 1022줄** (949 → 1022). 800줄 상한 초과가 더 벌어졌다.
   머리글 4행(`MatrixHead`·`SumRow`·`HeadCorner` 약 200줄)을 떼면 ~820줄 — **별도 작업**
4. 푸터 버튼 2개가 좁은 폰(360px)에서 한 줄에 들어가는지 — `일괄차감` + `다음 건`
