- **간단안(17:26)을 따랐다.** 행의 둘째 줄(「가장 오래된 요청 N일 전」), 「지금 상태 기준」, 빈 상태 둘째 줄이 빠졌다. 그래서 개수만 있으면 되고, 쿼리는 추가하지 않았다
