## 3. 구현 중 발견해 동반 수정한 잠복 결함 3건

시안·계획서로는 안 잡히고 **colgroup을 넣는 순간 드러난** 것들이다.

### 3.1 생산자관리 — 컬럼 수가 세 갈래로 어긋나 있었다

`canManage=false`일 때 **헤더 9칸 / 본문 10칸 / 그룹헤더 11칸**.
auto 레이아웃이 가려주고 있었다. 세 곳 모두 조건부로 맞췄다.

### 3.2 생산자관리 — 작목반 없는 농가가 2명 이상이면 데스크탑에서 안 보였다

헤더는 `isMultiFarmer && group.group`을 요구하는데 행은 `isExpanded`를 기다렸다.
펼칠 손잡이가 없으니 영영 렌더되지 않았다. `hasHeader` 도입으로 해소.
(모바일 뷰는 `isNoGroup`을 따로 처리해 원래 멀쩡했다 — 데스크탑만의 문제였다.)

### 3.3 벼 재고 — 선택 하이라이트가 묶음톤에 묻혔다

그라데이션(`primary/10 → primary/5 → **white**`)이 흰 배경 전제였다.
묶음톤이 `bg-slate-100`이 되자 왼쪽은 명도가 비슷해 묻히고 **오른쪽 불투명 흰 끝이
밝은 얼룩**으로 보였다. `bg-primary/20` 단색으로 교체하고, 선택된 행에는 묶음톤을 깔지 않게 했다.

## 4. 사용자 확인으로 조정한 것

- **묶음톤 강화**: 시안의 `bg-slate-50/75`는 흰색과 **2% 차이**라 실제로 구분이 안 됐다.
  `bg-slate-100`(5.5%)으로 올렸다. 접힌 그룹은 `slate-50` 유지 → 접힘(3%) < 펼침(5.5%) 위계가 생겼다.
- **반복 컬럼 비우기**: 사용자 제안. 그룹 키가 `group.id`라 년도·작목반번호·작목반·인증번호가
  그룹 내에서 동일하다. 펼친 하위 행에서 비웠다 — **색보다 이쪽이 묶음을 훨씬 잘 읽히게 한다.**
  잡곡의 `inExpandedGroup` 패턴을 벼·생산자관리로 확대한 것이고, R3가 「잡곡 패턴을 따르라」고 한
  부분을 처음에 톤·단일건만 가져오고 빠뜨렸던 것을 보완했다.
- **안내 칩 제거**: 「클릭해서 펼치기/접기」는 세 화면 중 생산자관리에만 있던 예외.
  R3의 「모두 넣거나 모두 빼거나」에 따라 제거했다.

### 🔴 제품재고가 이번 작업의 가장 큰 미결이다

출발점이 「화면 이동 시 밀도가 튄다」였는데, 표 10곳을 14px로 올린 결과
**가장 많이 쓰는 목록 하나만 혼자 작아졌다**(`text-[10.5px]` 헤더 · `text-[13px]`/`[11px]`/`[10px]` 본문).
격차가 오히려 벌어졌다.

시안 R5는 「grid 마크업 자체는 유지」라고만 적었는데, 그것이 **마크업 구조**를 뜻하는지
**타이포·밀도까지 현행 유지**인지 불분명하다. 둘은 분리 가능하므로 **디자이너 확인이 필요하다.**
