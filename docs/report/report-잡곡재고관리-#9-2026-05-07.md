### #9a — `/sales` 라우트 신설 + `/releases` 이관 + 리다이렉트
**핵심 결정**: `/releases` 디렉토리는 **이동/삭제하지 않고 그대로 유지**. 새 `/sales/release-section.tsx`에서 `ReleasePageWrapper`/`ReleaseFilters`/`ReleaseExcelButton`을 직접 import해 재사용. 9개 파일 위치 이동을 회피해 grep 누락/import 경로 깨짐 위험 차단.

**신규 파일** (`app/(dashboard)/sales/`):
- `page.tsx` — `searchParams.tab`(`rice`/`misc`/`release`, default `release`) 분기 server component
- `sales-tabs.tsx` — F안 애니메이션 탭 (handoff §4.1). 비활성 텍스트 `text-slate-400`, 활성 `text-slate-900` + 14px + 아래 2.5px 바
- `release-section.tsx` — 기존 `/releases/page.tsx`의 `Suspense + ReleasePageWrapper` 래핑 그대로 이식
- `coming-soon-panel.tsx` — 벼/잡곡 탭 placeholder ("곧 제공될 기능이에요. 현재는 출고 탭에서 ...")

**수정**:
- `next.config.ts`: redirects에 `/releases → /sales` + `/releases/:path* → /sales` 308 추가
- `app/actions/release.ts`: `revalidatePath('/releases')` 3곳 → `'/sales'`
- `app/(dashboard)/releases/release-filters.tsx`: `usePathname()` 추가, `router.push('/releases?...')` → `router.push('${pathname}?...')` — 출고 탭 검색이 `/sales` 경로 유지

### #9b — 사이드바 + 모바일 네비 개편
**`components/desktop-sidebar.tsx`** 전면 재작성:
- `MAIN_MENU` 배열 분리: 홈(lucide Home) + 원물재고/도정관리/제품재고/판매관리(Set C 듀오톤)
- `STATS_SUB`: 수율분석/재고분석/**판매분석**
- 듀오톤 아이콘에 `active` prop 전달 (active=true 시 fill currentColor → primary 색으로 채움)
- active 색 `text-blue-600` → `text-primary` 통일
- MANAGEMENT 섹션(품종/생산자/관리자)은 권한 가드 그대로 유지

**`components/mobile-nav.tsx`**:
- `navItems` 5개 → 4개 + 통계: 홈 제거, `원물/도정/제품/판매` (Set C 듀오톤) + `통계`(StatsIcon)
- `statsSubItems` 출고분석 → **판매분석**
- `STATS_INDEX` 상수로 통계 인덱스 명시 (배열 변경에 견고)
- `getActiveIndex` 분기 단순화 (홈 케이스 제거 → `findIndex(... href.startsWith)`)
- Goo blob + cubic-bezier 애니메이션 + safe-area는 그대로

**모바일 헤더(`mobile-header.tsx`)는 변경 없음** — 로고 → 홈 링크가 이미 적용되어 있어 홈 진입점 보존됨.
