## 2. 주요 결정 사항

1. **PR-4 Segmented Tab**: 디자인 영향이 커 사전 시안(`public/preview/raw-stocks-tab.html`, 3안 비교) 확인 후 진행. 사용자가 **A안(중립 흰 카드)** 선택. raw-stocks만 우선 적용, packages/sales 확장은 후속 보류.
2. **PR-5 카드 폰트 sweep 철회**: 당초 "모바일 카드 본문 폰트 한 단계 상향"이 핵심이었으나, 카드가 한 줄에 욱여넣은 구조라 폰트↑ 시 줄 넘침이 더 큰 문제 → **카드 폰트 유지**. 가독성은 정보 재배치로 해결(원물카드 A안). 향후 원칙으로 메모리화.
3. **원물카드 A안**: 사용자가 Claude Design 핸드오프 번들(`docs/원물카드_상태간소화_A안/`) 제시. 테이블형 1행 + **상태칩 제거**(상태는 배경+흐림으로) → 긴 생산자명 잘림 해소. 드롭인 교체본 그대로 적용.
4. **PR-6 범위 축소**: 실측 결과 `start-milling-dialog`는 이미 정합이라 제외. grid 1열화는 "긴 값 필드만, 짝 숫자 필드는 2열 유지" 원칙 적용.
5. **보류·범위밖**: 도정 카드(`mobile-milling-card.tsx`) 레이아웃·클릭영역 단일화(추후 재검토), PR-7 confirm→AlertDialog(별도 PR).
