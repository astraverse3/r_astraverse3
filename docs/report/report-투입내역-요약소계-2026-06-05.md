# 결과보고서 — 투입내역 팝업 요약 밴드 + 생산자별 소계

- 날짜: 2026-06-05
- 대상 파일: `app/(dashboard)/milling/stock-list-dialog.tsx` (단일 파일, 표시 UI만 추가)
- 시안: `docs/투입내역-요약-소계-시안.html` (B안)

## 변경 사항 요약

1. `Fragment` import 추가 (`react`).
2. 집계 로직 추가 — `farmerNames`, `varietyNames`, `groups`(생산자 첫 등장 순서 유지), `showSummary`(톤백 ≥2), `showSubtotal`(생산자 ≥2). 기존 `totalWeight` 재사용.
3. 모듈 레벨 `Stat` 컴포넌트 추가 (요약 밴드 3지표 셀).
4. 요약 밴드 렌더 — 메타 밴드와 표 사이, `showSummary`일 때만. 톤백/생산자/품종/합계(강조).
5. `TableBody`를 `groups.map` + `Fragment` 구조로 변경, 각 생산자 그룹 끝에 `showSubtotal`일 때 소계 행 삽입(`소계` + 개수 + 중량만, 이름 텍스트 없음). `canDelete` 분기에서 빈 `<TableCell />` 1개 더 추가해 컬럼 정렬 일치.

## 주요 결정 사항

- 기존 props·삭제/수정/메타편집 로직은 그대로 유지(수술적 변경). 추가 API/쿼리 없음.
- 소계 단위는 **생산자명 기준**(certType·품종 달라도 생산자로만 묶음).
- 번호순 재정렬 안 함 — 첫 등장 순서로 그룹화.

## 검증

- `npx tsc --noEmit` 통과(에러 없음).
- 엣지 케이스(코드 분기 기준): 톤백 1개 → 요약·소계 모두 숨김 / 단일 생산자·톤백 ≥2 → 요약 O·소계 X / 다중 생산자·톤백 ≥2 → 둘 다 O.

## 확인이 필요한 사항

- 실기기/실데이터에서 600px 다이얼로그 폭 기준 요약 밴드 레이아웃 육안 확인(특히 생산자명이 긴 경우).
