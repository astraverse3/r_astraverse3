## 2. 주요 결정

- **B안**(사용자 결정): 1행 = 지금 그룹 제목(`groupTitleOf`) 그대로. 도정이 다르면 분리(`서농22호` / `서농22호 · 현미`), 포장지만 다른 것만 합친다
- 같은 품종 안에서 제목끼리 모으는 2차 정렬 추가 — 없으면 택배 시트에서 `서농22호` 칸이 두 번 뜬다(실데이터로 확인)
- 매칭실패 그룹은 매칭된 그룹과 제목이 같아도 합치지 않는다(빨간 글씨가 섞이면 안 됨)
- 셀 팝오버·검토 게이트의 품목명(`g.title · 규격`)과 D5 엑셀 머리글(원본 품목명 기준 병합)은 그대로
