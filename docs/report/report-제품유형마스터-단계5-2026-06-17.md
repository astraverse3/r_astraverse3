# 결과보고서: 제품유형(ProductType/SKU) 마스터 — 단계 5 (등록 3경로 연동) 완료

## 1. 작업 개요

제품유형 마스터의 마지막 단계인 **등록 3경로의 `productTypeId` 연동**을 완료. 이로써 새로 등록되는 모든 제품재고(`MillingOutputPackage`)가 SKU(`ProductType`) 카탈로그에 자동으로 묶인다.

| 경로 | 다이얼로그 | 커밋 |
|---|---|---|
| 잡곡 매입 | misc-purchase-dialog | `55b4941` |
| 잡곡 포장 | misc-package-dialog | `55b4941` (+ `5dfc206` 기본 승격) |
| 벼 도정산 | add-packaging-dialog | `c7b03d5` |
| UI 1행 통합 | add-packaging-dialog | `892b0d5` |

## 2. 변경 사항 요약

### 2.1 잡곡 매입 (`createMiscPurchase`)
- 단순 create → 트랜잭션 전환. `'매입포장'`(active=false) sentinel Packaging 조회 → `findOrCreateProductType(품종, '기타', 규격, 매입포장)` → `productTypeId` 주입. **UI 무변경**(포장지 자동).

### 2.2 잡곡 포장 (`createMiscPackage`)
- `CreateMiscPackageSchema`에 `packagingId` 추가. 다이얼로그에 포장지 드롭다운 신설(`suggestProductType`으로 기본 자동선택 + 변경 가능).
- **`findOrCreateProductType`에 `promoteDefaultIfNone` 옵션 추가**: 새 SKU 생성 시 그 (품종+도정+규격) 조합에 기존 기본이 없으면 첫 등록 포장지를 기본으로 자동 승격. 헬퍼를 `upsert` → `find → (기본유무 확인) → upsert`로 재구성.

### 2.3 벼 도정산 (`updatePackagingLogs`, add-packaging-dialog)
- `MillingOutputInput`에 `packagingId?` 추가.
- `updatePackagingLogs`(replace-all)가 라인마다 SKU 결정:
  - **잔량** = `productTypeId` null (SKU 미부여, 재포장 소진 정책)
  - **톤백** = `'톤백'` Packaging 강제 (lazy 조회)
  - **그 외** = 라인 `packagingId`로 `findOrCreateProductType(promoteDefaultIfNone)`
- `getMillingLogs`: `outputs` include에 `productType.packagingId` 추가 → 다이얼로그 재진입 시 라인별 포장지 복원.
- UI: 규격 버튼 클릭 시 `suggestProductType`으로 기본 포장지 자동 부여. 라인별 포장지 표시/드롭다운.

### 2.4 UI 1행 통합 (Claude Design 핸드오프)
- 포장 라인을 2행(포장지 별도 줄) → **1행 통합**. 그리드 `[40px_140px_1fr_58px_24px]`, 포장지 select를 규격 옆 인라인.

## 3. 주요 결정 사항

- **잡곡 포장지 = "기본 자동선택 + 변경 가능 드롭다운"**(사용자 확정). 잡곡 품종은 시드 SKU 0건이라 첫 등록 시 직접 선택 → `promoteDefaultIfNone`로 그 선택을 기본으로 승격 → 다음부터 자동.
- **매입은 기본 승격 안 함**(`'매입포장'` 단일 포장지라 무의미).
- **잔량 = SKU 미부여 유지**(백필 때와 동일 정책), **톤백 = `'톤백'` 포장지 SKU**.
- **`addPackagingLog`는 UI 미사용 데드코드라 이번 범위 제외** — 향후 사용처 생기면 동일 패턴 적용 필요.

## 4. 검증 (증거 기반)

- 전 변경 `tsc --noEmit` 통과. 변경분 신규 lint 0건(stash 비교로 기존 부채와 동일 수 확인).
- **실 DB 동작 확인**:
  - 잡곡 매입(칼슘찹쌀) → SKU `#62`(매입포장) 자동 생성·연결.
  - 잡곡 포장(흑미 1kg) → SKU `#63` 생성 + 첫 포장지 기본 승격.
  - 벼 도정산(천지향1세 배치 재저장) → 8kg/4kg/10kg/5kg 전 라인 `pt#…(기본)` 주입, 잔량 NULL 유지, 백필 이후 NULL이던 서농22호 4kg도 채워짐.
