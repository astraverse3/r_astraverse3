# 결과보고서: 권한 단순화 (비즈니스 5→2 + USER/SYSTEM ADMIN 흡수)

> 2026-06-22 작업 완료. 계획서: [plan-권한단순화.md](../plan/plan-권한단순화.md)

## 1. 변경 사항 요약

비즈니스 권한 5개 → 2개로 통합하고, 관리 권한 중 위임이 없던 `USER_MANAGE`·`SYSTEM_MANAGE`를 ADMIN role로 흡수했다.

### 1.1 권한 키 재편
| 구분 | 변경 |
|---|---|
| 신설 | `SUPPLY_MANAGE`(원물·마스터), `OPERATION_MANAGE`(가공·판매) |
| 폐기→통합 | `STOCK_MANAGE`·`VARIETY_MANAGE`·`FARMER_MANAGE` → `SUPPLY_MANAGE` / `MILLING_MANAGE`·`SALES_MANAGE` → `OPERATION_MANAGE` |
| 폐기→ADMIN 흡수 | `USER_MANAGE`·`SYSTEM_MANAGE` (개별 보유자 0명, 관련 액션 이미 `requireAdmin`) |
| 유지 | `NOTICE_MANAGE`, `ADMIN` role |

### 1.2 코드 변경 (커밋 전, working tree)
- `lib/permissions.ts`: `BUSINESS_PERMISSIONS`(2개)·`ADMIN_PERMISSIONS`(NOTICE만) 교체, 주석 갱신.
- `middleware.ts`: `/admin/varieties`·`/admin/farmers`→SUPPLY, `/admin/product-types`→OPERATION, `/admin/users`·`/admin/logs`·`/admin/backup`→`null`(ADMIN 전용).
- **서버 액션 가드**: `stock.ts`·`misc-stock.ts`·`admin.ts`·`excel.ts`·`packages.ts`·`milling.ts`·`release.ts`·`product-type.ts` 총 **~45곳** 치환(sed 일괄, `\b` 워드 경계).
- **클라이언트 UI 가드**: raw-stocks·milling·packages·sales/release·admin/varieties·admin/farmers·product-types·_components 등 **~25곳** 치환.
- **관리자 메뉴 노출 조건**: `desktop-sidebar.tsx`·`mobile-header.tsx` — 섹션 노출 조건에서 USER/SYSTEM 제거(ADMIN은 `hasAnyPermission` 자동 통과), 사용자/로그/백업 개별 항목은 `user?.role === 'ADMIN'`으로 교체.
- `docs/permission-matrix.md` 전면 갱신(단일 진실 원천, 문서 선행).
- `docs/plan/plan-발주서판매처리.md` §8.3: 발주서 권한 전부 `OPERATION_MANAGE` 확정(#14 역할분리 소멸 명시).

## 2. 주요 결정 사항

- **2분할의 근거 = 실데이터**: MILLING↔SALES 100% 동행, VARIETY↔FARMER 100% 동행, STOCK↔(가공·판매) 분리(입고전담·가공판매전담 실재). "다 합치자"(1개)가 아니라 2분할이 정답.
- **키 이름 2안(새 키)** 채택 — 의미 명확성 우선(사용자 결정). 전수 치환했으나 sed 일괄 + 타입체크로 안전 확보.
- **USER/SYSTEM의 ADMIN 흡수** — 개별 보유자 0명이라 영향 없이 정리.
- **사용자 관리 화면 무수정** — `UserPermissionDialog`·`UserTable`이 권한 정의를 동적 순회 → 정의 교체만으로 자동 반영.

## 4. 확인이 필요한 사항 / 후속

- **세션 JWT 캐싱**: 기존 로그인 사용자는 토큰에 옛 permissions가 남아 있어 **재로그인해야 새 권한이 반영**됨. 운영 사용자에게 재로그인 안내 필요.
- **커밋·배포**: 코드 변경은 아직 working tree 상태(미커밋). 빌드(`next build`)는 미실행(타입체크만 수행) — 배포 전 빌드 1회 권장.
- **마이그레이션 스크립트**: `scripts/migrate-permissions-2026-06-22.cjs`는 1회성·idempotent. 보관(이력) 또는 정리 선택.
