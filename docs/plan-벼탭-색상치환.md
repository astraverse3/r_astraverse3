# 계획서 — 벼 탭 레거시색 → 디자인 토큰 치환 (PR1)

> 작성일: 2026-05-21
> 출처: `docs/벼탭-디자인점검.html` P0 §1.1 / 작업순서 PR1
> 범위: **색상 치환만** (구조 변경·공용 컴포넌트·행 액션·다이얼로그 정렬은 다음 라운드)

## 목표
벼 탭 페이지(원물재고/도정관리/출고)의 레거시 하드코딩 색을 디자인 시스템 토큰으로 일괄 치환.

## 범위 (벼 탭 3개 디렉토리)
- `app/(dashboard)/raw-stocks/**`
- `app/(dashboard)/milling/**`
- `app/(dashboard)/sales/release/**`

**제외**: admin/*, statistics/*(순수 hex 스타일 객체 — 별도), 제품재고 벼 탭(판매관리 연동 시), 모든 구조/패턴 변경(P1~), 보류 항목.

## 색상 매핑
| 레거시 hex | → 토큰 | 비고 |
|---|---|---|
| `#00a2e8` | `primary` | 메인 시안톤 (금지색) |
| `#008cc9` | `primary` | 진한 변형. **합계 강조 slate-900化는 P1로 미룸** (이번엔 통일만) |
| `#007ab3` | `primary` | 더 진한 변형 |
| `#f0f9ff` | `blue-50` | 연한 배경 |
| `#8dc540` | `emerald-600` | 유기농 인증색 (라임 → 에메랄드, 시각 변화 있음) |
| `#7db037` | `emerald-700` | 인증 진한 변형 |
| `#6ba02c` | `emerald-800` | 인증 더 진한 변형 |

- opacity 보존: `bg-[#00a2e8]/[0.04]` → `bg-primary/[0.04]`, `ring-[#00a2e8]/20` → `ring-primary/20`
- 벼 탭은 순수 hex 문자열 없음(전부 className arbitrary) → 패턴 치환으로 100% 커버

## 방식
1. `scripts/recolor-rice-tabs.js` 작성 — 벼 탭 3개 디렉토리 한정, **dry-run 기본 / `--commit`로 실제 적용**
2. dry-run으로 변경 미리보기(파일별 건수 + 샘플) 확인
3. `--commit` 실행
4. 검증: `npx tsc --noEmit` 통과 + 벼 탭에 레거시 hex 잔여 0건(grep) 확인
5. 스크립트 삭제(일회용) → 결과보고서 + worklog

## 확인 필요 / 결정사항
- `#008cc9` → 이번엔 `primary`로 통일. 합계 숫자 `slate-900` 톤다운은 P1(패턴 정렬) 단계.
- `#8dc540`(유기농) → `emerald-600`. 라임에서 에메랄드로 색감이 바뀌는 점 인지 필요(디자인 시스템 성공색 통일).
- 잔여 구조 작업(그룹 톤/공용 컴포넌트/행 액션/다이얼로그/UX)은 본 PR 범위 밖 — 다음에 별도 진행.
