## 2. 주요 결정

- **A안**(사용자 선택): 품종끼리 모으고, 품종 사이와 품종 안은 처음 나온 순을 유지
- 품종 = `varietyName` — 도정을 가리지 않는다(서농22호 백미·현미 = 가바백미·가바현미가 이웃)
- **규격은 재배열하지 않는다** — 원본이 `10kg → 1kg`(해남)·`1,000kg → 200kg`(시아스) 순이라 무게로 세우면 원본과 맞던 시트가 깨진다(후보 B 기각 이유)
- 함수 50줄 제한 때문에 정렬을 `gatherByVariety`로 분리

## 4. 확인이 필요한 사항

1. **화면 확인** — 택배 시트 매트릭스(데스크탑)에서 천지향·서농22호(가바백미·가바현미)·하이아미가 모여 있는지. 모바일 건 목록·게이트도 같은 열 순서를 쓴다
2. 🔴 **바로잡음** — 앞서 「이마트가 원본과 달라졌다(D5 때는 같았다)」고 보고한 건 틀렸다. D5의 「같음」은 폐기한 위상정렬 방식 기준이었고, 화면 순서로 바꾼 뒤엔 원본 대조를 다시 돌리지 않았다
