## 12. [보안/권한] 사용자관리 권한 키 재정리 — 잡곡/제품재고/판매관리 추가에 따른 정비

- **발견일**: 2026-04-30 (잡곡 #5 계획 단계, 사용자 메모)
- **현상**: 현재 권한 키는 벼 중심으로 구성됨 — `STOCK_MANAGE`, `MILLING_MANAGE`, `NOTICE_MANAGE` 등. 잡곡 입고/포장/매입, 제품재고 페이지(`/packages`), 판매관리(`/sales`)가 추가되면 권한 분리 정책 재검토 필요
- **검토 항목**:
  - 잡곡 원물 입고/조회 권한을 기존 `STOCK_MANAGE`로 통합할지, `MISC_STOCK_MANAGE`로 분리할지
  - 제품재고(`/packages`) 권한 신설 여부 (`PACKAGE_MANAGE` 등)
  - 잡곡 매입 등록을 별도 권한으로 둘지 (`PURCHASE_MANAGE`)
  - 판매관리(`/sales`)는 신규 권한(`SALES_MANAGE`) 도입
  - 사이드바·모바일 네비 메뉴 가시성을 권한과 일관되게 동기화
- **영향**: 권한 누락 시 일반 사용자가 잡곡 기능 접근 불가, 또는 반대로 통제되어야 할 사용자가 매입/판매 화면에 접근 가능
- **처리 시점**: **상위 계획서 작업 단계 #9.5 (권한 체계 정리)** — 사이드바/네비 개편 직후, 엑셀 #10 진입 전. 이때 모든 신규 화면이 어느 정도 윤곽 잡혀있고, 메뉴 가시성과 권한을 한 번에 맞출 수 있음
- **권장 조치**: 별도 PR. (1) 권한 키 정의 마스터 문서 신설 → (2) `lib/permissions.ts` 업데이트 → (3) `/admin/users` 권한 편집 UI에 신규 키 노출 → (4) 사이드바/페이지에 `hasPermission` 가드 일괄 점검
