# 📱 모바일 점검 — 발주서 판매처리 M1 (건별 리스트)

- 작성: 2026-09-21 · 기준 폭 **390px**(iPhone 12~15) · **360px**(갤럭시 기본)도 한 번은 볼 것
- 대상: **M1-1 ~ M1-3 완료분**(커밋 `33c568f`·`2030e21`, **미푸시**)
- 제품재고·재포장 쪽 체크리스트(백로그 §23)는 `docs/모바일-실기기-체크리스트.md`에 있고 **전부 종결**됐다. 이건 별개다.

> 🔴 **폰트가 작아 보여도 키우지 말 것** — 줄 넘침이 더 큰 문제다.
> 안 읽히면 **정보 재배치**로 푼다. 「글자 작음」은 결함으로 적지 않는다.

## 적는 법

걸리는 게 있으면 **화면 캡처 + 아래 번호**만 주면 된다. 문장은 짧아도 된다.
예) `A-3 그룹 헤더가 행이랑 붙음` / `B-5 다음 건 눌렀는데 스크롤이 중간부터`

## 가는 길

`판매관리 → 제품판매`(`/sales?tab=product`) → 묶음 행 탭 → `/sales/purchase/{id}`
폰에서는 **매트릭스가 아니라 건 목록**이 뜬다(`sm` 미만).

## B. 건 상세 (M1-1 · M1-3)

**가는 길**: `#15 택배` 아무 건 → **1라인짜리가 58건**이라 카드 한 장으로 끝나는 게 정상

- [ ] **B-1** 헤더에 **`n/67`** 위치 표시가 뜨는지 · 진행바와 `차감/주문`이 맞는지
- [ ] **B-2** 푸터가 **`작업 필요 n라인 · 남은 n kg`** + **`n라인 FIFO 일괄차감`**으로 뜨는지
- [ ] **B-3** 🔴 **360px에서 푸터 버튼 2개가 한 줄에 들어가는지** (`일괄차감` + `다음 건`)
       — 넘치면 버튼이 잘리거나 줄바꿈된다
- [ ] **B-4** 푸터가 **하단 탭바에 가리지 않는지** (Sheet는 `z-50`이라 괜찮아야 하는데 실기기 확인)
- [ ] **B-5** **`다음 건 ›`** → 목록 안 거치고 이동 · 🔴 **스크롤이 맨 위에서 시작하는지**
- [ ] **B-6** **마지막 건**에서 버튼이 **`목록으로`**로 바뀌는지
- [ ] **B-7** 🔴 **「다음 건」이 건을 건너뛰지 않는지** — 차감한 뒤에 눌러 볼 것.
       기본 필터가 「작업 필요」라 방금 차감한 건이 목록에서 빠지는데, 그래도 **바로 다음 건**이 나와야 한다
- [ ] **B-8** 매칭실패 라인 문구가 **「품종 관리에서 별칭을 추가한 뒤 재매칭」**인지
       (「SKU 지정」이면 안 된다 — 수동지정은 철회됐다)
       ⚠️ 현재 **실패 라인이 0건**이라 볼 데이터가 없다 → §3 참조
- [ ] **B-9** `#19 시아스` 건 상세 → 톤백 4라인의 규격칸이 **`1,000kg` / `200kg`**으로 갈려 보이는지
       (🔴 「톤백」만 적으면 1,000과 200이 안 갈린다)

## C. 건 단위 일괄차감 → 검토 게이트 (M1-3)

**가는 길**: 건 상세 푸터 → `n라인 FIFO 일괄차감`

- [ ] **C-1** 게이트가 **그 건 하나만** 담고 열리는지 (선택했던 다른 건이 섞이면 안 된다)
- [ ] **C-2** 🔴 **건 상세(Sheet) 위에 게이트(Dialog)가 제대로 뜨는지** — 둘 다 `z-50`이다.
       스크롤 잠금·뒤로가기·바깥 탭 닫기가 엉키지 않는지
- [ ] **C-3** 확정 후 **패널이 열린 채로** 숫자가 갱신되는지 (닫히면 안 된다 — 다음 건으로 이어가야 한다)
- [ ] **C-4** 확정 직후 **`다음 건 ›`**이 바로 눌리는지 (B-7과 같이 본다)
- [ ] **C-5** 🔴 **게이트 이슈 줄의 「이 줄」을 누르면 그 건 상세가 열리는지**
       — 폰엔 매트릭스가 없어서 예전엔 **아무 반응이 없었다**. 이번에 고친 부분이다
- [ ] **C-6** 목록 푸터 **`작업 필요 61건 검토`** 버튼이 **탭바 위에 보이는지**
       (M1-2에서 고쳤는데 **아직 실기기 미확인**)
- [ ] **C-7** `#16 해남급식`(2건)·`#17 이마트`(3건)·`#19 시아스`(1건)에서 **그 버튼이 안 뜨는지**
       (5건 이상일 때만 — 임의 기준이라 쓰면서 조정)
- [ ] **C-8** 확정에 걸리는 **체감 시간** — 몇 초인지 적어 줄 것(⚠️ 아직 측정 안 됨)

## D. 데스크탑 회귀 (같은 컴포넌트다)

건 상세는 폰·데스크탑이 **같은 파일**이라 M1-3이 데스크탑에도 얹혔다.

- [ ] **D-1** 매트릭스 이름칸 → 패널에 **푸터 일괄차감·다음 건**이 새로 생긴 게 어색하지 않은지
- [ ] **D-2** 🔴 게이트 「이 줄」 → **매트릭스 셀로 가면서 패널이 닫히는지**
       (안 닫히면 오른쪽 468px이 그 셀을 덮는다)
- [ ] **D-3** 행 체크 → 선택 바 → `차감 예정 확인`의 **기존 흐름이 그대로인지**
- [ ] **D-4** 모바일·데스크탑의 **상태 색·부족 배지가 같은지** (판정은 `cellStatusOf` 한 벌)

# 2. 🔴 데이터를 만들어야 볼 수 있는 것

## E. 완료 그룹 1줄 접기 — **지금은 확인 불가**

M1-3의 핵심인데 **작업+완료가 섞인 건이 하나도 없다**(실측 2026-09-21).
완료된 6건은 전부 **1라인짜리 전량 완료**라, 그 건에서는 **안 접히는 게 정상**이다
(작업 필요가 0이면 완료 목록이 곧 화면 내용이라 펴 둔다).

**보려면 먼저 차감해야 한다** — 지시서 §9-4 시나리오:

> `#18 서울급식` → **은평구/행복플러스 (16라인)** 건에서 **일부만** 차감

- [ ] **E-1** 16라인 중 몇 개만 차감한 뒤 → 완료분이 **`○○ 5kg 외 n건 · 전부 차감 완료 · n kg`** 한 줄로 접히는지
- [ ] **E-2** 그 줄을 누르면 펼쳐지고 다시 누르면 접히는지
- [ ] **E-3** 전부 차감하면 **접힘이 풀리고 펴진 채**로 뜨는지 (작업 필요 0)
- [ ] **E-4** 푸터가 **`전부 차감 완료 · n kg`**으로 바뀌는지

## F. 부분 차감 · 재고 부족 — **지금은 확인 불가**

실측상 **부분 0건 · 부족 판정은 가용재고에 달려 있다**.

- [ ] **F-1** 가용보다 많이 주문된 라인에서 **`부족 n`** 배지가 뜨는지
- [ ] **F-2** 부분 차감 후 상태가 **부분완료**로 바뀌는지
- [ ] **F-3** 🔴 게이트에서 **가용 0인 줄이 「부분 차감」이 아니라 「재고없음」**으로 잡히는지
       (실측에서 부족 18라인이 전부 가용 0이었다 — 4갈래로 가른 이유다)
