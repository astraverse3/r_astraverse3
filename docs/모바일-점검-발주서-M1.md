# 📱 모바일 점검 — 발주서 판매처리 M1 (건별 리스트)

- 작성: 2026-09-21 · 기준 폭 **390px**(iPhone 12~15) · **360px**(갤럭시 기본)도 한 번은 볼 것
- 대상: **M1-1 ~ M1-3**(`33c568f`·`2030e21`) + **화면 용어 통일**(`2a91668`) — 2026-09-22 **전부 실서버 배포됨**
- 🔴 **2026-09-22 용어가 바뀌었다** — 「묶음→시트 · 라인→품목 · FIFO 삭제」. 아래 기대 문구는 **바뀐 뒤 기준**이고, 용어 전용 항목은 **§G**에 모았다
- 제품재고·재포장 쪽 체크리스트(백로그 §23)는 `docs/모바일-실기기-체크리스트.md`에 있고 **전부 종결**됐다. 이건 별개다.

> 🔴 **폰트가 작아 보여도 키우지 말 것** — 줄 넘침이 더 큰 문제다.
> 안 읽히면 **정보 재배치**로 푼다. 「글자 작음」은 결함으로 적지 않는다.

## 적는 법

걸리는 게 있으면 **화면 캡처 + 아래 번호**만 주면 된다. 문장은 짧아도 된다.
예) `A-3 그룹 헤더가 행이랑 붙음` / `B-5 다음 건 눌렀는데 스크롤이 중간부터`

## 가는 길

`판매관리 → 제품판매`(`/sales?tab=product`) → 묶음 행 탭 → `/sales/purchase/{id}`
폰에서는 **매트릭스가 아니라 건 목록**이 뜬다(`sm` 미만).

## G. 화면 용어 통일 (2026-09-22 `2a91668`)

🔴 **옛 문구가 보이면 결함이 아니라 캐시다** — PWA 서비스워커가 옛 코드를 붙들 수 있다.

- [ ] **G-1** 행의 ⋮ 메뉴가 **「시트 삭제」**인지 (「묶음 삭제」면 옛 코드) ← 이번 작업의 발단

- [ ] **G-3** 차감된 게 있는 행의 ⋮ 안내가 **`차감된 품목이 있어 삭제할 수 없어요`**인지
- [ ] **G-4** 채널 칩으로 **빈 채널**을 고르면 **`이 채널의 시트가 없어요.`**인지
- [ ] **G-5** 목록 하단 안내가 **`상차 임박순으로 정렬돼요 — 먼저 나갈 것이 먼저 포장되도록.`**으로
       끝나는지 — 🔴 **`묶음 1건 = 시트 1장`**(동어반복)과 **`매트릭스 차감 화면은 다음 단계에서`**

- [ ] **G-6** 행의 건/품목 칸이 **`n건 / n품목`**인지

**업로드 2단계 모달** (`발주서 등록` → 파일 선택)

- [ ] **G-7** 1단계 설명이 **`파일을 올리면 시트 목록을 보여드려요.`**인지
       (🔴 `시트 1개 = 묶음 1건 ·` 이 앞에 붙어 있으면 옛 코드)
- [ ] **G-8** 2단계 설명이 **`체크한 시트마다 1건씩 등록됩니다.`**인지
- [ ] **G-9** 표 머리글이 **`건 / 품목`**인지
- [ ] **G-10** 🔴 푸터 요약이 **`시트 n개 · 품목 n개`** **한 줄**인지
       — 전에는 `n개 시트 → 묶음 n건 · 라인 n`으로 **같은 값을 두 이름으로 두 번** 셌다.
       **3줄 → 2줄**이 됐으니 레이아웃이 어색하지 않은지 같이 볼 것
- [ ] **G-11** 등록 성공 토스트가 **`시트 n건 등록 — 수령인 n · 품목 n`**인지
- [ ] **G-12** 시트 행의 상차 입력 힌트가 **`이 시트에 그대로 저장됩니다`**인지

**건 상세 · 게이트** (§B·§C와 같이 보면 된다)

- [ ] **G-13** 건 목록 행의 품목 수가 **`n품목`**인지 (`n라인` 아님)
- [ ] **G-14** 게이트 상단이 **`포장 n개 · 로트 n개 · 오래된 것부터`**인지
       — 🔴 **`오래된 것부터`가 새로 붙었다.** FIFO를 버튼에서 뺀 대신 순서 단서를 여기로 옮겼다.
       모바일에서 이 줄이 안 넘치는지 같이 볼 것
- [ ] **G-15** 게이트 구성 줄이 **`n품목 구성`**, 확정 버튼이 **`n품목 차감 확정`**인지
- [ ] **G-16** 매트릭스 상단(데스크탑) 배지가 **`매칭실패 n품목`**인지
- [ ] **G-17** 셀 팝오버(데스크탑) 추천 라벨이 **`오래된 로트부터 추천`**인지
       (`FIFO 추천 · 오래된 로트부터`면 옛 코드)

- [ ] **H-3** 다시 누르면 접히는지 · 다른 행을 누르면 **먼저 것이 닫히는지**
- [ ] **H-4** 🔴 **접힌 줄에 「1품목」이 안 보이는지** — 택배 67건 중 58건이 1품목이라
       전부 적으면 잡음이다. **2품목 이상일 때만** `n품목`이 뜬다
- [ ] **H-5** 매칭실패가 있는 행은 **`n품목 매칭실패`**(빨강), 재고부족은 **`재고부족`**(주황)
       🔴 **부족은 개수를 안 적는다** — 셀에 부족분이 없어 숫자를 지어내면 틀린다
       (주문 10·가용 3이면 부족은 7인데 10으로 찍힌다). 정확한 수는 펼치면 보인다
       ⚠️ 지금 데이터는 **매칭실패 0 · 부족 0**이라 이 둘은 볼 데이터가 없다
- [ ] **H-6** 펼친 행 안에 **라인 카드**와 **`n품목 일괄차감`**·**`다음 건`**이 있는지
- [ ] **H-7** 🔴 **「다음 건」이 건을 건너뛰지 않는지** — 차감한 뒤에 눌러 볼 것.
       기본 필터가 「작업필요」라 방금 차감한 건이 목록에서 빠지는데, **펼칠 때 잡아 둔**
       **순서**를 따라가므로 바로 다음 건이 나와야 한다(B-7과 같은 함정이다)
- [ ] **H-8** 차감 확정 뒤 **펼친 채로** 숫자가 갱신되는지 (닫히면 안 된다)
- [ ] **H-9** 정렬을 **「수령인 가나다」**로 바꾸면 **그룹 헤더가 사라지고** 전체가
       이름순 한 덩어리가 되는지 (백로그 §45 · A-4 참조)
- [ ] **H-10** `#18 서울급식`·`#17 이마트`·`#19 시아스`는 **여전히 건 상세가 열리는지**
       🔴 이쪽이 펼쳐지면 분기가 잘못된 것이다

# 2. 🔴 데이터를 만들어야 볼 수 있는 것

## E. 완료 그룹 1줄 접기 — **지금은 확인 불가**

M1-3의 핵심인데 **작업+완료가 섞인 건이 하나도 없다**(실측 2026-09-21).
완료된 6건은 전부 **1라인짜리 전량 완료**라, 그 건에서는 **안 접히는 게 정상**이다
(작업필요가 0이면 완료 목록이 곧 화면 내용이라 펴 둔다).

**보려면 먼저 차감해야 한다** — 지시서 §9-4 시나리오:

> `#18 서울급식` → **은평구/행복플러스 (16라인)** 건에서 **일부만** 차감

- [ ] **E-1** 16라인 중 몇 개만 차감한 뒤 → 완료분이 **`○○ 5kg 외 n건 · 전부 차감 완료 · n kg`** 한 줄로 접히는지
- [ ] **E-2** 그 줄을 누르면 펼쳐지고 다시 누르면 접히는지
- [ ] **E-3** 전부 차감하면 **접힘이 풀리고 펴진 채**로 뜨는지 (작업필요 0)
- [ ] **E-4** 푸터가 **`전부 차감 완료 · n kg`**으로 바뀌는지

## F. 부분 차감 · 재고 부족 — **지금은 확인 불가**

실측상 **부분 0건 · 부족 판정은 가용재고에 달려 있다**.

- [ ] **F-1** 가용보다 많이 주문된 라인에서 **`부족 n`** 배지가 뜨는지
- [ ] **F-2** 부분 차감 후 상태가 **부분완료**로 바뀌는지
- [ ] **F-3** 🔴 게이트에서 **가용 0인 줄이 「부분 차감」이 아니라 「재고없음」**으로 잡히는지
       (실측에서 부족 18라인이 전부 가용 0이었다 — 4갈래로 가른 이유다)
