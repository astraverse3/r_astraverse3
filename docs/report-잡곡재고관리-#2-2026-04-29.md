## 3. 확인이 필요한 사항

### 3.1 후속 작업 단계 #11(엑셀 Import)에 영향 가능
- 25년산 엑셀(`docs/잡곡대장 (25년산).xlsx`)에 등재된 품종명이 위 15종과 표기 불일치할 가능성
- 특히 슬래시 별칭(콩/적두/쥐눈이)이 엑셀에 등장하면 매칭 실패
- **#11 import 스크립트에서 alias 매핑 테이블** 추가 또는 시드에 별칭 레코드 추가 검토

### 3.2 기존 dead seed 파일
- `prisma/seed.ts`, `prisma/seed.js` 모두 현재 schema와 어긋남 (`certifications.create`는 존재하지 않는 관계)
- `package.json`의 `prisma.seed`는 `node prisma/seed.js`를 가리키고 있어 `npx prisma db seed` 실행 시 실패할 것
- 본 작업 범위 외이므로 손대지 않음. 별도 정리 작업으로 진행 권장
