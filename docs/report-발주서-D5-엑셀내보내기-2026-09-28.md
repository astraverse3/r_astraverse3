## 2. 주요 결정

| 결정 | 근거 |
|---|---|
| 용도 = 내부 증빙 · 로트는 발주서 모양 안 · 시트 단위 | 사용자 Q1·Q2·Q4 |
| **셀 색 없음** · 새 의존성 없음 | 사용자 Q3 — 발주 난 건 거의 다 나간다 |
| 열 = 원본 열(영업이 쓴 품목명·포장지·규격) | 증빙은 원본과 대조하는 것 |
| **열 순서 = 매트릭스 화면 순서** (계획 변경) | 원본 순서 복원(위상정렬)이 실DB 택배에서 실패 — 수령인마다 1~2품목이라 단서가 없다. 사용자 「규칙만 있으면 된다」 |
| 상태 판정은 `buildMatrix` 결과를 빌림 | 매칭실패·재고부족(톤백 kg) 판정이 두 벌이면 화면과 파일이 갈린다 |
| 상태 라벨은 액션이 `STATUS_META`에서 넘김 | lib가 app 폴더를 import하지 않게, 라벨은 한 벌 |
| 매입 잡곡 로트 칸 = `매입` (계획은 빈칸) | 빈칸이면 「외 N」 대표가 빈 글자가 된다 |
| 열 폭 = 농가명·로트 글자 수(10~28) | 로트 23자가 고정 폭 12에서 잘렸다. 무료판은 줄바꿈 스타일 불가 |
